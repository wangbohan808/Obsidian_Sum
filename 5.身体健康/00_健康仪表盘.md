# 健康仪表盘

> [!info] 本页用途
> 把 `5.身体健康/每日健康/` 里的每日记录当成一张数据库来查：**体重 / 睡眠 / 训练 / 饮食**。
> 每天一条记录，写在 `5.身体健康/每日健康/YYYY-MM-DD.md`；本页只负责汇总，不手写数据。
> 数据源统一为 `FROM "5.身体健康/每日健康"`，所以**新增内容不需要改本页**。
> 统计口径：一切数字以每日卡片为准；[[烹饪探索]] 是配方与计划，与实际执行有出入属正常，不参与统计。

## 记录口径

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `weight` | 体重 kg | 晨起空腹，排便后 |
| `sleep_in` / `sleep_out` | 入睡 / 起床 | 24 小时制 `"23:30"` |
| `sleep_hours` | 睡眠时长 h | 手填或我来算（起床 − 入睡） |
| `sleep_quality` | 睡眠质量 1–5 | 默认按下面的基准自动打分，你的主观感受优先 |
| `am_type` | 晨间活动 | 晨走 / 散步 / 慢跑 / 无 |
| `am_km` / `am_min` | 晨间距离 / 时长 | km / 分钟 |
| `pm_type` | 中午训练类型 | 力量-推 / 力量-拉 / 力量-腿 / 力量-全身 / 徒手 / 休息 |
| `pm_sets` | 力量总组数 | 当天所有动作的组数之和 |
| `pm_volume` | 力量总容量 kg | Σ（重量 × 次数），衡量训练量 |
| `pm_min` | 训练时长 | 分钟 |
| `kcal` | 全天摄入热量 | 估算值，允许 ±10%，估不出来就留空 |
| `protein` | 蛋白质 g | 估算值 |
| `steps` | 步数 | 可留空 |

> **睡眠基准（2026-10-12 定）**：理想 21:00 入睡 → 06:00 起床（9 h）。
> 时长达成率 ≥90% / ≥80% / ≥65% / ≥50% / 更低 → 5 / 4 / 3 / 2 / 1 分。入睡时间不额外扣分，它本身是独立字段，趋势里单独看。
> **计量口径**：器械写"两侧各 x kg"按总重 2x 计入容量；辅助类动作（辅助引体等）的辅助重量不计入容量，只留在明细里——辅助越少即越强。

> 明细（吃了什么、每个动作多少 kg 几组几次）写在记录正文里，前表的数字只放"能算的"。
> 分析时我会同时读正文和字段：字段用来画趋势，正文用来看内容变化。

## 1. 最近 14 天明细

```dataview
TABLE WITHOUT ID
  date AS 日期,
  weight AS 体重,
  sleep_hours AS 睡眠h,
  sleep_quality AS 睡质,
  am_type AS 晨间,
  am_km AS km,
  pm_type AS 力量,
  pm_sets AS 组数,
  kcal AS 热量,
  protein AS 蛋白
FROM "5.身体健康/每日健康"
WHERE date >= date(today) - dur(14 days)
SORT date DESC
```

## 2. 周汇总（近 12 周）

```dataview
TABLE WITHOUT ID
  key AS 周,
  length(rows) AS 天数,
  round(average(nonnull(rows.weight)), 1) AS 平均体重,
  round(average(nonnull(rows.sleep_hours)), 2) AS 平均睡眠,
  round(average(nonnull(rows.sleep_quality)), 1) AS 平均睡质,
  sum(nonnull(rows.pm_sets)) AS 总组数,
  round(sum(nonnull(rows.pm_volume)), 0) AS 总容量kg,
  round(average(nonnull(rows.kcal)), 0) AS 平均热量,
  round(average(nonnull(rows.protein)), 0) AS 平均蛋白
FROM "5.身体健康/每日健康"
WHERE date != null
GROUP BY dateformat(date, "yyyy-'W'WW")
SORT key DESC
LIMIT 12
```

## 3. 月汇总（近 6 个月）

```dataview
TABLE WITHOUT ID
  key AS 月份,
  length(rows) AS 记录天数,
  round(average(nonnull(rows.weight)), 1) AS 平均体重,
  round(min(nonnull(rows.weight)), 1) AS 最低,
  round(max(nonnull(rows.weight)), 1) AS 最高,
  round(average(nonnull(rows.sleep_hours)), 2) AS 平均睡眠,
  round(average(nonnull(rows.kcal)), 0) AS 平均热量,
  round(average(nonnull(rows.protein)), 0) AS 平均蛋白
FROM "5.身体健康/每日健康"
WHERE date != null
GROUP BY dateformat(date, "yyyy-MM")
SORT key DESC
LIMIT 6
```

## 4. 体重 × 睡眠（近 30 天，看两者关系）

```dataview
TABLE WITHOUT ID date AS 日期, weight AS 体重, sleep_hours AS 睡眠h, sleep_quality AS 睡质
FROM "5.身体健康/每日健康"
WHERE date >= date(today) - dur(30 days)
SORT date ASC
```

## 5. 晨间活动统计

```dataview
TABLE WITHOUT ID
  key AS 类型,
  length(rows) AS 次数,
  round(average(nonnull(rows.am_km)), 2) AS 平均km,
  round(sum(nonnull(rows.am_km)), 1) AS 累计km,
  round(average(nonnull(rows.am_min)), 0) AS 平均分钟
FROM "5.身体健康/每日健康"
WHERE am_type != null
GROUP BY am_type
SORT length(rows) DESC
```

## 6. 力量训练统计

```dataview
TABLE WITHOUT ID
  key AS 类型,
  length(rows) AS 次数,
  sum(nonnull(rows.pm_sets)) AS 总组数,
  round(average(nonnull(rows.pm_sets)), 1) AS 平均组数,
  round(average(nonnull(rows.pm_volume)), 0) AS 平均容量kg,
  round(average(nonnull(rows.pm_min)), 0) AS 平均分钟
FROM "5.身体健康/每日健康"
WHERE pm_type != null
GROUP BY pm_type
SORT length(rows) DESC
```

## 7. 待补字段（近 14 天记录不全的）

```dataview
TABLE WITHOUT ID date AS 日期, weight AS 体重, sleep_hours AS 睡眠, kcal AS 热量, pm_type AS 力量
FROM "5.身体健康/每日健康"
WHERE date >= date(today) - dur(14 days) AND (weight = null OR sleep_hours = null OR kcal = null)
SORT date DESC
```
