# 2026-11-11

## 今日发生的事

### 一、方向收敛：音视频成为爱好与工作的合流点

两个月前（2026-09-14 日记）写的待办是「探索 Linux 音视频相关内容（**判断是否值得投入**）」。今天这句问句有了答案。

我自己给出一条链：总方向 Linux + 端侧 AI → 以音视频切入（理由是视听是人接收信息最主要的两种通道）→ 与音乐/编曲、摄影/剪辑两个爱好重合 → 延伸到机器人视觉 + 端侧 AI → 爱好与工作成为有机整体。

被指出两处：
1. **"音视频"是同一条路的错觉**。视频线是爱好直接长成的技术底座（摄影的光学/色彩 → ISP/3A → 机器人视觉）；音频线只是爱好滋养的信号直觉，编曲懂"声音怎么被加工"，不懂"音频怎么被采集同步编码传输"，不是入门通道。**所以音频应当延后或降级，不是并行。**
2. **"视听是主要感官"是事后解释，不是选方向的理由**。更硬的是：机器人的感知层只有摄像头和麦克风两个入口，而视觉闭环我已经有一个在跑的项目（猫咪监控）。

还有一条我认了：**合流有方向性**——技术→爱好是免费收益，爱好→技术是有成本的（练琴一旦挂技术 KPI，就同时当不成燃料也当不成爱好）。这和"把想要的东西先训练化"是同一个习惯的变形。

落盘：`4.极简主义/33.爱好与技术合流·两条不对称的桥.md`

### 二、器材问题：iPhone 能不能替代专业相机

我担心学摄影的器材太贵，问能不能直接用 iPhone 17，并下载了「飓风相机」。

关键结论：**"器材贵"是伪障碍**。缺的不是相机，是一根 USB-C 转 HDMI 线加一块 UVC 采集卡（≈150 元），而这两样本就在音视频学习清单的第 3 步里。相机贵在镜头和传感器，恰好是我求职方向不需要的。

iPhone 的正确定位不是相机，是**可控视频源 + 色彩基准 + 元数据样本库**。三条路径：元数据路径（ffprobe 读色彩/范围/码率，0 元）、HDMI 采集路径（160 元，验 limited/full 与 quantization 透传）、手动拍摄（只学摄影）。

两个提醒记下：系统相机必须停用（计算摄影把物理关系打散）；飓风相机里的光圈是**模拟**的，手机永远学不到光圈-景深-衍射。
