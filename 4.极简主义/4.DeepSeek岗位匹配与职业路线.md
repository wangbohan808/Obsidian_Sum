# DeepSeek 岗位匹配与职业发展路线

> 更新时间：2026-08-27　|　基于 DeepSeek 官方招聘页及公开招聘渠道的实时在招信息
> 前提：纯工程社招路线、不读全职研；长期路线图 + 近期清单两条都要

---

## 一、你的坐标

**现状（已从笔记核实）**
- 2025 年 6 月本科毕业，现职：MES 系统 + 海康工业相机上位机代码重构（Python、机器视觉、YOLO/迁移学习、Bayer-RAW 等）。
- 计划轨迹：2026 年底离职 → 空窗 1–2 个月 → 入职瑞莎 Radxa 做 Linux BSP / 多媒体驱动约 3 年 → 最终出口 DeepSeek（或自由职业）。

**差异化优势（DeepSeek 里真正稀缺的那类人）**
- **懂真实硬件**：MCU / FreeRTOS / PCB / 焊接 / SolidWorks 建模，能从芯片寄存器一路看到电路板——这正是绝大多数纯软件工程师不具备的底层视角。
- **向 Linux 底层走的能力**：规划中「Linux 系统构建 → 驱动添加与适配 → 自研发行版 → 端侧AI」这一条链，正好覆盖 DeepSeek 硬件基础设施岗位 JD 里写明的 **ACPI / OpenBMC / PCIe / I2C / I3C / BIOS-UEFI** 等加分项。
- **端侧AI + 全链路造物**：在真实硬件上部署、调试、优化 AI，是「纸上 AI」泛滥时代里的稀缺交叉点。
- **造得出、也讲得好**：摄影剪辑 + 宣发能力，是「AI 跨界技术人才」这类不限专业岗位最看重的「从零到一做成有影响力的事」的底气。

> 一句话定位：你走的是「全链路硬核工程师」路线，DeepSeek 不招"只会调包写业务"的人，但非常需要"真实硬件 + Linux 底层 + AI"交叉的人。

| AI 核心系统研发（4） | 超算集群研发、高性能算子/通信/编译器、大模型训练/推理框架、高性能分布式存储 |

- **Agent**：20+ 岗位提及；**LLM**：15+ 岗位

- **MCP / Tool Use / Agent Loop**：5 个岗位明确要求
- **Prompt / Context Engineering**：5+ 岗位
- Go / Rust / C++ / Python 为核心工程语言

**关键信号**：多数岗位「接受实习」且明确"欢迎没有大模型经验、但计算机基础扎实、对 AGI 有热情的同学"——对你这种「非科班大模型、但硬底子扎实」的人是明确利好。

## 三、岗位契合度排序

按契合度从高到低（每项标注：契合点 / 差距 / 是否主攻）：

### 1.　硬件 / 基础设施方向（契合度 ★★★★★，主攻）
- **代表岗位**：IT 基础设施团队-系统硬件 & 网络方向、IDC 数据中心团队、超算集群研发工程师。
- **契合点**：JD 加分项直接写着 ACPI、OpenBMC、BIOS/UEFI、PCIe、I2C/I3C、Redfish/IPMI、RDMA——全是你 Linux BSP / 嵌入式 / 总线的既有或规划强项；"懂真实硬件、能在固件或总线层面定位问题"正是你的差异化。
- **差距**：需补 Python/Go 工具开发、压测框架（fio/iperf3/gpu-burn）、大规模集群运维经验。
- **结论**：**第一主攻**，且该岗"欢迎有热情的白纸同学"、经验要求宽松。

### 2.　AI 核心系统研发（契合度 ★★★★，中长期主攻）
- **代表岗位**：大模型训练/推理框架工程师、高性能算子/通信/编译器工程师、高性能分布式存储工程师。
- **契合点**：底层不变量是 C/C++/Rust + 性能调优 + 系统基础，你的「Linux 底层 + 硬件」是稀缺交叉；JD 明确"欢迎无大模型经验、基础扎实者"。
- **差距**：需补 C++/Rust 深度、CUDA/Triton 算子、并行/分布式计算、RDMA 编程，投入周期约 2–3 年。
- **结论**：**第二主攻**，当作瑞莎 3 年后要够到的"上升主峰"。

### 3.　Agent Infra / 服务端 / 全栈后端（契合度 ★★★☆，可转）
- **代表岗位**：Agent Infra 研发、服务端开发（大模型研究中台/线上核心服务/数据仓库）。
- **契合点**：Python 可迁移；Agent 沙箱/容器/调度与"嵌入式资源隔离"思维相通；年薪可观。
- **差距**：需补 Go/Rust、容器与沙箱（Docker/K8s/gVisor/Firecracker）、流式服务（SSE/WebSocket/gRPC streaming）、ReAct 循环基建。
- **结论**：**备选方向**，若主攻 A/B 卡壳可作降级进入路线。

### 4.　测试开发（契合度 ★★★，敲门砖）
- **代表岗位**：测试开发工程师（Go/Rust 优先、AI 系统质量保障/评测体系）。
- **契合点 / 差距**：门槛相对低，但与你"造"的定位偏离。
- **结论**：不主攻，仅作保底敲门砖。

### 5.　深度学习研究员 / 算法（契合度 ★★，明确降级）
- **代表岗位**：预训练/后训练/多模态研究员。
- **差距**：通常需硕博 + 顶会论文，纯社招对本科学历基本不可达。
- **结论**：**远期观察项**（除非未来读在职硕/发高质量成果），不进入近期主线。

### 6.　「AI 跨界技术人才」特色通道（契合度 ★★★★★，主推差异化敲门）
- **岗位特点**：不限专业背景，按个人兴趣/能力匹配至研究或工程团队。
- **加分项（几乎为你量身定制）**：某领域做到极致 / 著名开源贡献 / 个人技术博客 / 从零到一做成有影响力的事 / "不走寻常路"[扩招报道](https://www.eet-china.com/news/202606262416.html)。
- **结论**：**贯穿全过程的特色通道**——用「全链路造物 + 端侧AI + 开源/博客 + 产品宣发」作为差异化筹码，绕过学历/论文门槛。

## 四、主攻岗位定标（2 + 1）

### 主攻 A：IT 基础设施团队-系统硬件 & 网络方向（First Choice）
- **地点**：杭州（拱墅区汇金国际）｜杭州/北京
- **JD 要点（硬件方向）**：探索 GPU/CPU/SSD/网卡/服务器实现细节、选型决策；建立「品牌→型号→固件→参数」配置管理体系与自动下发工具；设计硬件基准压测框架（集成 fio/iperf3/gpu-burn）；集群故障应急处置。
- **JD 要点（网络方向）**：OSPF/BGP/VXLAN/VPN；跨地域多 DC 互联；InfiniBand/RoCE v2（RDMA）全生命周期运维；全栈监控与网络自动化。
- **任职要求**：硬件架构或网络技术至少一个方向深入；熟悉 Python 或 Go、能独立开发压测/配置管理/自动化工具；有数据建模能力。
- **加分项（务必逐个对标）**：Redfish/IPMI、Rust、ACPI/OpenBMC/BIOS-UEFI/PCIe/I2C/I3C、RDMA 调优、AI 训练流程理解[IT基础设施 JD](https://www.51shuobo.com/ids_other/job_277559548)。
- **你要补的**：Python/Go 自动化工具、fio/iperf3/gpu-burn 压测、OpenBMC/IPMI、基础 RDMA 概念。
- **为什么是你的菜**：这是全公司里最"贴硬件"的技术岗，与你的 BSP/驱动规划重合度最高，且经验要求宽松。

### 主攻 B：大模型训练/推理框架工程师（3 年后的主峰）
- **地点**：杭州 / 北京｜实习/全职
- **JD 要点**：建设分布式训练/推理系统（模型并行、长上下文、MoE、低精度训推）；RL 训练系统（异步 RL、Agent RL、OPD）；多模态训练系统；KV Cache 磁盘缓存与负载均衡。
- **任职要求**：熟悉 Python/C++/Rust 之一、了解 PyTorch；代码品味好、擅长与 Code Agent 合作。
- **加分项**：开源深度贡献/优秀个人项目、高性能计算赛事（SC/ASC/ISC/PAC）、CUDA/Triton/TileLang 算子、RDMA 编程/CPU-IO 优化、复现 LLM/RL 论文[训练推理框架 JD](https://www.51shuobo.com/ids_other/job_277559543)。
- **你要补的（2–3 年）**：C++ → Rust、CUDA/Triton 算子、并行/分布式、PyTorch 训练与推理、至少一个开源 LLM 训练/推理项目深度贡献。

### 特色通道 C：AI 跨界技术人才
- **定位**：不按 JD 投、按"个人作品集"投——把你瑞莎期间的开源驱动/BMC 项目、端侧 AI 小产品、技术博客、产品宣发视频打包成一个"从零到一带点影响力"的 portfolio，走差异化面试。
- **为什么是你的王牌**：这条通道的加分项几乎逐条命中你的「四位一体」，是学历/论文短板下的最优撬动点。

## 五、长期路线图（三段式）

### 阶段 0｜现在 → 2026 年底（稳住 + 启动）
- 目标：不急于投 DeepSeek，把离职前几个月变成"技能引擎预热"。
- 里程碑：MATLAB/迁移学习与机器视觉项目收尾归档；确定瑞莎入职方向（Linux BSP/多媒体驱动）；开启 C++ / Rust / 个人博客三项并行起步。

### 阶段 1｜2027 → 约 2030（瑞莎 3 年沉淀，兑现"全链路"）
- 主线：Linux 内核驱动、硬件 bring-up、多媒体/网络相关底层，把 BSP 做实；同步补 DeepSeek 缺的工程语言。
- 里程碑（逐年）：
  - **第 1 年**：独立完成 1–2 个 Rockchip 平台的驱动 bring-up；C++ 到可写高性能代码；把 Rust 学起来；开博客持续记录驱动/底层调试。
  - **第 2 年**：向 OpenBMC/IPMI/ACPI/PCIe 等硬件底层延伸；做出 1 个开源驱动/BMC 相关项目；引入 PyTorch 端侧推理（RKNN/NPU）做端侧 AI 落地。
  - **第 3 年**：包一个"全链路"作品（建 shell-建模→PCB→BSP→端侧AI→宣发视频），打磨成 portfolio；对标主攻 A/B 的 JD 逐项清缺口。
- 可验证产出：开源仓库深度贡献、个人博客、1 个完整硬件产品 + 宣发视频。

### 阶段 2｜约 2030 → 2031（出口前 1–2 年定向补强）
- 目标：把"能造"翻译成"DeepSeek 要的语言"。
- 关键动作：
  - 用 1 年补齐主攻 B 的 C++/Rust + CUDA/算子 + 并行计算，复现 1 个 LLM 训练/推理小项目。
  - 参加 1 项高性能计算/算法类赛事或给主流开源 LLM 框架提 PR。
  - 同步投「AI 跨界技术人才」特色通道 + 主攻 A（系统硬件&网络）。
- 可验证产出：开源贡献记录 + 赛事成绩 + 面试作品集。

### 阶段 3｜进入 DeepSeek（落地）
- 目标：以主攻 A（IT 基础设施-系统硬件/网络）或特色通道 C 作为第一落点，进入后再向 AI 核心系统（主攻 B）内部迁移。
- 判据：拿到 offer；若未果，回退到备选「Agent Infra/服务端」或自由职业 Plan B。

## 六、近期可执行清单（逐阶段可上手）

### 离职前（现在 → 2026 年底，剩余约 3–4 个月）
1. 把 MES/海康相机项目整理成可展示的「问题—方案—结果」仓库（GitHub），作为第一个 portfolio 素材。
2. 确定瑞莎投递方向（Linux BSP / 多媒体驱动 or 科技视频创作），准备简历。
3. 每天固定 1–2 小时刷 **C++ 基础 + Rust 入门**（《The Rust Programming Language》官方书即可）。
4. 开一个技术博客，先写 3 篇：机器视觉踩坑、Bayer-RAW 色彩处理、MES 上位机重构心得。
5. 读一遍主攻 A 的 JD，把不懂的词（OpenBMC/IPMI/Redfish/RDMA）列成学习清单。

### 空窗期（约 1–2 个月）
1. 彻底休息恢复（你既定的目标），不安排硬性学习。
2. 用碎片时间看 2–3 个 DeepSeek 官方技术博客/论文，建立对"他们到底在做什么"的直觉（可选，勿压力化）。

### 瑞莎头一年（2027）
1. 上手 Linux BSP 后，把驱动/底层调试写成博客，每周 1 篇。
2. 半年内完成第 1 个开源 driver/bring-up 项目并持续贡献。
3. C++ 进阶到能写高性能/内存安全代码；Rust 达到能写工具链水平。
4. 学习 Python/Go 写运维工具（对应主攻 A 的"独立开发压测/配置管理工具"要求）。
5. 留出 20% 精力做端侧 AI（Rockchip NPU 推理），保持"硬件+AI"交叉标签。

## 七、风险与备份（Plan B）

- **DeepSeek 岗位随融资后扩张在变**：当前 33–36 岗是"扩招一倍的起点"，策略上不必锁定单一岗位名，锁定"硬件基础设施 + AI 核心系统"两个大类更稳。
- **核心人才流失带来窗口，也带来竞争**：2025 下半年至 2026 上半年至少 5 名核心研发离职进入大厂，DeepSeek 急需新鲜血液，但同时顶级候选人也在流入，竞争激烈[扩招报道](https://www.eet-china.com/news/202606262416.html)。
- **算法研究员路线存在学历天花板**：已按"纯工程社招"降级处理；若未来有意愿，可在瑞莎期间读在职/非全硕再评估。
- **Plan B（自由职业）**：你已有明确备选——时间地点自由的自由职业。若 3 年沉淀后 DeepSeek 无果，用「全链路造物 + 端侧 AI + 宣发」能力直接做独立产品/接单，同样成立。
