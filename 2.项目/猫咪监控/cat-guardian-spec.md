## 1. 产品定位与形态

**一句话**：一台基于 ROCK 5C 的**迷你一体机（mini AIO）**——上半是「方屏 + 45° 半透半反镜」的棱镜悬浮显示，下半是装开发板的底座；差旅时当猫咪监护站，日常当桌面信息摆件。

**形态拆解**（自下而上）：

| 层级   | 内容                                    | 作用          |
| ---- | ------------------------------------- | ----------- |
| 底座   | ROCK 5C 开发板 + 外露 USB/网口/HDMI/TF + 摄像头 | 算力、存储、联网、感知 |
| 顶面屏幕 | 4.0 寸 480×480 方屏，平放朝上发光               | 悬浮画面的光源     |
| 斜架镜片 | 45° 半透半反镜                             | 把屏幕虚像「抬」到空中 |

**双场景**：

| 场景   | 显示内容                | 相机/网络                |
| ---- | ------------------- | -------------------- |
| 差旅监护 | 今日猫报 + 异常提醒         | 本地 AI 检测 + 加密 P2P 远程 |
| 桌面摆件 | 时钟 / 天气 / 日历 / 照片屏保 | 待机                   |

## 3. 显示子系统（核心）

### 3.1 屏幕规格

| 参数     | 取值                 | 注释（是什么 / 怎么调）                              |
| ------ | ------------------ | ------------------------------------------ |
| 尺寸（对角） | 4.0 英寸             | 「寸」= 英寸，1 英寸 = 25.4mm，指屏幕对角线长度，不是宽高        |
| 分辨率    | 480 × 480 像素       | 横竖各 480 个像素点；同尺寸下数值越大画面越细。方屏用「1:1 正方形」     |
| 有效显示区  | ≈72 × 72 mm        | 实际能发光的区域边长，决定虚像大小                          |
| PPI    | ≈170               | 每英寸像素密度；>150 近距离看基本无颗粒，>300 接近手机           |
| 面板     | IPS 全视角            | 可视角度大；「Normally Black」黑位更好，利于悬浮            |
| 接口     | MIPI DSI（2-lane）   | 接 ROCK 5C 的 4-lane DSI 口，向下兼容；lane 数越高带宽越大 |
| 驱动 IC  | ST7701S            | 屏幕驱动芯片，主流、Linux/LVGL 生态成熟                  |
| 亮度     | 850–950 cd/m²（高亮款） | 悬浮靠镜片反射，会损失约一半,故优先高亮版；普通款 300–350 白天偏暗     |
| 位深     | RGB565 / RGB888    | 颜色精度，RGB565=6.5 万色，RGB888=1670 万色          |

**选型理由**：方屏 + 高亮 + 480×480 正好凑齐「方形悬浮 + 白天能看清」两个硬条件；ST7701S 是 480×480 的事实标准驱动，调试资料最全。

### 3.2 棱镜（45° 半透半反镜）规格

| 参数    | 取值            | 注释                            |
| ----- | ------------- | ----------------------------- |
| 结构    | 单面 45° 镜      | 只用一块斜镜，不同于 HoloCubic 的四面金字塔   |
| 镜片尺寸  | ≈72 × 102 mm  | 长边 = 屏幕显示区对角线 ≈72×√2          |
| 反射率 R | 45–50%        | 镜片把多少光反射进眼睛；太高→后面背景看不清，太低→虚像暗 |
| 透射率 T | 50–55%        | 镜片让多少背景光透过，决定「半透明悬浮感」         |
| 材质    | 光学级亚克力 / 超白玻璃 | 玻璃更平整、亚克力更轻不易碎                |
| 镀膜    | 介质分光膜         | 比普通铝膜透反比更均匀、基本无色偏             |

**光学几何（关键公式）**：

- 屏幕平放朝上，镜片与之成 **45°**。

- 人从镜片低端一侧平视，看到屏幕经镜反射的**竖直虚像**。

- **虚像高度 = 屏幕显示区深度**（72mm 方屏 → 72mm 方形虚像）。

- 镜片实面长边 = 显示区 × √2 ≈ 72 × 1.414 ≈ 102mm。

### 3.3 需要注意的两个坑

1. **亮度衰减**：45° 半透反镜反射率约 50%，屏幕 900 cd/m² 到眼睛只剩约 450 cd/m²。所以高亮屏是刚需，不是可选项。
2. **排线路径**：屏幕在顶面朝上、板子在底座，MIPI DSI 排线（FFC）要从底座绕到顶面且不能挡镜片光路，需预留走线槽。

## 4. 底座与接口

### 4.1 ROCK 5C 外露接口清单

| 接口               | 数量 | 作用 / 是否外露     |
| ---------------- | -- | ------------- |
| USB 3.0 Host     | 1  | 外露，接外设/存储     |
| USB 3.0 OTG      | 1  | 外露，刷机/调试      |
| USB 2.0 Host     | 2  | 外露            |
| 千兆以太网 RJ45       | 1  | 外露，稳定联网       |
| HDMI 2.1（8Kp60）  | 1  | 外露，调试显示器      |
| TF 卡槽            | 1  | 外露，存储         |
| 耳机孔（含麦克风输入）      | 1  | 外露            |
| MIPI DSI（4-lane） | 1  | 内部接屏幕排线       |
| MIPI CSI（4-lane） | 1  | 内部接摄像头        |
| 40-pin GPIO      | 1  | 内部接 RGB 灯/传感器 |

**接口布局原则**：所有外露口集中到底座后立面，用短 FPC/转接小板统一引出，前面板只留摄像头开孔与 RGB 灯，保证正面简洁、屏占比观感高。

### 4.2 摄像头

- **位置**：底座前面板，向前俯瞰，俯角约 30° 可微调。

- **镜头**：广角/鱼眼，对角 FOV 120°–150°，尽量一机覆盖「食碗 / 饮水器 / 猫砂盆」三区。

- **接口**：MIPI CSI 4-lane。

- **约束**：镜头光轴与屏幕发光面垂直、与镜片光路分离，互不遮挡。

## 6. 参数注释（名词手册）

> 本节是给作者自己看的「翻译」，看不懂任何数值都来这里查。

| 术语           | 通俗解释                  | 本项目取值                   | 调大/调小的影响                |
| ------------ | --------------------- | ----------------------- | ----------------------- |
| 分辨率          | 画面由多少个「像素点」拼成，横×竖     | 480×480                 | 越大越清晰，但也越吃算力/带宽         |
| 屏幕尺寸(寸)      | 对角线长度，1 寸≈25.4mm      | 4.0″                    | 越大虚像越大、整机越大             |
| PPI          | 每英寸塞多少个像素             | ≈170                    | 越高近看越细；<100 会有颗粒感       |
| 亮度(cd/m²)    | 屏幕发光强度，俗称「尼特 nit」     | 850–950                 | 越高越抗强光；悬浮显示按一半损耗算       |
| 对比度/黑位       | 最亮与最暗的比值；黑位=不发光时有多「黑」 | IPS 1000:1              | 黑位越纯，虚像越「浮」；OLED 纯黑最优   |
| 反射率 R        | 镜片把多少入射光反射出来          | 45–50%                  | 太高(如80%)像镜子、太低(如20%)虚像暗 |
| 透射率 T        | 镜片放多少背景光过去            | 50–55%                  | 与 R 之和≈100%，决定「半透明」程度   |
| 视场角 FOV      | 镜头能拍到的角度范围(对角)        | 120–150°                | 越大覆盖越广，但边缘畸变越大          |
| NPU 算力(TOPS) | 每秒可做多少万亿次 AI 运算       | 6 TOPS                  | 决定能跑多大的检测模型             |
| RAM          | 运行内存                  | 16GB                    | 越大越能并行跑多个模型/进程          |
| MIPI lane    | 数据传输「车道」数             | DSI 4-lane / CSI 4-lane | 越多带宽越大，支撑更高刷新/分辨率       |

## 7. 软件栈与功能模块

| 层级   | 选型 / 技术                     | 说明                      |
| ---- | --------------------------- | ----------------------- |
| 系统   | Armbian / Radxa OS（Linux）   | ROCK 5C 官方支持            |
| 推理框架 | RKNN-Toolkit + rknn runtime | Rockchip NPU 原生推理       |
| 检测模型 | 轻量 YOLO（YOLOv8n 级）          | NPU 上 30fps 猫检测         |
| 追踪   | ByteTrack / IoU             | 给猫挂 ID，防多猫混淆            |
| 行为判定 | ROI 状态机                     | 食碗/饮水/砂盆三联状态机           |
| UI   | LVGL                        | 悬浮屏画 UI，对 480×480 方屏支持好 |
| 远程   | WebRTC 加密 P2P               | 按需建立连接，不看则不传画面          |
| 存储   | 环形预录缓冲 + TF 卡落地             | 事件前后 8s 落盘              |

**功能优先级**（首版只做 P0+P1）：

- **P0**：远程实时查看、进食/饮水/如厕计数、异常事件录制、离线缓存。

- **P1**：桌面信息仪表、今日猫报、照片屏保、喂食/加水提醒。

- **P2**：手势交互、多机扩展、喂食器联动、健康趋势报告。
