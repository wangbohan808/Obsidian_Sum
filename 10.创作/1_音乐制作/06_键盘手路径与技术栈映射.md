# 键盘手路径与技术栈映射

> [!info] 一句话核心
> **键盘手的任务不是弹钢琴，是补频段——哪一格空着就补上去；而"设备调试＋录音"这条副线之所以值得兼，是因为它和 Linux 音视频是同一批概念的两种叫法，但必须产出数字才算数，乐队本身不能变成求职项目。**

> 缘起：2026-11-17。已定方向：用 61 键 MIDI 键盘学键盘手技能 → 进初级乐队 → 兼任设备调试与录音。本篇是"键盘手任务 + 训练路径 + 技能映射"三问的收敛。
> 前置：[[05_编曲分工与频率预算]]（24 格与功能线是本文的地基）。

## 零、键盘手的五件活

| 任务 | 具体 | 频段 |
| --- | --- | --- |
| **和声铺底（comping）** | 主歌长音 pad，副歌节奏和弦。**主要工作** | 200–1k |
| **音色提供者** | 弦乐／电钢／Organ／Pad。判断"乐队缺什么声音"，不是"我弹什么音" | 任意 |
| **副旋律 / 呼应** | 跟主唱一唱一和，副歌后 hook | 1–3k，退半步 |
| **低频补强** | 小编制替 bass，大编制与 bass 锁 | 40–200 |
| **特殊音效 / riff** | city pop 电钢 riff、funk clav | 800–2k |

**键盘是唯一能在任意频段出现的乐器**——这既是万能补丁，也是塞爆中频的元凶。

### 初级键盘手三个错（都源于"怕听不见自己"）

| 错 | 症状 | 正解 |
| --- | --- | --- |
| 弹太满 | 每个空隙都填 | 主歌只长音，1–3k 让给人声 |
| 音色太厚 | pad 铺满 200–2k，盖住吉他与人声 | cutoff 调暗、attack 拉长 |
| 推音量 | 听不见自己就抬推子 | 换音区／减少占位——推子只改优先级，不改身份 |

## 一、四层训练（按序，不可跳）

| 层 | 内容 | 时长 |
| --- | --- | --- |
| 一、和弦与和声 | 12 个基本和弦＋转位（转位是为了低音线走顺）；和弦符号 C/Cm7/Cmaj7/Csus4/C·E；**级数系统（1-6-4-5、4-5-3-6、卡农）** | 2–3 个月 |
| 二、节奏与 comping | 柱式／分解／切分／反拍。**本质＝不弹整拍，只弹空隙（TDM）** | 2–3 个月 |
| 三、音色 | 五类：Acoustic Piano、Electric Piano（Rhodes）、Organ（含 rotary）、Pad/Strings、Synth lead。**只吃两个旋钮：cutoff ＋ attack/release → 覆盖 80% 调整** | 持续，见效最快 |
| 四、合奏意识 | 听 hi-hat 判密度、听 bass 定左手、8 小节一组数段落、**学会不弹** | 进队后 |

**级数系统是查表不是感觉**：会了级数任何调都能弹，不必背 12 个调和弦表。工程师背景者一周可达，很多学两年琴的人不会。

**每日 40 分钟分配**：10 min 和弦转换（纯机械，不算曲子）／15 min 曲子／10 min 跟节拍器 comping／5 min 音色。

**起步曲目按"和声教材价值"挑，不按好听挑**：

| 曲 | 为什么 |
| --- | --- |
| Plastic Love（竹内玛莉亚） | city pop 和声进行标准教材 |
| Just the Two of Us | 2-5-1-4 变体，被采样最多 |
| Isn't She Lovely | 12 小节循环，comping 最省心 |

## 二、技术栈映射（乐队 ↔ Linux 音视频）

| 乐队里做的事              | 同一个概念        | Linux 音视频里的名字        |
| ------------------- | ------------ | -------------------- |
| 增益结构与电平             | 幅度、精度、动态范围   | 位深／dBFS 刻度           |
| XLR 平衡线与接地          | 差分传输与共模抑制    | I2S 差分／CMRR          |
| Word clock 同步       | 时钟域与抖动       | BCLK／LRCLK／MCLK      |
| **Buffer size 与延迟** | **缓冲、周期与欠载** | **ALSA period／xrun** |
| EQ／压缩／混响            | 滤波与增益控制      | biquad／包络／卷积         |
| 分轨与路由               | 数据通路拓扑       | PipeWire／ASoC DAPM   |

> [!important] 最值钱的一行是 buffer
> 在乐队里会亲手经历：buffer 调小→手感好但爆音；调大→稳但半秒后才出声。这个取舍摸过之后，再看 ALSA 的 `period_size`／`-EPIPE` 就不靠想象。
> **稀缺组合＝懂时钟/DMA/寄存器/差分信号，同时摸过真实音频工作流。** 纯软件转过去的人没摸过现场，做现场的人不读驱动。

### 但必须产出数字

简历上"我懂音频"＝零。要能说：**"端到端延迟从 20 ms 降到 5 ms，靠 period 1024→256，并解决 clock drift 导致的周期性 xrun。"**

## 三、设备与录音学习清单

### 设备调试（2 周理论＋4 周实机）

| 内容    | 要点                                              |
| ----- | ----------------------------------------------- |
| 电平单位  | dBu／dBV／dBFS；**-18 dBFS ≈ 0 VU ≈ +4 dBu** 为对齐标准 |
| 增益结构  | mic→preamp→mixer→amp 各级目标电平、噪声底与削波余量            |
| 平衡传输  | XLR 三芯（热/冷/地），差分抵共模                             |
| 接地与噪声 | 地环路→50 Hz hum；DI 隔离变压器／单点接地                     |
| 反馈抑制  | 麦箱相位、陷波、gain before feedback                    |
| 延迟换算  | 48 kHz 下 256 samples ≈ 5.3 ms                   |

### 录音（8–12 周）

话筒指向性极坐标（心形／全指向／8 字）→ 近场效应与距离 → 三种立体声摆法（XY／AB／ORTF）→ 多轨延迟补偿与时钟主从 → CoreAudio／ASIO／ALSA 三套驱动差异。

**顺序：设备调试 → 录音 → 驱动。** 前两者立刻给乐队带来价值（换来位置），第三个才回主线。

## 四、两条边界

| 边界 | 说明 |
| --- | --- |
| **顺序边界** | 61 键（无配重）学"键盘手"够，学"钢琴触键"不够。练触键去琴行租真钢（30–60 元/时），别指望 MIDI 键盘 |
| **心态边界** | **设备调试是"顺便"，不是"顺便的任务"。** 每个动作先问求职有无用，乐队会变成第二个工作，乐趣一没撑不过三个月。技术重叠是副产品，不是目标 |
