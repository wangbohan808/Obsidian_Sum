好处：
- 单机游戏录制和推流十分吃性能
- 游戏机只负责打游戏，推流机负责跑推流和录制，互不干扰
- 游戏机性能损失最小
# 硬件准备

1. 采集卡 x 1
2. HDMI转HDMI线 x 1
3. type-c转type-c的线 x 1

- 内置采集卡--要求台式机有pcie槽
- 外置采集卡--电脑需要有USB3.0以上的接口（需要采集卡的type-c转type-c转接过去）--否则带宽不够，跑不满 1080p x 60帧

# 接线步骤

1. HDMI线接在显卡（不要接在主板），另一边插在HDMI-in（不要插在HDMI-out）
2. type-c转type-c，分别接在笔记本与笔记本电脑上

- 如果采集卡很高端（支持4K144帧、240帧），可以将采集卡的HDMI-out接到显示器--电脑性能会进一步损失
- 老老实实拉一根DP线，从显卡接到显示器就行了--上述作用与这一个等价

1. 打开笔记本的OBS--添加一个源--点击视频采集设备--创建源--采集到采集卡、选择采集卡型号--画面就出来了
2. 分辨率进行选择--一般是1080P60帧
3. 优先使用硬件解码一定要开
4. 音频设置输出桌面音频

5. 游戏机屏幕，开扩展模式；开复制模式开不了HDR，开扩展模式打开HDR


- 设置完毕上述之后，采集不到游戏机的画面

1. 点游戏机的OBS
2. 点击左下角加号--点击显示器采集--可以单独采集游戏（选择主显示器，不要选择采集卡的副显示器）
3. 打开“原投影”，投影到副显示器

--做完上述，画面就通了



# 声音配置

让推流机的麦克风声音传回台式机，并且没有延迟

**硬件配置：**
1. 耳机
2. 麦克风（可以是USB接口）
3. 3.5mm AUX 公对公的线


**原理：**
- 采集卡采集视频的时候，已经顺便将音频采集过来了；
- 如何让台式机没有拿到麦克风声音，并且没有延迟？

解决方案：
- 将声音从笔记本，传回台式机

1. 耳机插在采集卡的耳机插孔（3.5mm AUX公头）
2. USB-A接口的麦克风，插在笔记本上
3. 3.5mm AUX 公对公线，分别插在笔记本口以及台式机口（麦克风-in）
4. 笔记本插孔设置--模拟选项，选择耳机
5. 系统--声音--高级--更多声音设置--录制--找到麦克风--右键点击属性--“侦听此设备”打勾，“通过此设备播放”选择刚刚模拟的耳机--点击保存

- 打开笔记本的OBS--选择音频输入采集--创建新源（不要选择麦克风，需要选择采集卡）

- 做完上述，声音回到台式机--直接推流，观众也可以听到
- 回到笔记本的OBS--混音器空白点击右键--点击高级音频设置--音频监听关闭
- 采集卡已经将声音从台式机传到笔记本，再次监听会从笔记本传回去，造成回环，双倍延迟
