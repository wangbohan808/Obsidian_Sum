# 作息与周节奏

> **一句话核心：不能"每天做所有事"。事项按周期排，不按时刻排。**
> 本篇回答一个问题：在"**05:30 / 06:30 起 · 加班日 22:20 睡 · 非加班日 21:30 睡** · 中午健身 · 8 小时工作 + 一三五加班到 21:00 · 周六正常班"这套硬约束下，怎样把以前所有短期规划与延迟满足的事真正装进去。
>
> **⚠️ 2026-11-02 全面重排**：工作改加班制（一/三/五到 21:00，周六 08:30–18:00）。**分钟级时刻唯一权威是 [[身心练习总纲]] §00**，本页只留骨架。**睡眠是这套排法的基准，不是可选项**——其余（自由块、周末内容、性训练日子）都可以灵活改。

> 上游：`13` 第七节（及时满足 = 护城河本体 · 记账错误 · 四档供给）、`12` 第九节（频率 > 强度）、`9.半年扎根计划`（每周节奏 · 三线并行）、`0.生活构成`（睡眠-饮食-健身底座）。

## 一、先对齐现实：现在真正在跑的是什么

翻健康日志，现实与目标之间有明显落差：

| 日期 | 入睡 → 起床 | 晨跑 | 备餐 | 午间力量 |
|---|---|---|---|---|
| 10-13 | 23:00 → 06:30 | 无 | 未执行 | ✅ 力量-全身 |
| 10-14 | 00:00 → 07:40 | 无 | 未执行（外食） | 无 |
| 10-15 | 待补 | 无 | 未执行（外食） | ✅ 力量-胸/肩 |

**唯一稳定在跑的是中午那一次力量训练。** 目标（21:00–06:00）与现状（23:00–00:00 入睡）差 2–3 小时；"晨跑 + 备餐"目前仍是纸面计划。

> 因此本篇不写"理想的一天"，只写**从现状走到目标的路径**。直接排一张 21:00 睡、6:00 起的完美表，只会得到第二份纸面计划。

## 二、时间账

> 完整时间表见上方**执行表 A**；精确到分钟的分叉见 [[身心练习总纲]] §00。

**结论（2026-10-21 重算）：工作日晚间已没有"每天固定的 75 min 自由块"。**

22:00 必须睡——这是 8 小时睡眠能成立的前提，不可动。18:30 下班到家后到 22:00 的 3.5 小时里：晚饭 45 min + 备餐 60 min + 训练/阅读/自由 85 min + 冥想 20 min + 洗澡 20 min，**刚好排满，没有余量**。

**所以"自由调度"从每天变成了按周分配：**

| 日子 | 20:15–21:40 这段用来做什么 | 有无机动 |
|---|---|---|
| 周一 / 周五（A 摩擦日） | 训练 35 min + 洗澡 + 空档 | 无 |
| 周三（B 看片日） | 看片 30 min + 洗澡 + 阅读 | 阅读可弃 |
| 周二 / 周四 / 周六（无训练） | **自由块 85 min** | **就是缓冲** |
| 周日（C 实战日） | 训练已放下午，晚上走自由块 | 有 |

**但账上很富裕——每天已有 3.5 h 以上「双收益」：**

| 时段 | 时长 | 同时兑现 |
|---|---|---|
| 晨间散步（第 3 周起） | 20 min | 光照锚 + 情绪 + 起床锚（不是燃脂） |
| **熟制（早上）** | 60 min | 厨艺 + 当日三餐 + 及时满足 |
| **预加工（晚上）** | 60 min | 备料 + 次日省时 + 及时满足 |
| 午间力量 | 60 min | 身体 + 下午状态 + 性能力（有氧 / 睾酮） |
| 睡前冥想 | 20 min | 情绪调节 + 入睡（直对 `8` 篇躯体化） |
| B 型日阅读 | 50 min | 兴趣 + 恢复 |

> **早晚两次做饭不是重复**：晚上是**预加工**（配面糊 / 肉分装 / 切菜 / 冷藏，产出备料），早上是**熟制**（腌制 / 裹油 / 煎 / 炒，产出当日三餐）。完整流程与可压缩处见 [[身心练习总纲]] §00 第五节。

一个动作、两个账户同时进账。**这不是时间不够，是把这些记成了"待兑现"**（`13` 第七节）。真正需要额外挤的，只有周二/四/六自由块里那几件——**挤不下就跳过，别去动冥想和睡眠**。

## 三、周期制：不按时刻排，按频率排

> 频率表见上方**执行表 B**。

85 分钟装 5 件事 = 每件 17 分钟 = 全部浅尝辄止，而且每天都欠账。所以事项按**周期**排、不按**时刻**排：每天只保留固定块（睡眠 / 散步 / 备餐 / 午间力量 / 冥想 / 凯格尔），把钢琴、游戏、性训练、社交这些降到「每周 N 次」，各自有落点即可。

> **自由块规则（再强调一次）**：**只在周二 / 周四 / 周六**，每次最多放两件（45 min 主 + 30 min 辅），从「钢琴 / 游戏」里选。**性训练已经升级成固定时刻（周一/三/五/日），不再从自由块里出**——这是本次重排里最实质的一个变化：它从"每周找时间做"变成"到点就做"。

## 四、白天换脑：把「理论课」搬进 8 小时

**本人观察**：长时间看代码很难保持专注，学一点别的东西恰好是**换脑**。

**这条成立，而且把晚间的压力卸掉了一大半：**

- 注意力是有限资源，**换脑不是偷懒，是恢复机制**——从"符号密集型"（代码）切到"结构 / 听觉型"（乐理、游戏机制），前额叶的不同子网络交替休息。
- 因此白天适合放**输入型 / 理论型**：乐理理论、游戏底层机制与连招原理、端侧 AI 的前沿论文；晚间只留**实操型**：弹琴、打游戏、性训练。
- 这条一旦成立，晚间的 75 分钟就从"理论 + 实操都要"变成"只有实操"，压力减半。

**边界（否则会变成新的焦虑源）：**

1. **只放在认知低谷与等待间隙**：午后 14:00–15:00、等编译 / 等构建、会议间隙。**不占用深度工作块。**
2. **当天产出不能受影响**——`0.生活构成` 写的是"工作 = 奉献与意义的载体"。换脑是为了让当天产出更好，不是替换产出。
3. **提前准备材料（关键）**：换脑那一刻人不会去找资料，只会刷手机。所以要在工位常备一份**换脑清单**——乐理 PDF、游戏机制文档、一篇论文。这与 `12` 第一节同构：**占用靠环境设计，不靠意志。**

## 五、性能力训练：先把「零占用项」捡起来

**本人观察**：性能力是对人生影响很大的一环，不能从日程里漏掉。

**先分清哪些需要额外时间、哪些根本不需要：**

| 项 | 时间成本 | 落点 |
|---|---|---|
| **有氧训练** | **已自动包含** | 午间力量里的有氧部分（不再单排晨跑） |
| **PC 肌 / 凯格尔** | **零占用** | 见下 |
| 脱敏 · 无幻想摩擦 | 需私密时间 | **固定：周一 / 周五 20:15**（A 摩擦日） |
| 无幻想对象看片 | 需私密时间 | **固定：周三 20:00**（B 看片日） |
| 玩具模拟 | 需私密时间 | **并入 A 摩擦日的器具排精 5 min**，周末可加长 |
| 实战 | 需整块时间 | **固定：周日下午 15:00**（C 实战日，可并行看片 + 摩擦） |

> **这四项已经全部从"自由块"里移出去了**，改成固定时刻。完整时刻与降级规则见 [[身心练习总纲]] §00 表二。

**凯格尔是这份清单里性价比最高的一项——它不需要排时间，只需要挂锚点：**

- **零占用**：通勤、久坐、刷牙、等电梯时均可做。
- 挂到已有锚点上（**每天 3 组**）：出门前（备餐后）1 组、午间力量收尾 1 组、通勤路上 1 组。
- **剂量**：慢肌组 = 收 5 s → 放 5 s ×10（约 100 s）；快肌组 = 收 1 s → 放 1 s ×10（约 20 s）。**每天 3 组慢肌 + 1 组快肌**，总收缩约 40 次。
- **收缩与放松要等长**——这一步最常被省掉，省掉会让盆底越练越紧（反而尿频、会阴痛）。总量也别贪：每天 30–50 次够了，"一天 100 次"式蛮练是盆底过紧的常见来源。
- 见效周期约 **8–12 周**（初期 3–5 s 保持即可，别一上来就 10 s）。
- 与 `13` 第七节"② 纯回血型"同构：**零占用、随时可做，是性价比最高的一档。**

#### 辨析：「凯格尔」有两种形态，别混（2026-10-16 澄清）

| | **本体版（零占用）** | **跟练版（要时间）** |
|---|---|---|
| 练什么 | **盆底肌（PC 肌 = 耻骨尾骨肌）本身的收缩—放松** | 臀桥 · 夹腿 · 深蹲 · 凯格尔球 |
| 形态 | 一个**看不出来的动作**，无体式、无器械 | 一整套跟练节目 / 器械 |
| 时间成本 | **不需要单独排** | 需要专门一段 |
| 为何存在 | 凯格尔本来就是这个 | 找不到盆底肌时的"外围激活"；或器械 / 生物反馈版 |

- **为什么会看到"腿部版"**：很多人本体感觉差、找不到盆底肌，教练就让做臀腿动作"顺带"激活盆底；短视频再把它拍成一整套跟练。它练的是**臀 / 大腿内收肌 / 核心**，**不是**凯格尔本体。
- 关键：**盆底肌是一个"看不见的动作"，不是一套腿训。** 反过来，如果做的时候腿和臀明显在发力，恰恰说明盆底肌没找到。

**唯一"要时间"的环节是定位——一次性，不是每天：**

- 找感觉：**憋尿感偏前（尿道外括约肌），提肛 / 憋屁感偏后（肛门外括约肌 + 耻骨直肠肌）。两个都是盆底，但凯格尔是"整片一起上提"，不是二选一。** 正确感觉像"整个会阴被吸上去"，而不是夹紧某一个点。**排尿中断法只用一次做定位，不要当训练**（会扰乱排尿反射）。
- **做得对不对，看三件事**：腿不动、臀不动、肚子不鼓，且**不屏气**（呼气时收缩更顺）。任何一处动了，就是把凯格尔做成了腿训。
- 定位成功后，剩下的全是挂锚点——所以它计入「零占用」档。

> **例外**：若平时有明显尿频 / 尿急 / 会阴痛 / 排便困难，盆底可能是**过紧（高张）型**——那需要的是**放松**而非加强，别盲目加量。

**一个被忽略的事实**：看片这件事**本来就会发生**——它属于及时满足的犒赏档。要做的是把它从"随机发生"改成"带训练目标地做"。**成本已经付了，只是没被计作训练。**

> 与 `13` 第二节接上：崩溃时的"快速推进关系"是**劣质燃料**；平常有节奏的推进属于关系层的**正常动作**。两者要在日程上占据清楚不同的位置，别混成一件事。

## 六、冥想 20 分钟：锚点在睡前，把 `8` 篇的应急技术预装成日常

> **⚠️ 2026-11-02 改判：锚点已从"睡前"挪到"起床后"。** 本节以下全部是 10-21 版的论证，**逻辑保留，位置作废**。
> 现行为：**起床后 20 min**（蒸饭日 5:35 / 炒饭日 6:53）；晚上的降速由 **断电子 30 min** 承担。完整规则见 [[身心练习总纲]] §00 第四节。
> 改判原因只有一条：**加班日 21:00 下班、22:20 躺，中间 50 min 是通勤 + 冲凉 + 忍三，物理上排不进 20 min。**
>
> **2026-10-21 改口径**：原写"到公司后 10 min"。后改为 **睡前 21:40–22:00、20 min**，早上只留 1 min 落座检查。理由与完整执行细节见 [[身心练习总纲]] 第四节 + 第六节改动 4。

- **它不是"心法"，是直接作用在自主神经上的工具。** `8` 篇里诊断的躯体化（咽喉 / 食管 / 贲门的平滑肌痉挛）本质是**交感兴奋找不到出口**——前额叶（CEO）能定对错，却无权命令底层神经立刻服从。冥想走的正是这条底层通道：**加长呼气 → 迷走张力上升 → 副交感启动**。
- `8` 篇的现场对策里已经写着"肩膀下沉、下巴放松、柔吸气、加长呼气"——**那本身就是微冥想**。区别只在：把这项技术从"应激时临时调用"改成"**每天预装**"。应激那一刻人是调不出来的，能调出来只因为平时装好了。
- **为什么从早上挪到睡前**：早晨的"启动"已经由散步 + 户外光照完成，不需要再叠一次；而入睡是当前最硬的短板（23:40 → 22:00），睡前的 20 min 直接作用在这一项上。**降交感有半衰期，做完隔 40 min 再睡就泄掉一半**——所以它必须是当天最后一件，不是倒数第二件。
- **位置**：**21:40–22:00，三种训练日共用，不浮动。** 一个每天都要重新决策的动作长不成习惯；21:40 要变成不需要想的数字。
- **早上（1 min）**：到工位后三次生理叹息 + 肩沉下巴松 + 坐姿自检（肋骨下缘到骨盆 ≥ 4 指）。这是入场仪式，不是冥想训练。

**判据（不要用"有没有杂念"）：**

> 杂念出现是正常的，与做得好不好无关。唯一要看的指标是——**结束时肩膀和下巴是不是松的，有没有开始打哈欠。**

- 落点：**不是"坐得清净"，是"松下来了"。** 与 `8` 篇的预期管理一致：目标不是没有念头，是不被它接管。
- 打哈欠 / 眼皮沉 = 剂量够了，**直接躺下睡**，不用做满 20 min。

> 具体做什么（20 min 分段 + 三个选项选一个固定用）＋ 呼吸节奏 ＋ 坐姿：见 [[身心练习总纲]] 第四节。它同时处理 `8` 篇的躯体化（支路 B）和胃酸反流（支路 A），两边管的东西不一样，不能互相替代。
