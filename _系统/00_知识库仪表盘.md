# 知识库仪表盘

> [!info] 本页用途
> 用 Dataview 把全库当成一张数据库来查：**待整理清单 / 复习面板 / 项目看板 / 统计 / 孤立笔记**。
> 判读规则：`status: 空壳` = 待写种子；`mastery` 越低越该复习。

## 1. 待整理清单（空壳 = 待写种子）

```dataview
TABLE up AS 上级, file.folder AS 所在分区, created AS 建立
FROM ""
WHERE status = "空壳"
SORT file.folder ASC, file.name ASC
```

## 2. 复习面板（按熟练度升序）

```dataview
TABLE mastery AS 熟练度, file.folder AS 分区, updated AS 更新
FROM ""
WHERE mastery >= 0
SORT mastery ASC, updated ASC
LIMIT 40
```

## 3. 项目看板

```dataview
TABLE rows.file.link AS 笔记, rows.status AS 状态, rows.updated AS 更新
FROM "2.项目"
GROUP BY project AS 项目
```

## 4. 全库统计（按 type）

```dataview
TABLE WITHOUT ID type AS 类型, length(rows) AS 数量
FROM ""
WHERE type != null
GROUP BY type
SORT length(rows) DESC
```

## 5. 最近更新

```dataview
TABLE status AS 状态, file.folder AS 分区, updated AS 更新
FROM ""
WHERE file.name != this.file.name AND updated != null
SORT updated DESC
LIMIT 15
```

## 6. 孤立笔记（没有任何反向链接）

```dataview
LIST
FROM ""
WHERE length(file.inlinks) = 0 AND file.name != this.file.name
SORT file.folder ASC
```
