# 烹饪探索

## 📅2026-09-23

## 前置知识

**食物美味：**
1. 脂溶性香气分子没有油来溶解储存，加热时就挥发散失到空气里，吃到嘴里就感受不到； 
2. 好吃 = 舌的基础味觉 + **鼻后嗅觉的风味** + 口腔触觉（口感）；嗅觉是风味的核心； 
3. 口感不只由自由水决定，蛋白质、淀粉果胶结构、油脂、孔隙、纤维、渗透压都会共同作用。




## 📅2026-10-08

## 全麦卷饼

食材:
1. 240g全麦面粉
2. 2个鸡蛋
3. 360g水
4. 0.8g含碘盐

制作方法：
1. 上述食材搅拌成“黑芝麻糊”的粘稠度--搅匀，静置15min消泡进行摊饼
2. 锅里喷一圈油，开中大火
3. 面糊倒锅里，快速转成薄饼
4. 煎2min，面皮变色进行翻面
5. 之后鼓包进行翻面，两面都有鼓包就是熟了




## 牛羊肉处理

- 选**纯瘦羊腿肉，剔除所有白色肥肉、筋膜**（肥肉会增加多余脂肪，冷藏后腥味更明显）
- 一天摄入280g

1. 切片：切成约 3~4mm 薄片，大小适合卷饼；全部 280g 一次性切好。
2. 腌制（极简，控钠！不要再额外加盐） 只用少量黑胡椒碎即可，**不要再放生抽、蚝油、酱料**（会造成钠超标，影响睡眠），抓拌均匀，静置 10 分钟--我使用黑胡椒海盐进行腌制，下调卷饼中的含盐量
3. 煎制：平底锅小火，不放油（饼皮已经刷橄榄油），分批放入羊肉片，快速翻炒至**完全变色、无血水，八分熟即可**（第二天微波会二次加热，避免肉变老柴）。
4. 放凉 + 分份：全部煎好后摊开彻底放凉（**热肉直接装盒会出水、变质**），平均分成 3 份，装保鲜小盒。


## 蔬菜用量与处理

蔬菜总量推荐区间**300～500g / 天**

1. **菠菜**：沸水焯 30s → 捞出，用力挤干水分（去除草酸，防止影响矿物质吸收，同时避免出水泡烂饼皮），切段；用来预制卷饼。
2. **彩椒**：沸水焯 60s 即可，不要久煮，捞出沥干。（原方案是干炒，焯水替代完全可行，口感会更软一点，不影响营养），预制卷饼。
3. **油麦菜**：**不建议提前焯水**。
    - 如果提前焯水：油麦菜会发黄、软烂，维 C 大量流失，冷藏后口感很差。
    - ✅最优方案：油麦菜**生吃**，洗净沥干，单独分装；吃的时候直接加到卷饼。
    - 如果你肠胃弱，一定要烫：吃之前用开水快速烫 10 秒，马上捞出沥干，不要提前预制。



## 其余每日营养补充

- 30g每日坚果
- 200g无糖酸奶


- 卷饼上刷初榨橄榄油（3 x 5g）
- 卷饼上添加芝士（3 x 10g）



**上述卷饼，食用前使用空气炸锅或者微波炉加热**

## 饮食构成

卷饼：
- 全麦面粉：200g
- 水：300g
- 加碘盐：2g
- 鸡蛋：2个
- 蔬菜：100g
- 卷饼煎制结束：加入30g芝士碎、5g初榨橄榄油

牛/羊肉处理：
- 生肉净含量：150g左右
**处理步骤：**
1. 鲜肉买回家，冷冻60min
2. 水平切两三刀--横向切多刀--竖向切多刀（确保最后是足够小的丁）
3. 2g含碘盐腌制8min
4. 煎炒40s左右

- 不含钠每日坚果：30g
- 带皮苹果：1个
- 兰格格低脂酸奶 360g

- 500g蔬菜--早晚餐各250g，用水蒸







**替换餐：**
- 每周抽出两天将肉类替换为深海鱼（秋刀鱼 / 三文鱼 / 沙丁鱼、虾肉，300g 生重）


其余辅助：
- 补充维生素D：户外日晒，每周 3 次，每次 15–20 分钟手臂面部暴露
