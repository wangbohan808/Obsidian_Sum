# 三测窗口与起号路径

> **一句话核心：这不是"如何成为优秀 UP 主"的长期课题，而是一次有截止日期的信息差窗口——准备已经做完了（定位、链路、时间账、护城河都在库里），真正缺的只有「发布」。**

> 缘起：2026-11-10 拿到《异人之下》终局测试资格，提出在 B 站直播 + 做视频，自述"以前没有 UP 主经验"。
> 事实基线：终局测试 11-04 开服，结束时间另行通知；**12 月正式上线**；官方答疑明确"可以对测试内容直播、录屏、截图并发布到社交平台，不作严格限制"，但对**拆包、盗用、刻意抹黑、不当使用**保留追责权利；测试内容不代表最终品质。

## 零、结论先摆

| # | 判断 | 性质 |
|---|---|---|
| 1 | **缺的不是经验，是第一条已发布的稿件。**设备、链路、定位、时间账四件事在 [[01_设置项探勘表]] / [[02_直播推流术语与链路]] / [[31.直播副业·时间账、切片飞轮与平台门槛]] 里已经齐了 | 核心改判 |
| 2 | 三测流量本身不值钱，**值钱的是给 12 月公测做一次带真实数据的彩排**（账号标签 + 素材库存 + 闭环跑通） | 定位 |
| 3 | "直播 + 做视频"不是两条产线。**切片是直播的副产品**，另起一条正片产线是这次最大的超载风险 | 判断分歧 |
| 4 | 护城河仍是 31 号定的那条：讲**链路**不讲感觉（输入延迟 / 帧率 / 采集 / 同步）；别人凭体感，你给数值 | 沿用 |
| 5 | 新号数据**看斜率不看单条**。前 10 条单条涨跌是噪声，7 条滚动一次 | 口径 |
| 6 | 前 4 周的数据是**链路健康度**，不是成绩单 | 边界 |

## 一、窗口：现在处在哪个位置

| 时点 | 状态 | 该做什么 |
|---|---|---|
| 11-04 | 终局测试开服，首发资讯红利 | 已过（今天 11-10，第 7 天） |
| **11-10 → 测试结束** | 有资格的人少、全角色开放、玩家在搜设置/连招/角色；**搜索需求 > 推荐需求** | 埋搜索词、攒素材、打账号标签 |
| **12 月公测前后 24–48h** | 外生的搜索量脉冲，全周期最大 | 用三测攒的经验与库存接这一波 |

**推论：现在追单条爆款是错配。** 三测期该交付的三样东西是——① 系统认识这个号是"异人之下 / 格斗技术"垂类；② 有一批可复用的素材与选题；③ 跑通「播→剪→发→记→改」的闭环，公测时不用现学。

> 开播前再看一眼游戏内公告与官方最新答疑，确认传播口径未收紧；内容里标注"终局测试版本，不代表正式品质"。

## 二、最短闭环（唯一要做的一条流水线）

```
单机开播（不等采集卡） → 每场留 1–2 条切片 → 标题埋搜索词发布 → 记 5 个数 → 改下一场
```

| 这次**做** | 这次**不做** |
|---|---|
| 单机 OBS 直接开播 | 等双机 / 采集卡到位才开播 |
| 剪映粗剪 + 自动字幕 | 学转场、特效、调色 |
| 切片从直播里出 | 另起"正片"选题会 |
| 记数据表 | 盯收入、盯粉丝数 |

理由：[[02_直播推流术语与链路]] 里的双机方案是**画质与稳定性的上限**，不是开播的前置条件。B 站实名即可开播，当晚就能播；把工程能力用在**发布之后**的自动化（批量切片、数据抓取），而不是发布之前。

## 三、内容：把已有技术资产变成选题

判据只有一条：**同一件事，别人凭感觉讲，你能给数值或链路。**

| 选题 | 出处 | 为什么别人做不了 |
|---|---|---|
| 为什么同样的连招你打得出我打不出——输入延迟拆成四段 | [[01_设置项探勘表]] §零 | 主播只能归因为"手速" |
| 锁 45 帧反而比 60 帧顺：编码器按固定间隔取帧 | [[02_直播推流术语与链路]] §2 | 反直觉，且有工程解释 |
| 画面卡 / 糊 / 灰，是三个完全不同的故障 | 02 §5 | 现成的三档排查口诀 |
| 判定框 / 帧数显示 / 输入记录有没有，决定能不能做帧数据 | 01 §六 | 直接把"技术型 UP 主"这条线立住 |
| 设置项逐条按"延迟 / 信息量 / 判定一致性"三判据过一遍 | 01 §零–五 | 玩家现在正在搜这个 |

**不要打"技术最强"**（31 号已否）：职业格斗高手太多，正面撞必输。

## 四、流量数据：只记 5 个数

| 指标 | 口径 | 掉在哪里 | 对应动作 |
|---|---|---|---|
| 点击率 CTR | 曝光 → 点击 | 封面 / 标题 | 换封面，标题埋玩家会搜的词 |
| 前 5 秒留存 | 0–5s 流失 | 开头钩子 | 把结果或冲突放前 2 秒，删开场白 |
| 完播率 | 平均播放进度 | 中段结构 | 砍等待画面，每 2–3 分钟一个小钩子 |
| 收藏率 | 收藏 / 播放 | 价值密度 | 给可回查的东西（设置清单、帧数据表） |
| 涨粉 / 播放 | 每千播放涨粉 | 定位清晰度 | 低＝观众看完不知道你是谁，收窄垂类 |

**归接口径**：与体重一样用**滚动均值**（7 条一滚），单条爆或不爆都不改判断；判据是"这次失败里我能改的变量有几个"。

| 发布侧 | 做法 |
|---|---|
| 时段 | 游戏区约 19:30；周二 / 四 18–19 点竞争更小，适合冷启动测试 |
| 标签 | 2–3 个：一个大标签（游戏区）+ 一个小标签（游戏名 / 具体玩法） |
| 标题 | 埋玩家会搜的词（游戏名 + 设置 / 连招 / 角色名），**不要文艺标题** |
| 红线 | 同类型内容高频日更会被降权（2026 算法）；稿件改动别超 2 次；不刷量（同 IP 连坐） |

> 2026-04 起 B 站换 AI 推荐系统，新号有约 7–14 天冷启扶持期，期间**持续更新**更容易被判为活跃创作者；收藏 / 评论权重高于点赞。以上为业内公开口径，非平台官方文档，按"假设"用，用自己的数据验。

## 五、收入预期（诚实口径）

| 项 | 现实 |
|---|---|
| 创作激励门槛 | 实名 + 等级/电磁力 + 1000 粉 **或** 累计 10 万播放 |
| 游戏区万播放 | 约 8–15 元；基础激励月封顶 2000 |
| 花火商单 | 1 万粉才入驻 |

**结论：这轮不谈钱。** 31 号已算过，"一次较大报酬"的门票是**一条起量的切片**，不是时长；而三测的作用是把拿到这张票的概率提高。

## 六、与 31 号的分工与红线

| | 31 号 | 本篇 |
|---|---|---|
| 回答 | 长期副业的**时间账**（月 90h / 周日 6h 发动机 / 睡眠不动） | 测试期的**窗口账**（截止日期 / 搜索红利 / 闭环彩排） |

**不冲突，别互相覆盖。** 三条红线原样保留：

1. **睡眠时刻不动**（22:20 / 21:30），直播黄金段 20–24 点这个亏要吃。
2. **前期设备投入 0**，等第一笔收入再买。
3. **允许某天只玩不播，不补录、不记账**——燃料一旦变成任务就不再是燃料。本篇所有"该做什么"都不得升级成这条的例外。

## 七、ID 与命名分层（2026-11-10 定）

| 层 | 名字 | 职责 | 生命周期 |
|---|---|---|---|
| B站 昵称 | **地球online808**（保持不动） | 跨项目身份资产 | 年级 |
| 合集 / 标题前缀 | `地球online · 异人界服`（候选）· `【异人之下】…`（前缀） | 垂类识别 + 搜索词 | 跟版本，**待定** |
| 游戏内 ID | **B站地球online808** | 结算画面里的指路水印 | 跟测试期 |

**判断口径：主 ID 不带游戏名。** 见 [[24.地球online·高玩是方案，主导权才是目的]]——"地球online"值钱在它指**整局游戏**而不是某一块板；把具体游戏焊进主 ID＝让游戏给自己发身份，是 §三陷阱 1「评价权外置」换了马甲。"分区授权"的正确落地是**主 ID 管整局、具体那块板用子标识**。

**一次改判（本人 2026-11-10）：游戏 ID 从「玩梗」改为「指路」。** 原提 `炁走链路` 一类梗名，要有工夫琢磨才有味，而格斗游戏结算画面只闪一下；`B站 + 可搜的 ID` 是直接可转化的信息，目标函数比原方案对。带全名"异人之下"的诉求则由**标题前缀**承担（玩家搜的是这四个字），不占栏目名。

### 三个风险

| # | 风险 | 处置 |
|---|---|---|
| 1 | `B站地球online808` 约 13 个字符；旧作《一人之下》昵称限 7 字 + 改名卡，本作自定房间名也是 7 字，**本作昵称上限未查到官方口径** | 进游戏看输入框实测；放不下走第 3 条补丁。**不要删 808**——它是 B站 唯一搜索线索，删了搜不到 |
| 2 | 昵称前置外部平台名，可能被审核判为"导流信息" | 被拦则退回 `地球online808` / `地球OL808`，指路交给水印 |
| 3 | 游戏 ID 是**平台受限字段**，水印是**自己可控字段** | **OBS 加常驻文字源**（右下角 `B站 @地球online808`）：长度不受限、每帧都在、切片自动带上 |

**第 3 条是真正的解法**：把"指路"从受限字段搬到可控层，游戏 ID 退回短名也不损失任何引流效果。

### 开播前手动确认（4 步）

1. 游戏内打开取名 / 改名界面 → 看输入框能打几个字符、是否提示需改名卡。
2. 试填 `B站地球online808` → 观察是否被长度截断或判敏感词；把实际结果回填本节。
3. B站站内搜 `地球online808` → 确认唯一、能被精确搜到（唯一制 + 改名冷却，主 ID 不试错）。
4. OBS 加一个文字源，录 10 秒回放 → 确认切片里水印清晰、不挡血条与技能 CD。
