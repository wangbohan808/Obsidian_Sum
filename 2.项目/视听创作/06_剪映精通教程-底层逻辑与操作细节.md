# 剪映专业版 · 精通教程（底层逻辑 / 操作细节 / 帧率原理）

> **一句话核心：剪映看着"傻瓜"，底下是标准 NLE 模型——剪辑只做四件事（时间、空间、外观、声音），时间轴存的永远是"引用 + 参数"；吃透这两句，界面上每个按钮都会自动归位。**

> **定位**：工具层·操作手册（与 [[01_Logic Pro 功能全图与上手路径]] 对称——那篇是声音的"信号汇流"，本篇是画面的"引用 + 参数"）。
> **来源**：WorkBuddy 分享页《剪映软件使用教程》（两轮对话：总览 + 滤镜/蒙版/调色/关键帧/帧率深挖），2026-11-16 抓取整理，图示已导出至 `Assets/剪映教程/`。
> **读法**：第一～五节是**模型**（为什么要这样），第六节是**本质**（四个易混功能到底在动什么），第七节是**物理**（帧率），第八～十节是**手册**（查）；第十一节是练法。

## 一、底层模型：剪辑只做四件事

最重要的一句：**剪辑不修改素材文件**。时间轴里存的不是视频，而是"引用 + 参数"。删片段不会删视频，复制片段不会复制数据——这就是"非线性编辑（Non-Linear）"这个词的全部含义。

![[Assets/剪映教程/01_片段四维参数模型.svg]]

| 维度 | 具体旋钮 | 典型用途 |
|---|---|---|
| **时间** | 入点/出点、速度、倒放、定格 | 砍废话、变速卡点、抽帧做封面 |
| **空间** | 位置、缩放、旋转、裁剪、镜像、锚点 | 数字变焦（推拉）、画中画、左右翻转 |
| **外观** | 亮度/对比/饱和度、HSL、曲线、色轮、LUT、混合模式、蒙版、抠像、特效 | 统一影调、绿幕合成、遮挡、氛围 |
| **声音** | 音量、关键帧包络、淡入淡出、降噪、变声、闪避 | 人声压 BGM、环境声铺底 |

**判据**：任何想实现的效果，先问"它属于四维中的哪一个"。问得出来，就能在面板里找到它；问不出来，说明需求还没拆清楚。

> 这条判据与 §十一 的"精通三判据"第一条是同一件事——**会不会定位，就是入门与熟练的分界**。

## 二、两套时间坐标 —— 90% 新手坑的根源

每个片段同时活在两个时间里，这是所有 NLE 最反直觉的地方。

![[Assets/剪映教程/02_片段参数解剖.svg]]

```
放置长度(target) = 源长度(source) ÷ 速度(speed)
```

于是所有"灵异现象"都能解释：

- **变速后音频变调** → 音频跟着 `source_timerange` 重采样，抽/补样导致音高变化；要"变速不变调"须单独勾选。
- **变速后音画不同步** → 你只改了视频轨的 `speed`，音频轨还是原速。正确做法：同一素材的**视频 + 音频一起选中**再变速。
- **素材看起来"变短了"** → 不是素材坏了，是 `target_timerange` 被重算。

**第二套时间：帧与时间码。** 时间轴有固定帧率（24/25/30/50/60，在「草稿参数」改），所有操作最终对齐到整帧。时间码 `HH:MM:SS:FF`，`00:00:10:12` = 10 秒 12 帧。

**高频坑**：25fps 素材放到 30fps 时间轴，系统必须补帧或丢帧，快速横移会顿挫 → 详见 §七。

## 三、渲染原理：预览和导出是两条完全不同的管线

![[Assets/剪映教程/03_渲染管线四阶段.svg]]

四阶段：**解码 → 变换与调色 → 合成（蒙版/混合/透明度）→ 编码输出**。预览是"实时低分辨率算一遍"，导出是"全分辨率逐帧算一遍"——所以两者故障表现完全不同。

| 现象 | 真实原因 | 处理 |
|---|---|---|
| 预览卡，导出正常 | 预览是实时算的，你让它 1/30 秒内做完四阶段 | 开代理、降预览分辨率、关"高质量预览" |
| 预览流畅，导出花屏/黑帧 | 编码器或显卡驱动问题 | 换编码（H.265→H.264）、关硬件加速编码 |
| 越编越卡 | 缓存碎片 + 特效层数累积 | 清缓存；复杂片段先导出中间文件再导回 |
| 单个片段卡死 | 智能抠像 / 光流补帧是逐帧 AI 推理 | 局部预渲染，或降低该段分辨率 |

**烘焙（bake）/ 预合成**是所有 NLE 的通用降载手法：把"每帧都要重算的复杂效果"固化成"每帧只需解码的普通视频"。同一条思路能救 90% 的卡顿。

**推论**：卡顿先判断在哪一段管线，再动手。判断不出来，加内存、换电脑都是白花钱。

## 四、图层即合成顺序

![[Assets/剪映教程/04_轨道图层合成模型.svg]]

**三条铁律：**

1. **主轨（V1）是"磁性"的**——不能留空隙，前面片段一删，后面自动前移。副轨（画中画）自由摆放，可重叠、可留空。主轨就是片子的"时间骨架"。
2. **画中画不会自动缩成小窗**——默认铺满全屏，缩放得自己做。新手经典困惑"主轨不见了"，其实是被完全盖住。
3. **音频没有图层概念**——两条音轨同放是**相加**，不会覆盖。A1/A2 打架时唯一解是调音量或用闪避。

**复合片段 `Ctrl+G` = 嵌套序列**：N 个片段折叠成 1 个，内部有自己的时间轴。好处：整体移动、整体加特效；代价：外层看到的时长被锁死，改内容要双击进去。这是长片的分块手段。

## 五、关键帧 = 参数的时间函数

![[Assets/剪映教程/05_关键帧插值曲线.svg]]

逻辑只有一句：**给某个参数在某个时刻拍一张快照，软件负责在快照之间补出中间值。** 凡是能拖的参数（位置、缩放、旋转、不透明度、音量、滤镜强度、蒙版位置）都能打关键帧；打不上，通常只是该参数没展开或没选中片段。

| 套路 | 打几个关键帧 | 效果 |
|---|---|---|
| 数字推拉（Ken Burns） | 首帧 100% → 尾帧 115% | 静态图有呼吸感，纪录片常用 |
| 淡入淡出 | 0% → 100% / 100% → 0% | 比转场更高级的入场 |
| 甩镜转场 | 位置 + 运动模糊 | 位移量够大才有速度感 |
| 音量爬升 | −20dB → 0dB | 铺垫情绪，避免 BGM 突然砸进来 |

## 六、三维正交框架：滤镜 / 蒙版 / 调色 / 关键帧

**这四个不是并列的四种效果，而是三个互相垂直的维度 + 一个时间轴。**

![[Assets/剪映教程/06_滤镜蒙版调色关键帧的三维正交框架.svg]]

分工一句话：**蒙版管"哪里"，调色管"变成什么"，滤镜管"整体调性"，关键帧管"什么时候"。**

### 6.1 调色的本质：逐像素的数值映射

调色不是"调好看"，是**把输入像素值按某个函数映射成输出像素值**。所有滑杆都只是"预设好形状的曲线开了个参数口"：

| 滑杆 | 数学本质 | 说人话 |
|---|---|---|
| 亮度 / 光感 | 整体加常数 `y = x + b` | 整条曲线上抬 |
| 对比度 | 绕中灰改斜率 `y = a(x−0.5)+0.5` | 亮的更亮、暗的更暗 |
| 高光 / 阴影 | 只移动曲线两端的弯钩 | 救回死白和死黑 |
| 色温 / 色调 | R、B 通道的独立增益 | 白平衡，不是"加个滤镜" |
| 饱和度 | 颜色向灰度轴靠拢或远离 | 让颜色"喊"或"悄悄话" |
| 曲线 | 任意单调映射（RGB 或单通道） | 最强入口，其余滑杆都是它的特例 |

**为什么曲线最高级？** 滑杆是"固定形状曲线 + 一个参数"，曲线是让你直接画那条线。想只提亮暗部又不碰亮部，在曲线上抬左下段即可——滑杆做不到。

专业调色**分三层打，顺序不可逆**：

![[Assets/剪映教程/07_调色三层结构.svg]]

**为什么顺序不能换？** 风格化（LUT、色轮）是"在已有影调上叠加的固定映射"。素材本身偏黄、过曝时先套 LUT，LUT 的输入假设已被破坏，输出必然脏、断层。**先救回中性，风格才站得住**——和化妆先打底再上色同理。

### 6.2 滤镜的本质：打包好的调色 + 一个混合比例

滤镜不是另一类东西，**它就是调色的预设包**。内部做的是：读像素 → 按预设曲线/LUT 映射 → 输出。

```
强度 k：结果 = 原图 × (1−k) + 滤镜结果 × k      （50% 时即各半）
```

**「强度滑杆」的真实含义是一根线性混合（lerp）推子**，不是"效果轻重"的抽象概念：0% 等于没加，100% 等于全量，中间值是数学插值。

| 结论 | 原因 |
|---|---|
| 滤镜可叠加，但**结果不可预测** | 两次非线性映射串联，后一个的输入分布已被前一个改变 |
| 同一滤镜在不同素材上**效果差很多** | 固定映射，不看你素材的实际曝光 |
| 滤镜与调节**打架时优先用调节** | 调节连续可控，滤镜是离散预设 |

**滤镜的真正价值在效率**：把十几步调色压缩成一次点击 + 一个强度值。适合批量统一风格、快速出片，**不适合精修**。

### 6.3 蒙版的本质：一张权重图

蒙版不是裁剪工具。**裁剪把像素丢掉，蒙版只改透明度**——像素一直都在，关掉蒙版即可恢复。

![[Assets/剪映教程/08_蒙版的权重图本质.svg]]

四个常见疑问一次说清：

1. **羽化调大为什么"糊"？** 你把中间灰阶带宽拉宽了，那块变成半透明，底下图层透上来——这是**混合**，不是模糊。
2. **边缘为什么有锯齿？** 羽化 0 时权重从 255 直接跳 0，是硬边；给 10–30 就有过渡。
3. **为什么能挡住却"移不动"下面？** 权重 0 的区域只是不参与合成，下面的轨道照样存在。
4. **一个片段为什么只能挂一个蒙版？** 因为一个片段只有一张权重图。要多层蒙版：**复制一层轨道**或**做复合片段**，每层各挂一个。

**六大使用场景**（按频率排）：

| 场景 | 做法 | 关键点 |
|---|---|---|
| 局部提亮/压暗 | 圆形或线性蒙版圈人脸/天空 | 羽化给到 30–80，否则像贴了块膏药 |
| 分屏 / 双人对话 | 线性蒙版 + 反转，两轨各一半 | 过渡带上羽化，避免硬接缝 |
| 遮挡穿帮 | 矩形蒙版盖 Logo、路人、字幕残留 | 蒙版位置要打关键帧跟着走 |
| 无痕转场 | 线性蒙版横扫 + 位置关键帧 | 比转场插件自然，可反向 |
| 风格化画框 | 星形/爱心蒙版做聚焦 | 配合背景虚化 |
| 只给天空调色 | 蒙版圈天 + 调色 | 天空会动时必须跟踪或补帧 |

### 6.4 关键帧的本质：把参数写成时间函数

四者里只有关键帧**不改变画面、只改变时间**——它本身不产生效果，作用是"接管某个参数的控制权"。

```
参数值(t) = 在关键帧 A 与 B 之间，按插值曲线求值
```

所以关键帧不是"打点"，而是**你在声明：这个参数从这一刻起不再是常数**。

| 插值方式 | 手感 | 适用 |
|---|---|---|
| 线性（Line） | 匀速、机械、生硬 | 字幕滚动、机械运动、需要精确等速 |
| 缓入缓出（贝塞尔） | 起步慢、中段快、收尾稳 | 90% 的镜头运动、缩放推拉 |
| 单边缓入 / 缓出 | 突然启动后滑停 / 慢慢启动后急停 | 甩镜、撞击、强调 |

**新手最常犯的错**：只打头尾两帧，然后说"怎么这么假"。真实世界的运动从不匀速，**加一个缓动，观感立刻翻倍**——投入产出比最高的一个操作。

**三条纪律：**

1. **先定位光标，再改参数**。剪映是"光标在哪，关键帧就打在哪个时刻"。参数改了却没打上帧，说明你改的是常数，不是动画。
2. **越少越好，但间隙不能有"意外"**。两帧之间出现不该有的位移（绕路、抖一下），补一个中间帧压住。
3. **两帧之间的插值方式由起点关键帧决定**。想改手感，选起点那一帧。

### 6.5 四者配合：一个真实案例

**需求：街拍视频里让天空变蓝，镜头还在轻微摇动。**

| 步骤 | 用到谁 | 动作 |
|---|---|---|
| 1 | 调色·一级 | 曝光、白平衡先把画面拉回中性 |
| 2 | 蒙版·空间 | 线性蒙版圈出天空，羽化 40 |
| 3 | 调色·二级 | HSL 选蓝色，饱和度 +30、明度 −10 |
| 4 | 关键帧·时间 | 镜头在摇 → 给蒙版「位置」打 3–5 个关键帧跟着天走 |
| 5 | 滤镜·数值 | 套轻微胶片 LUT，强度 25%，统一整体影调 |
| 6 | 关键帧·时间 | 想"逐渐变蓝" → 给 HSL 饱和度打两个关键帧 |

一次调色任务，四者全用上且分工不重叠——这就是那张三维图的实际运转。

## 七、帧率的本质：一个网格，一个信号

> **素材帧率是被记录的"样本密度"，时间轴帧率是工程的"时间网格"。**

- **素材帧率 24fps** = 相机每秒拍 24 张。**客观事实**，写死在文件里，改不了（改了就是重新编码）。
- **时间轴帧率 30fps** = 工程把 1 秒切成 30 格。**你的选择**，所有位置、时长、关键帧都要落在格子上。

比喻：**素材帧率是原始照片的张数，时间轴帧率是相册里的格子数。** 照片不够，格子只能重复贴；照片太多，装不下就扔掉。

结论：两者不同时必然发生**重采样（resampling）**，而重采样只有两种手段——**复制或丢弃**。

![[Assets/剪映教程/09_二十四帧素材落到三十帧时间轴.svg]]

**读图**：上面 12 个蓝点是素材真实存在的画面，下面 15 格是时间轴；多出的 3 格只能拿相邻帧填，填进去的那帧**与前一帧完全一样、没有任何新信息**。人眼对"一帧没动、下一帧突然跳"极敏感，读出来就是**顿挫（judder）**。

### 7.1 四种不同步的后果

| 情况 | 采样比 | 后果 | 严重度 |
|---|---|---|---|
| 素材**低于**时间轴（24→30） | 1.25 | 每秒补 6 帧 → judder，横移最明显 | 中，肉眼可辨 |
| 素材**远低于**（24→60） | 2.5 | 60% 帧是重复，明显卡顿 | 重，不可接受 |
| 素材**高于**（60→30） | 0.5 | 每 2 帧丢 1，观感正常（运动模糊还在） | 轻，多数看不出 |
| 素材**远高于**（120→30） | 0.25 | 播放没感觉，但**浪费 3/4 素材** | 隐性损失 |

```
采样比 = 时间轴帧率 ÷ 素材帧率
采样比 > 1  →  一定有复制帧（顿挫风险）
采样比 ≤ 1  →  只丢帧不复制（观感安全，但可能浪费素材）
```

### 7.2 最值钱的推论：慢动作的流畅度是"拍"出来的

```
能无损慢放的最大倍数 = 拍摄帧率 ÷ 时间轴帧率
```

以时间轴 30fps 为例：

| 拍摄帧率 | 最大无损慢放 | 超过会怎样 |
|---|---|---|
| 30fps | 1 倍（不能慢） | 0.25× 每帧重复 4 次，卡成 PPT |
| 60fps | 2 倍 | 0.25× 每帧重复 2 次，开始顿 |
| 120fps | 4 倍 | 0.25× 恰好 1:1，丝滑 |
| 240fps | 8 倍 | 0.125× 依然丝滑 |

**"我的慢动作为什么卡"的答案永远是：拍的时候帧率不够。** 后期变速只是把时间拉长，拉长不产生新画面。智能补帧/光流法是在"猜"中间帧——能救，但有果冻和边缘撕裂，别无选择时才用。

### 7.3 四个更隐蔽的坑

1. **VFR（可变帧率）素材——手机录屏的头号杀手**
   录屏、部分手机拍摄、直播回放帧间隔不均匀，剪映按恒定帧率理解它 → **时长漂移、音画不同步、越到后面差得越多**。
   *判断*：导入后对比时长与原文件，拖到结尾听声音是否还对得上。*解决*：先转 CFR 再导入。

2. **关键帧会被吸附到整帧——与第六节直接咬合**
   30fps 工程里第 15.5 帧不存在，每个关键帧都会被吸到整帧上。所以：30fps 下做 0.2 秒位移只有 6 帧可用，动作必然"跳格"；要细腻的快速动画必须用 50/60fps 工程。
   **这就是两个问题的接点**：关键帧是时间函数，时间轴帧率是这个函数的采样精度。**网格越密，动画越细。**

3. **改帧率会牵动音频对齐**
   音频是 48kHz 连续采样，完全不受帧率影响。工程从 30 改 25，画面网格变了、音频没变，落在非整帧位置的关键帧/变速点/标记被重新吸附 → **音画差几帧**。改完必须重过一遍同步点。

4. **24fps 的"电影感"不是玄学，是运动模糊**
   24fps 配 1/48s 左右快门，快速运动产生**自然拖影**，人眼读成流畅；60fps 快门更短、每帧锐利，反而"像家庭录像/游戏画面"。
   - 要电影感 → 24/25fps + 适当运动模糊
   - 要"真实清晰" → 50/60fps（体育、游戏、屏幕演示）
   - **拍摄端铁律**：快门 ≈ 1 ÷ (2 × 帧率)——25fps 用 1/50s，60fps 用 1/120s。这条错了，后期怎么调都救不回来。

### 7.4 帧率决策表

| 内容类型 | 时间轴 | 导出 | 理由 |
|---|---|---|---|
| 剧情 / 纪实 / 氛围向 | 24 或 25 | 同时间轴 | 电影感，运动模糊自然 |
| 口播 / 知识 / 带货 | 30 | 30 | 平台主流、体积小、兼容最好 |
| 运动 / 游戏 / 屏幕录制 | 50 或 60 | 同时间轴 | 快动作不糊，录屏文字更锐 |
| 需要升格慢动作 | 30（配 120 素材） | 30 | 留出 4 倍无损慢放空间 |
| 平台硬性要求 | 按平台 | 按平台 | 抖音/视频号多接受 30 或 60 |

**只记一句：时间轴帧率 = 最终交付帧率，中途不要改。导出帧率与时间轴不一致，等于白做一次重采样。**

### 7.5 收口：两张图其实是一张

- 上半场（§六）：关键帧把参数写成时间函数 `P(t)`
- 下半场（§七）：时间轴帧率决定 `P(t)` 每秒被采样多少次

所以"动画不细腻""动作跳格""慢动作卡顿"是同一个问题——**函数的采样精度不够，或样本本身不够**。前者靠提高时间轴帧率，后者只能靠拍摄时提高帧率。

## 八、操作细节矩阵

### A. 时间轴与结构

| 操作 | 入口 | 底层在改什么 |
|---|---|---|
| 分割 `Ctrl+B` | 光标处切一刀 | 1 个 segment 拆成 2 个，各自重算 source/target |
| 波纹删除 | 删除后后续自动吸附 | 后面所有片段的 target 起点整体前移 |
| 复制片段 `Alt+拖拽` | 或 Ctrl+C/V | 新增 segment，仍指向同一素材（不复制文件） |
| 复合片段 `Ctrl+G` | 选中多个 | 生成子时间轴，对外表现为单个 segment |
| 变速 | 右键 → 变速 | 改 speed；0.1×–10×，超出范围要分段 |
| 曲线变速 | 变速面板 → 曲线 | 片段内部再切多个 speed 段，做"快—慢—快"卡点 |
| 智能补帧 | 变速面板内 | 光流法插帧，慢放不顿但计算量大 |
| 倒放 / 定格 | 右键 | 反向采样 / 抽单帧变静态素材 |
| 主轨磁吸、自动吸附、联动 | 时间轴上方开关 | 决定拖动对齐行为，关掉才能精确微调 |

### B. 画面处理

| 功能 | 关键参数 | 原理 |
|---|---|---|
| 蒙版 | 线性/镜面/圆形/矩形/爱心/星形 + 羽化 + 反转 | 只改这一层 alpha，不裁像素，随时复原 |
| 色度抠图 | 取色 + 强度 + 阴影 | 按色相距离判定透明，绿幕首选 |
| 智能抠像 | 一键 | 模型逐帧分割人像，质量高但吃性能 |
| 混合模式 | 正片叠底 / 滤色 / 叠加… | 改变两层像素的混合公式，做光效与纹理 |
| 调节 | 亮度/对比/饱和/色温/色调/高光/阴影 | 全局逐像素色彩变换 |
| HSL | 分色相单独调 | 只改某一种颜色，比如只让天空更蓝 |
| 曲线 | RGB + 单通道 | 精确控制亮度映射，最专业的调色入口 |
| LUT | 导入 `.cube` | 3D 查找表，一次性套整套风格 |

### C. 声音

| 功能 | 用途 |
|---|---|
| 音量关键帧 | 做音量包络：讲话处压低、留白处抬起 |
| 淡入淡出 | 避免爆音，比手动打帧快 |
| 降噪 | 去底噪/空调声，强度过大会"水下感" |
| 变声 | 音高 + 音色，做角色化处理 |
| 音频闪避 | 检测人声自动压低 BGM，访谈必备 |
| 识别字幕 | ASR 语音转文字，必须联网，口音重需人工校 |
| 文本朗读 | TTS 配音，适合口播稿和无音素材 |

### D. 导出

| 参数 | 怎么选 |
|---|---|
| 分辨率 | 跟用途走；4K 素材导 1080p 完全够，体积小一半 |
| 编码 | H.264 兼容最好；H.265 同画质体积小 30–50%，但老设备解码吃力 |
| 码率 | 1080p30 用 10–16 Mbps 足够；平台会二次压缩，给太高没意义 |
| 帧率 | 必须 ≥ 素材帧率且与时间轴一致，否则出现重复帧 |
| 色彩空间 | 普通用途 Rec.709；HDR 素材才动 Rec.2020/HLG |

**体积估算**：`大小(MB) ≈ 码率(Mbps) × 时长(s) ÷ 8`。20 Mbps × 60s ÷ 8 = 150 MB。

## 十、工程管理与性能（决定能不能做长片）

- **草稿位置**：`C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\`，每个草稿一个文件夹，`draft_content.json` 就是工程本体。
- **备份 = 复制整个草稿文件夹**，不是只复制视频。换电脑、重装系统前先做这件事。
- **草稿打不开的急救**：找 `draft_content.json.bak` 之类历史版本改名顶上，能救回大半。
- **缓存盘设到 SSD 并定期清**——缓存膨胀是"越编越卡"的头号原因。
- **代理模式**：为 4K 素材生成低分辨率副本，剪辑读代理、导出读原片。多机位与 4K 项目必备。
- **素材集中放一个文件夹**：剪映存的是路径引用，路径一变就红框丢素材。别用桌面/下载/微信缓存里的散文件。

## 十一、四周精通路线

| 周 | 目标 | 具体练习 |
|---|---|---|
| 第 1 周 | 手速与结构 | 3 段素材剪 30 秒无特效短片，全程只用快捷键；练分割、删除、吸附对齐、导出 |
| 第 2 周 | 时间操控 | 15 秒音乐卡点（曲线变速 + 定格 + 倒放）；一条纯关键帧的"图片推拉" |
| 第 3 周 | 画面控制 | 绿幕抠像合成、双人分屏（蒙版）、HSL 单独调色、LUT 统一影调 |

**"精通"的三个标准**：① 任何效果能说出它改的是四维中的哪一个；② 遇到卡顿能定位到管线哪一段；③ 拿到别人的工程能看懂结构并改得动。

## 十二、十二个高频坑（原教程 6 + 本库补充 6）

| # | 坑 | 正解 |
|---|---|---|
| 1 | 模板套用后改不动 | 模板只开放"素材槽"，轨道与时长为保结构被锁，是设计如此 |
| 2 | 竖屏项目导入横屏素材 | 要么裁剪、要么缩放留黑边，没有自动"智能填充" |
| 3 | 字幕识别错字 | ASR 必有错，永远人工过一遍，尤其术语与人名 |
| 4 | 自动保存 ≠ 版本管理 | 只能撤销、回不到三天前；重要节点手动"另存为草稿" |
| 5 | 导出比预览暗/偏色 | 预览降采样 + 色彩空间不匹配；以导出后实际播放为准 |
| 6 | 一直加特效掩盖节奏问题 | "看不懂"通常是节奏与叙事问题，不是特效不够 |
| 7 | 变速只改视频轨 | 视频 + 音频一起选中再变速，否则音画分开 |
| 8 | 画中画以为"主轨丢了" | 画中画默认铺满，主轨被完全盖住 |
| 9 | 慢放卡顿怪软件 | 是拍摄帧率不够；见 §七.2 |
| 10 | 录屏素材时长对不上 | VFR 素材，先转 CFR |
| 11 | 30fps 工程做快速动画 | 网格太疏，关键帧被吸到整帧；换 50/60 工程 |
| 12 | 中途改时间轴帧率 | 所有非整帧的关键帧/标记被重吸附，音画错位；帧率开工就定死 |
