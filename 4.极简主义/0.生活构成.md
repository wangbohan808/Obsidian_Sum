# 生活构成

> 很多事情理性分析好像没什么意义，但你真的去做了，其实还是很不错的。
> —— 动手去体验，比在脑子里论证价值更接近意义本身。

## 理想生活蓝图（总纲）

> 内核只有两根柱子：一份值得奉献的事业 + 一个好家庭；其余皆随缘。
> 一句话定义：找一家值得奉献、对人类有意义、五天 8 小时的公司，和一个价值观相近、大钱各立 / 小钱不计较的妻子，组成一个两室一厅、近乎零家务的家——下班就回家。

### 一、事业
- 终极理想：时间自主（想干就干、想歇就歇）——现阶段不现实，作为长期方向。
- 现实落点：值得「奉献青春」的公司——一周 5 天 × 8 小时，工作有意义、对人类有贡献（标杆：DeepSeek），绝不「用时间换工资」。
- 升级路径：先在公司攒技术深度 → 再用深度换自由度。

### 二、婚姻
- 找一个价值观相近的妻子。
- 金钱观：大钱各立（AA）/ 小钱不计较，尊重彼此独立与人性规律。
- 时间线：24 恋爱 → 26 结婚 → 29 生育（26 时月薪约 2.5 万，可养家）。

### 三、住房
- 婚后先租房：月租 4000、五六十平。
- 理想户型：两室一厅（一间书房 + 一间同住 + 一个客厅）。

### 四、工作与家庭平衡
- 6 点下班回家陪家人；周末（离家近）/ 节假日回家放松。
- 下班与中午彻底放空、不碰工作；仅当自己有兴趣才学点工作相关。
- 工作 = 奉献与意义的载体，而非生命的全部。

### 五、家务（近乎零家务）
- 扫地机 + 家中保持极简规整（方便清扫）。
- 工作日晚餐外卖；得空谁想做谁做（做饭 = 创造的享受 + 培养感情）。
- 全自动洗衣机。

### 六、现阶段主动「不关注」（避免焦虑）
- 健康 / 体检：等月薪到 2.5~3 万再谈每年体检，其余随天意。
- 父母、财务细节：顺其自然，不强求掌控。
- 兴趣（可选，未来再说，非重点）：一人之下游戏、音乐 / 钢琴、健身跑步。

## 人生享受

1. 爱情：理解人性后，入场感受
2. 美食：吃美味的食物，少而精，避免暴食
3. 按摩泡澡：周末泡汤泉（12h 澡票，回血仪式）
4. 放空：洗热水澡 → 只听音乐 / 纯放空（每晚 1h 起步）

> 享受原则：可以一定程度上享受，但要一直提醒自己不要沉沦。（见 `6.物尽其用·关系操作系统` 十一：情绪与好意的瞬时性）

充电 = 回血（不是继续干活）
> 休息的本质是"切断输入"，不是"换活干"

## 当下与快乐

> 人生是无数个「当下」的体验，没有永恒的快乐解法；无聊与孤独不会消失，只随生活变好而降低比例。

- 扎根期（没时间 / 没爱好 / 没钱 / 无成就感）→ 90% 当下无趣
- 能力与掌控感提升、培养摄影 / 剪辑 / 钢琴 / 编曲 / 写歌等爱好 → 降至 50%
- 可支配时间变多、圈子影响力上升 → 仅 10% 无趣

## 找乐子（让日子有趣）

> 别活得太紧绷，找乐子是人生很重要的一部分。

- 心态参考「坐忘道」（典出《道诡异仙》）：以「骗」为修行——连上天、命运也能玩着骗过去。把它看成一场人生游戏，不较真、不紧绷，用洒脱戏谑的心态过日子。
- 核心：常给自己留点乐子，用「玩」的视角化解日常的严肃与紧绷。

> 很多事情想着没有意义，但是做的时候有趣就去做了
## 美食记录

**原则：** 少而精，避免暴食。周末一天一餐，吃得丰盛又精，顺带探索新种类。

> 记住：先评估自己的实力，再下单 / 点菜。总以为自己能吃很多，实际吃一点就腻了。
> 宁愿少点一份、精致好吃，也不要撑到想吐。

### 日常饮食节奏

工作日（周一~周五）饮食固定，不折腾：

- 早餐：两个肉包子
- 午餐：滑蛋牛肉 + 辣椒炒蛋 + 一小份糙米饭
- 晚餐：鸭腿饭 + 一点小菜素菜

周末（周六、周日）：每天只吃一顿，但要吃得丰盛又精。
每周共 3 顿"放松餐"：周五晚上 + 周六 + 周日。

- 适合安排进周末的：寿司拼盘（吃不腻，味道好）→ 见下方「想吃清单」
