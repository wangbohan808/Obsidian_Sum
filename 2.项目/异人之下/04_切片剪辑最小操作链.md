# 切片剪辑 · 最小操作链

> **一句话核心：一条能发的切片只需要三个动作——切、字幕、导出，第一次约 40 分钟出片；其余 80% 的功能等卡住了再学，不用先学。**

> 缘起：2026-11-10，本人提出完全没有剪辑经验，需要教"素材怎么获取 / 怎么剪 / 怎么插文字 / 怎么效果更好"。
> 判据：**剪辑不是知识，是肌肉记忆**，看教程的边际收益远低于剪完第一条。所以本文只给"最短可用链"，不给完整知识体系。

---

## 零、三步速览

| 步 | 动作 | 耗时 |
|---|---|---|
| 1 | 拖入素材 → 播放头定位 → `Ctrl+B` 分割 → 删废段 | 15 min |
| 2 | 一键语音转字幕 → 改错别字 → 调字号 | 15 min |
| 3 | 导出 1080p60 / H.264 / 8–12 Mbps | 5–10 min |

---

## 一、素材获取（含一个必踩的坑）

| 来源 | 怎么做 | 坑 |
|---|---|---|
| **OBS 本地录制（首选）** | 输出里同时开「推流 + 录制」，与推流并行 | 格式选 **MKV**（异常退出不损坏），录完用「文件 → 重新封装录像」转 MP4，**不转码、几秒完成** |
| B站 直播回放 | 直播中心 → 我的直播间 → 直播回放 → 下载 / 投稿 | **只保留 14 天，过期物理删除**；官方 FAQ：用 OBS 开播会导致回放时长低于实际时长，建议关键帧间隔调到 2–5s（`02` 里的 2s 是推流标准，靠回放要留余量） |
| 游戏内 / 手机录屏 | 兜底 | 画质帧率不够做技术向内容 |

### 平台口径（官方）

- **整场投稿**：需开播时 500 粉以上，**只在个人空间展示，不进推荐与搜索**。
- **投片段**：所有主播可用，**进推荐与搜索**。
- 弹幕同步到稿件：需 5000 粉。
- 官方原文建议"自行下载回放后剪辑再投稿"——切片路线是被官方鼓励的，不用等粉丝。

### 录制参数建议

`1080p60` · `MKV` · `CQP 18–20` 或 `CBR 15000–20000 kbps` · 音频 `AAC 192–320 kbps` · 存独立盘（如 `D:\录播\`）。

## 二、软件选型

| 工具 | 免费够用吗 | 结论 |
|---|---|---|
| **必剪**（bcut，B站官方） | 全免费，一键语音转字幕，投稿直通 | **首选**，省掉导出再上传两步 |
| 剪映专业版 | 自动字幕免费、1080p/4K 可导；VIP 才锁声音克隆/抠像/超分 | 备选，花字模板更多 |
| 达芬奇 Resolve | 免费版能力强 | 暂不学，中文自动字幕弱 |
| 开源流水线（bilive / ShadowReplay / biliup） | 免费，录+切+投一条龙 | **第 10 条切片之后再碰**：要配环境调参，且它判定的"高光"≠你认为的精彩 |

> **选哪个不重要，今晚随便选一个开始。**

## 三、三个动作详解

### 1. 切

- 素材拖进时间轴 → 播放头停在废段起点 → `Ctrl+B` 分割 → 选中 `Delete`。
- 只做这一件事。**不碰转场、不碰关键帧、不碰变速。**

### 2. 字幕

- 一键「语音转字幕」→ 逐句改错别字。
- 专有名词必错，重点核对：**炁、身外身、八奇技、哪都通、临时工、罗天大醮、各角色名**。
- 字号按"手机竖屏能看清"调，别用默认。

### 3. 导出

| 项 | 值 |
|---|---|
| 分辨率 · 帧率 | 1920×1080 · 60fps |
| 编码 | H.264 |
| 码率 | 8–12 Mbps（视频可高于推流，不必实时传） |
| 音频 | AAC 192 kbps |
| 色彩 | BT.709 · 部分（Limited） |

## 四、60 秒结构

```
0–3s   钩子：把结果/最反直觉的一句放最前，不要自我介绍
3–45s  主体：只讲一件事
45–55s 结论：一句能记住的话
55–60s 引导：关注只说一次，别啰嗦
```

**长录播里翻菜单、等加载、沉默全部剪掉**——这是切片和录播的全部区别。

---

## 五、文字的三层（"插播文字"到底插什么）

| 层 | 内容 | 用量 | 位置 |
|---|---|---|---|
| 字幕 | 口播 / 游戏内语音转录 | 全程 | 画面下方约 1/5，留边距 |
| 强调字 | 数字、结论、反直觉句 | **一条 ≤3 处** | 中部偏上，别压血条与技能 CD |
| 标题卡 | 开头一张，写清这条讲什么 | ≤1 张 | 0–2s |

**禁忌**：满屏花字、字体超过 3 种、颜色超过 3 种、字幕盖住判定区域。

---

## 六、五条"效果更好"（是可执行规则，不是审美）

1. **前 2 秒给结果**，不要"大家好我是……"。
2. **一条只讲一件事**，切片不是集锦。
3. **剪掉所有无信息段**：等待、翻菜单、沉默、重复操作。
4. **声音优先于画面**：人声峰值约 −6 dB，游戏音压到 −20 dB 以下，BGM 更小。先调好这条再调画面。
5. **字幕必加**：相当一部分人是静音刷，无字幕等于直接流失。

---

## 七、学什么、什么时候学（防止掉进"先学完再发"）

| 阶段 | 只学 | 不碰 |
|---|---|---|
| 第 1–3 条 | 切 / 自动字幕 / 导出 | 转场、调色、特效 |
| 第 4–10 条 | 关键句大字、片头 1 张标题卡 | 画中画、蒙版 |
| 真卡住了才学 | 需要对比/图解时，学贴图与画中画 | 绿幕、跟踪、复杂调色 |

> **硬判据：某一集剪辑超过 60 分钟，说明你在学软件，不是在剪内容——停。**

## 八、第一条发布前检查（勾选）

- [ ] 录制格式是 MKV，已 remux 成 MP4
- [ ] 前 2 秒有钩子，没有自我介绍
- [ ] 全片只讲一件事
- [ ] 无信息段已剪掉
- [ ] 字幕已加，专有名词已校对
- [ ] 人声清楚、游戏音未盖人声
- [ ] 强调字 ≤3 处
- [ ] 导出 1080p60 / 8–12 Mbps
- [ ] 标题埋"异人之下 + 具体词"，前缀 `【异人之下】`
- [ ] 标签：游戏区 + 具体玩法
- [ ] OBS 常驻水印 `B站 @地球online808` 在画面内
