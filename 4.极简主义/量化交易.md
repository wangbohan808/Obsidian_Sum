### 在windows安装的python，在wsl中的ubuntu22.04命令行环境无法使用

安装python基础包：
```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip python3-dev build-essential
```

升级pip：
```bash
python3 -m pip install -U pip setuptools wheel \
  -i https://pypi.tuna.tsinghua.edu.cn/simple
```

此时python3有反应，但是使用python仍然没有反应--安装python指向python3的包：
```bash
sudo apt update
sudo apt install python-is-python3
```

进入项目目录，创建并激活虚拟环境：
```bash
cd ~/stock_quant
python3 -m venv .venv
source .venv/bin/activate
```

验证与退出虚拟环境：
```bash
which python
deactivate
```
