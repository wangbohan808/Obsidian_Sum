# 芯源集尘桶项目

> [!info] 一句话结论
> 基于 CW32L010（Cortex-M0+）的集尘桶固件：Bootloader 占 Flash 首 4KB，负责 IAP 跳转到 APP 并管理升级标志，量产与重构围绕启动文件、链接脚本和 Flash 读写展开。

## 要点
- MCU 为 CW32L010（Cortex-M0+），复位默认走 HSI 分频约 4MHz，正式配置到 48MHz。
- Bootloader 与 APP 双区：Bootloader 占 Flash `0x00000000` 起 4KB，APP 从其后的偏移运行。
- IAP 跳转三步：改向量表（VTOR）+ 改栈顶（MSP）+ 跳转执行。
- Flash 写入前必须按页擦除（每页 512Byte），写 32bit 用 `FLASH_WriteWords`。
- 裸机无文件系统，`stdout` 无效，需重写 `fputc`/`printf` 才能输出到串口。
- 时间片循环遍历函数指针列表实现注册式回调。

## 项目背景
- 芯源集尘桶固件，采用 Bootloader + APP 架构以支持 IAP 在线升级。
- 开发方式：VSCode 做函数级快速跳转，Cursor 做项目整体分析，两者互补。

## 硬件与芯片

### Flash 与 RAM 划分

```text
芯片
├── Flash
│   ├── Bootloader Flash（向量表 / 代码 / 常量）
│   └── APP Flash（向量表 / 代码 / 常量）
└── RAM
    ├── Bootloader RAM（栈 / 堆 / 变量）
    └── APP RAM（栈 / 堆 / 变量）
```

- `appxaddr` 是 APP 相对 Bootloader 的偏移；64KB = `0x10000`，偏移过大将超出 Flash 有效范围。

### 时钟体系
- RCC = Reset and Clock Control（复位与时钟控制）。
- 五层结构：时钟源 → SYSCLK → HCLK（AHB/CPU）→ PCLK（APB 外设）→ 外设门控（AHBEN/APBEN）。
- 时钟源使能：`CW_SYSCTRL->CR1` 的 HSIEN/HSEEN/LSIEN/LSEEN 各自独立；SYSCLK 由 `CR0.SYSCLK` 四选一。
- HCLK 由 SYSCLK 经 `HCLKPRS` 分频，驱动 CPU/GPIO/Flash/SysTick；PCLK 由 HCLK 经 `PCLKPRS` 分频，驱动 UART/SPI/ADC（APB1）与 I2C/RTC/IWDT（APB2）。
- 门控：每个外设有独立时钟开关，未开启时读写其寄存器无效。

| 节点 | 配置 | 频率 |
| --- | --- | --- |
| HSI 源 | `HSIOSC_DIV1` | 48 MHz |
| SYSCLK | 选 HSI | 48 MHz |
| HCLK | `HCLK_DIV1` | 48 MHz |
| PCLK | `PCLK_DIV1` | 48 MHz |

- UART 115200 波特率分频基于 `48000000 / (16 × 115200) ≈ 26`。

> [!warning] 常见隐患
> 若未调用 `RCC_Configuration()`，CPU 可能仍在复位默认频率（`SystemCoreClock` 写死 4MHz），与 UART 里写的 48MHz 不一致会导致通讯异常。

## Bootloader 源码结构

### 链接脚本 Project.sct

```sct
LR_IROM1 0x00000000 0x00001000  {    ; load region size_region
  ER_IROM1 0x00000000 0x00001000  {  ; load address = execution address
   *.o (RESET, +First)
   *(InRoot$$Sections)
   .ANY (+RO)
   .ANY (+XO)
  }
  RW_IRAM1 0x20000000 0x00001000  {  ; RW data
   .ANY (+RW +ZI)
  }
}
```

- `LR_IROM`：本程序的加载区，`0x00000000`–`0x00001000`，共 4KB。
- `ER_IROM`：代码执行区，在加载区就地执行，只规定各文件的执行位置。
- 链接器把所有程序分类后「装箱」到指定硬件区域。

### 启动文件 startup_cw32l010.s
- 栈/堆各 `0x200`（512B）：`AREA STACK,NOINIT,READWRITE,ALIGN=3` 中 `READWRITE` 决定放 RAM、`NOINIT` 表示上电不初始化、`ALIGN=3` 要求 8 字节对齐（ARM 以 8 字节为整块读写单元，非对齐访问可能触发硬件异常）。
- `PRESERVE8` 要求进入函数时 SP 一定 8 字节对齐。
- `Stack_Mem`/`__initial_sp`、`Heap_Mem`/`__heap_base`：前者只创建连续空间，仅凭用途才认定为栈/堆；标签等价为空间接下来的地址。
- 向量表 `AREA RESET,DATA,READONLY`：Flash 从 0 起的一串 4 字节格子，前 16 个 ARM 内核规定、后 32 个厂商外设中断；**每个格子含义硬件写死，只负责填地址**，中断触发即去对应格子取地址跳转。
- `EXPORT __Vectors/__Vectors_End/__Vectors_Size` 让链接器知道向量表起止与大小。

```assembly
; 向量表（节选）
DCD  __initial_sp        ; -16 栈顶指针
DCD  Reset_Handler       ; -15 复位向量
DCD  NMI_Handler         ; -14 不可屏蔽中断
DCD  HardFault_Handler   ; -13 硬件故障
DCD  SVC_Handler         ; -5  系统服务调用
DCD  PendSV_Handler      ; -2  可挂起系统服务请求
DCD  SysTick_Handler     ; -1  系统滴答定时器
DCD  WDT_IRQHandler      ; 0   看门狗中断
DCD  UART1_IRQHandler    ; 27  UART1 中断
DCD  UART2_IRQHandler    ; 28  UART2 中断
```

- Reset_Handler：先从 `0x0` 取栈顶装入 SP，`BLX` 调用 `SystemInit`（返回），`BX` 跳到 `__main`（不返回）。

```assembly
Reset_Handler   PROC
                EXPORT  Reset_Handler             [WEAK]
                IMPORT  SystemInit
                IMPORT  __main
                LDR     R1, =0x0
                LDR     R0, [R1]
                MOV     SP, R0
                LDR     R0, =SystemInit
                BLX     R0
                LDR     R0, =__main
                BX      R0
                ENDP
```

- `PROC`/`ENDP` 界定函数；`EXPORT ... [WEAK]` 对外声明地址并允许外部重写；`IMPORT` 导入外部函数以便调用跳转。
- 默认弱定义中断（`NMI/SVC/PendSV/SysTick/HardFault`）体为 `B .`，**未重写则触发后程序卡死**；`Default_Handler` 用 `[WEAK]` 批量导出 WDT/LVD/RTC/GPIO/ADC/UART 等外设中断。
- 微库（`__MICROLIB`）自动管理堆栈；否则用 `__user_initial_stackheap` 手动给栈/堆地址。
- `ALIGN` 让当前地址在此处四字节对齐。

### 系统初始化 system_cw32l010.c

```c
void SystemInit(void)
{
#if defined(USER_VECT_TAB_ADDRESS)
    SCB->VTOR = VECT_TAB_BASE_ADDRESS | VECT_TAB_OFFSET;
#endif
    CW_SYSCTRL->HSI_f.TRIM = *((volatile uint16_t *)SYSCTRL_HSI_TRIMCODEADDR);
    CW_SYSCTRL->LSI_f.TRIM = *((volatile uint16_t *)SYSCTRL_LSI_TRIMCODEADDR);
    SystemCoreClockUpdate();
}
```

- 复位默认时钟为 HSI 分频后的约 4MHz。
- 定义宏则按偏移重定位向量表；把芯片校准值写入 HSI/LSI TRIM 寄存器；`SystemCoreClockUpdate()` 先记录频率估计值，后续按实际寄存器修正。

### main.c 与 IAP 跳转
- 函数指针 = 目标函数地址 + 到达地址后操作它的方法。
- Cortex-M 用 VTOR 保存向量表基地址，复位/中断时先查向量表取函数地址再跳转。

```c
typedef void (*func_ptr_t)(void);

void iap_load_app(uint32_t appxaddr)
{
    SCB->VTOR = FLASH_MEMORY_BASE | VECT_TAB_OFFSET;
    if (((*(__IO uint32_t*)appxaddr) & 0x2FFE0000) == 0x20000000)  // 判断地址有合法程序
    {
        JumpAddress = *(__IO uint32_t*)(appxaddr + 4);   // Reset_Handler 地址
        Jump_To_Application = (func_ptr_t)JumpAddress;   // 地址强转为函数指针
        __set_MSP(*(__IO uint32_t*)appxaddr);            // 设置 APP 栈顶
        Jump_To_Application();                           // 跳入 APP 的 Reset_Handler
    }
}
```

- `__IO` = `volatile`，禁止编译器优化、强制读写真实内存；`*(__IO uint32_t*)addr` 读该地址的 32 位值。
- IAP 跳转 = 改向量表（Flash）+ 改栈顶（RAM）+ 跳过去运行。

### Flash 读写

```c
int32_t app_flash_write(uint32_t *data, uint32_t Flash_address)
{
    uint32_t start_add = Flash_address;
    FLASH_UnlockAllPages();
    for (i = 0; i < FLASH_PAGE_SIZE / 4; i++)
        FLASH_WriteWords(start_add + i*4, &data[i], 1);   // 先擦页，再逐字写
    FLASH_LockAllPages();
    return 0;
}
```

- 写入前先 `FLASH_ErasePage(start_add + i*FLASH_PAGE_SIZE)` 擦页，每次 512Byte；`app_flag_write1` 用于写 32bit 升级标志。
- `FLASH_Read_half_apge` 从首地址把 32 位字逐个搬进数组（128 个 `uint32_t`，相当于 RAM 中的一页）。
- `SYSCTRL_Configuration()` 通过 `REGBITS_SET(CW_SYSCTRL->AHBEN, 0x5A5A0000 | bv)` 打开 Flash/GPIO 的 AHB 时钟。

## 烧录与量产

### printf 与串口输出
- 裸机无 OS/文件系统，也没有设备管理；`stdout` 只是一个地址固定的空/无效指针，不指向任何硬件。

```c
int my_printf(const char *fmt, ...)
{
    int count = 0;
    while (*fmt != '\0') {
        fputc(*fmt, stdout);   // 核心：最终落到 fputc 单字节输出
        count++;
        fmt++;
    }
    return count;
}
```

- 重写 `fputc` 即可把输出引到串口；**同名函数链接器优先用用户自定义实现，忽略标准库版本**。

### 编译链接与头文件
- 编译单位是单个 `.c`：只看该文件 + 它 `#include` 的头文件，做语法/原型检查后生成 `.o`，不关心函数是否实现。
- 声明与定义可分离（`.h` 里声明、任意 `.c` 里定义），只要签名一致就是同一函数。
- 链接阶段才把所有 `.o/.a/.lib/.so` 捆在一起找实现地址；找不到报 `undefined reference` 或 `unresolved external symbol`。

> [!tip] 终极总结
> 编译看声明，只认原型；链接找定义，搜遍所有目标文件。

### 寻址与类型
- 绝大多数处理器最小寻址单位是 1 字节，**位没有独立地址**；结构体所有成员共用同一起始地址、按顺序排列。
- `int` 是通用有符号整数；`size_t` 是专门表示大小/数量的无符号整数，与平台指针位宽匹配；长度/大小/索引用 `size_t`。

## 重构要点

### 函数指针注册
- 时间片循环遍历自己列表里的函数指针地址并执行；向列表传入函数地址即完成注册，后续自动调用。

### 时钟提速影响
- 主频从 4MHz 提到 48MHz，同代码理论上约快 12 倍。

> [!danger] 时序风险
> 提速后若不重新同步，通讯时序之间可能对接不上。
