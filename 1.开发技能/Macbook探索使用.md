# Macbook探索使用

## Mac支持的两种文件系统

**APFS**
- Apple File System
- 苹果公司开发
- 修改文件时，不覆盖原始数据块，而是在磁盘空闲区域写入新的版本，修改文件后更新文件指针，旧数据保留
- 内置元数据日志（记录文件目录、权限、大小、加密状态等变更记录），保留历史版本，重启后日志可回滚修复

**exFAT**
- Extended File Allocation Table（拓展文件分配表）
- Microsoft微软开发
- 修改文件无备份，直接拔盘易损坏
- 没有完整的系统权限，不支持Unix权限、用户分组；因而MAC写入后，Windows打开造成乱权限，使得Mac只能读不能写


## USB-C协议区别

C口外形是统一的，只是外壳标准，里面跑什么协议完全看**芯片、线材、设备**三者结合；主机（电脑）TCPC 芯片决定上限、外设（固态）主控决定下限、线材 E-Marker 决定协商放行门槛，三者木桶效应，最低一方决定最终协议。
- 24 针全功能：支持 USB3.2 / 雷电 / USB4、视频输出、100W PD--移动固态硬盘配置这种母头以及数据线
- 12 针简化版：仅 USB2.0 480Mbps 充电，**完全跑不了高速固态**--常用充电头、手机数据线是这一个配置
高速 C to C **线缆插头内部内置微型存储芯片**。插上线，电脑 TCPC 芯片通过 CC 引脚给线材 E-Marker 供电；读取 E-Marker 存储的线材规格；设备自动降级到**线材能承载的最高标准**，不会强行开高速烧毁线缆：

**USB 2.0 Type-C**
- Universal Serial Bus 2.0 Type-C
- 480Mbps ≈ 60 MB/s 
{**Mbps**：兆比特每秒（小写 b = bit，比特，传输最小单位）；
**MB/s**：兆字节每秒（大写 B = Byte，字节，电脑存储单位）}
- 使用：手机充电、只传送文档的U盘

**USB 3.2 Gen1（旧称 USB3.0 / 5Gbps）**
- 全称：USB 3.2 Generation 1
- 速率：**5Gbps ≈ 500MB/s**

**USB 3.2 Gen2（10Gbps）**
- 全称：USB 3.2 Generation 2
- 速率：**10Gbps ≈ 1000MB/s**

**USB 3.2 Gen2×2（双通道 20Gbps）**
- 速率：**20Gbps ≈ 2000MB/s**


**雷电3（Thunderbolt 3）**
雷电 3 芯片**永久预留 18Gbps 带宽给 DP 视频隧道**，无论你插不插显示器，这 18Gbps 都会锁死，不能挪给硬盘 / 显卡。
剩余可用给 PCIe+USB 的带宽：`40 - 18 = 22Gbps`
- 纯硬盘场景：PCIe 最多跑 22Gbps（≈2750MB/s）
- 插 1 台 5K 显示器：DP 占满 18G，硬盘只剩 22G
- 插双 4K 显示器：DP 直接占满全部 40G，硬盘几乎无带宽可用，拷贝速度暴跌




**雷电4（thunderbolt4）**
雷电 4 规范白纸黑字强制：**任何状态下，PCIe 隧道最低保障 32Gbps 带宽**，仅预留 8Gbps 给视频备用。
1. **不插显示器**
    全部 40Gbps 给 PCIe，满速 32Gbps 可用（扣除协议开销），高速固态、显卡坞拉满性能。
2. **插显示器**
    仅从 32G 里动态分割带宽给 DP 视频，不会挤占存储 / 显卡通道：

- 单 8K / 双 4K 同时使用时，最多占用 8Gbps，PCIe 仍保留 24Gbps 以上带宽；
- 一边拷大容量素材、一边 4K 剪辑渲染，硬盘速度几乎不掉速（雷电 3 做不到）。

**主机雷电 4 口总 PCIe 资源固定 32Gbps，拓展坞下所有高速设备（雷电固态、显卡、雷电网卡）共享这 32G**

雷电 4 标准强制底层兼容 USB4 协议；USB4 物理层、隧道架构源自雷电 3，两者硬件握手互通，不存在插不上、识别不了的情况

雷电3/4输出的视频都是DP协议信号，其余带宽留给PCIe硬盘数据等。接收端可以使用转接将DP协议转化为HDMI协议

雷电 3永久固定 18Gbps 预留给 DP 隧道，不管你转不转 HDMI，这 18G 带宽直接锁死给视频，剩余 22G 给 PCIe 硬盘；
雷电 4无固定预留，视频带宽动态按需分配，最多占用 8Gbps 物理带宽；哪怕用有源芯片转 HDMI，视频整体占用上限依旧 8G，底层 32Gbps PCIe 带宽全程保底给硬盘、拓展外设。

## PCIe与SATA、NVMe

**PCIe**
- Peripheral Component Interconnect Express，高速串行外设互联总线
- 本质：电脑主板上连接CPU与所有高性能硬件的**底层物理传输通道**，是硬件传输的“高速公路主干道”
- 最小单位：Lane（通道/车道），一组差分收发线，双向同时传输（全双工）
PCIe 3.0 ：单Lane 8Gbps -> 1GB/s
PCIe 4.0 :  单Lane 16Gbps -> 2GB/s
PCIe 5.0 :  单Lane 32Gbps -> 4GB/s

固态、显卡普遍使用 x4 （4条通道并行）：
PCIe 3.0 x 4 = 4GB/s，PCIe 4.0 x 4 = 8GB/s

PCIe 只是通道，本身不能读写硬盘，必须搭配上层协议：
- 搭配 NVMe → NVMe PCIe 固态（M.2 高速固态）
- 搭配 AHCI（老旧协议）→ 老式 PCIe SATA 转接卡


**SATA**
- Serial AT Attachment，串行硬盘附件总线
- 专门为2.5/3.5寸机械硬盘设计，后期兼容2.5寸SATA固态；是一套完整独立总线，不占用PCIe高速通道
- 单向半双工；
- 带宽**6Gbps**，换算实际最大读写 ≈ 550MB/s


**NVMe**
- Non-Volatile Memory Express，非易失性内存主机控制器接口规范
- 本质：运行在PCIe总线上、专为闪存（SSD固态硬盘）设计的轻量化通信协议
- NVMe协议相当于固态和CPU交流的”专用高级语言“，只能跑在PCIe通道上，不能跑SATA
- 原生支持 PCIe 多通道并发，充分释放 PCIe x4 全部带宽
NVMe PCIe3.0 x4：理论上限 4GB/s，消费级移动固态普遍 1000–3500MB/s；
NVMe PCIe4.0 x4：理论上限 8GB/s，旗舰台式固态 4–7GB/s

PCIe 标准**向下兼容**，最终运行速度由**规格更低的一方决定**：
1. 主机插槽 PCIe4.0 x4 + PCIe4.0 固态 → 跑满 PCIe4.0 全速
2. 主机 PCIe4.0 x4 + PCIe3.0 固态 → 自动降速到 PCIe3.0 x4
3. 主机 PCIe3.0 x4 + PCIe4.0 固态 → 强制锁死 PCIe3.0 x4（硬盘再强也跑不满）
