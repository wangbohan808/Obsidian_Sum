# 技能清单

> [!info] 一句话
> **这首歌七成是判断，三成是手上功夫。** AI 已经把执行成本压到接近零，门槛全部前移到了"知道什么该删"和"听得出好坏"。

## 零、先看三个数字

| 项 | 数 |
| --- | --- |
| 看似需要的技能 | 29 项 |
| **真正必须会的** | **12 项** |
| 你的知识库已覆盖 | 5 项（Suno / 剪辑 / Logic / 声音原理 / 摄影参数） |
| 真正空白的 | **3 项——且全部是"人的部分"** |

## 一、八组技能

### 1. 写词（权重最高）

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| **减法** | 40 行删到 24 行。技能 80% 在这里 | ★★★★★ |
| 口语节奏 | 口白的断句、气口、哪里该停半拍 | ★★★★★ |
| 视角控制 | "我"是谁、"你"是谁，全曲不能漂 | ★★★★ |
| 结尾设计 | 不解释、不总结，只留一句封口 | ★★★★ |

### 2. 结构

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| 段落功能 | A/B/间奏/尾声各自要完成什么 | ★★★★ |
| 情绪曲线 | 三级台阶（荒诞→沉默→自嘲）怎么搭 | ★★★★★ |
| 结构标签 | 给 Suno 的 `[Verse]` `[Spoken]` 之类怎么写 | ★★★ |

### 3. Suno

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| 八字段描述 | 流派/情绪/编制/人声/速度/结构/锚点/质感 | ★★★★ |
| 采样式生成 | 一次生成＝一次采样，多出少改 | ★★★★ |
| **选版判断** | 从 10 条里认出 2 条。**这才是核心** | ★★★★★ |
| 负面词 | 砍掉它爱加的套路（自动叠和声、结尾拉长音） | ★★★ |

### 4. 编曲（拆，不是写）

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| 数轨 / 认乐器 | 听得出有几层、都是什么 | ★★★★ |
| 段落配器变化 | 哪一段进了什么、退了什么 | ★★★★★ |
| 频段分配 | 谁占低频、谁让路 | ★★★ |
| **找偷懒** | 哪里该变没变——这是判断力的入口 | ★★★★★ |

### 5. 唱

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| **语气控制** | 同一句十种劲：解释的、不耐烦的、笑着的、认命的 | ★★★★★ |
| 近场录音 | 贴麦、干声、房间要小 | ★★★ |
| 保留呼吸 | 不许修干净 | ★★★★ |

### 6. 剪辑

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| **切点** | 画面换在音乐的重音上，不是话说完的地方 | ★★★★★ |
| 画幅与景别比例 | 空镜 6 : 手与肩 3 : 脸 1 | ★★★★ |
| 时间线分层 | 画面 / 声音 / 字幕三条独立轨 | ★★★ |
| 导出参数 | 码率、帧率、格式 | ★★ |

### 7. AI 生成 MV

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| **基准图锁定** | 一张桌面图派生全部空镜 | ★★★★★ |
| 一镜一动作 | 每条只允许一件事发生 | ★★★★ |
| 写"可见的" | 不写情绪词（AI 读不懂，只会给更烂的光） | ★★★★ |
| 筛选率意识 | 8 条里 3 条能用就算正常 | ★★★ |

### 8. 声音采集（最容易被漏掉）

| 技能 | 用在哪 | 权重 |
| --- | --- | --- |
| **偷录** | "你说的太多了"只能偷录，录不出来 | ★★★★★ |
| 环境音 | 杯底磕桌、椅子、打火机、远处的笑 | ★★★★ |
| 拟音意识 | 缺什么声音就想着"造"一个 | ★★★ |

## 二、四象限：现在该动哪个

| | 掌握度低 | 掌握度高 |
| --- | --- | --- |
| **权重高** | 🔴 **现在就动手**：写词减法 · 语气控制 · 偷录 | 🟢 **复习一遍就上**：Suno 选版 · 剪辑切点 |
| **权重低** | 🟡 边做边查：调色 · 混音 · 转场特效 | ⚪ 别管：摄影参数 · 器材 |

**红色格只有三项，而且全是"人的部分"——不是软件。**

## 三、三个空白

| 空白 | 为什么是空白 |
| --- | --- |
| **写词** | 库里一篇都没有。这是全曲权重最高的技能 |
| **唱** | 没有笔记，也没有判断标准 |
| **声音采集** | 完全没意识到这是一项技能 |

> 共同点：**你的知识库里，软件和技术全写完了，缺的正好是"怎么说话"和"怎么录人"这三块。**

## 四、明确不学的（排除清单）

| 不学 | 为什么 |
| --- | --- |
| 曝光 / 光圈 / 白平衡 | 全片室内，一盏暖光灯 |
| 调色 / LOG / 色彩管理 | 决定不加调色 |
| 混音 / 母带 | Suno 出的够用，或套模板 |
| 乐理 / 和弦进行 | 这首歌不转调、不写和弦 |
| 任何乐器演奏 | 不用弹 |
| 打谱 / MIDI 编写 | 不自己编曲 |
| AE 特效 | 一个特效都不用 |
| 转场设计 | 硬切到底 |

**排除这八项，省下的时间足够把写词练三遍。**

## 五、技能是串联电路，不是并联

**这是最容易忽略的一件事。** 词错了，Suno 生成的是错的歌，剪辑剪的是错的片，MV 拍的是错的画面——**一个上游错误会被放大四次。**

| 环节 | 出错后的可挽回度 |
| --- | --- |
| 词 | **几乎不可挽回**（下游全部作废） |
| 曲 | 可重生成（代价几小时） |
| 唱 | 可重录（代价一天） |
| 剪 | 可重剪（代价一天） |
| 画面 | 可重生成（代价几小时） |

**所以在词上多花的每一天，都是在给后面省一周。**

## 六、遗留问题

- [ ] 写词这一环没有任何笔记，第 0 周做完后可能需要新建一篇（以这一首的词为案例）
- [ ] 三项空白是否需要单独的训练，还是只靠这一首歌反复做
- [ ] "音乐性"相关技能（和声、律动、配器审美）被整体排除了——这是有意的取舍，不是遗漏
