# Logic 十二周实操路线

> [!info] 一句话核心
> **别让 Logic 当录音机，让它当老师。** 节拍器、和弦轨、录音回放、钢琴卷帘上的时值可视化——这四样是自学最缺的反馈回路，琴上练不出来。所以第一天就进 DAW，在 DAW 里练。

> [!note] 与 [[01_Logic Pro 本质模型与功能全图]] 的分工
> - **01 号管“会用软件”**：六个动词、六周、功能与性能边界。它是工具箱。
> - **本篇管“练成技能”**：十二周，键盘手与编曲能力。它是主线。
> - 两者可并行，但**别混读**：翻菜单的时候看 01，坐下来练的时候看本篇。
>

## 零、总图

| 阶段 | 周 | 每天 | 主题 |
| --- | --- | --- | --- |
| 0 | 第 1 周（2 次 × 90 min） | — | 搭练习模板 |
| 1 | 第 2–3 周 | 40 min | 音色与手感 |
| 2 | 第 4–7 周 | 45 min | **和弦与切分（重心）** |
| 3 | 第 8–9 周 | 40 min | 与鼓锁 |
| 4 | 第 10–12 周 | 40 min | 录音与设备 |
| 5 | 第 13 周起 | 每周 2 次 | 编曲拆解（长期） |

**第 1 周同期：报钢琴课。** 不要再等"有基础"——零基础才最需要老师改手型。

## 一、阶段 0 · 练习模板（一次性，2 × 90 分钟）

**不要用 Logic 现成模板**——只有自己建的工程才知道每轨是干什么的。

| 步 | 操作 |
| --- | --- |
| 1 | `File > New`（Empty Project，不选模板） |
| 2 | `Track > New Software Instrument`（钢琴）／`Track > New Drummer`（虚拟鼓手）／`Track > New Audio`（麦克风，先空着） |
| 3 | `Preferences > Audio > I/O Buffer Size` 设 **128 samples** |
| 4 | 标尺上方拖 **8 小节 Cycle**（`C` 开关） |
| 5 | Recording 设 **Count-in 1 bar** |
| 6 | `File > Save As Template`，命名"练习台" |

**必记 8 键**（比功能全表重要）：

| 键 | 作用 | 键 | 作用 |
| --- | --- | --- | --- |
| `Space` | 播放/停 | `P` | 钢琴卷帘 |
| `R` | 录音 | `Q` | 量化 |
| `C` | 循环开关 | `Y` | 音色库 |
| `K` | 节拍器 | `⌘K` | 电脑键盘当琴 |

**达标：30 秒内从零到"正在循环录音"。**

## 二、阶段 1 · 音色与手感（第 2–3 周，40 min）

**这一步解决 61 键的核心缺陷。** 无配重键盘 velocity 是线性映射，砸不出 127——手感必须软件补偿，不能靠蛮力。

| 动作 | 说明 |
| --- | --- |
| `Y` 过三类音色 | `Vintage Electric Piano`(Rhodes) / `Drawbar Organ`(B3) / `Warm Pad` |
| `I` Track Inspector | 找 Velocity 曲线或 `Fixed Velocity`，90/110/127 各录一遍同一和弦 |
| `P` 看 Piano Roll | velocity 柱状条——**唯一能"看见力度"的地方** |
| 每日配比 | 10 min 音色 + 20 min 节拍器弹 12 和弦 + 10 min 录音回听 |

**达标**：盲选三个音色，说出各自频段占位（Rhodes 200–1k、Organ 中高频泛音、Pad 宽而软）。

## 三、阶段 2 · 和弦与切分（第 4–7 周，45 min）——整条路线的重心

| 项 | 参数 |
| --- | --- |
| 节拍器 | **70 BPM** |
| Cycle | 8 小节 |
| 进行 | `1-6-4-5` → `4536251` |
| 调序 | **C → G → D → F**（覆盖流行歌 80%） |
| 左手 | 只弹根音八度 |
| 右手 | 三和弦，原位 → 第一转位 |

### 关键练法：量化—去量化

1. 录一遍
2. 按 `Q` 量化到 1/8 → **看"标准答案"长什么样**
3. **关掉量化**，靠耳朵重录
4. 反复会发现"我以为对齐了，其实第 3 拍每次都晚 30 ms"
5. `⌘F` 开 Flex Time 看波形对齐

> 这个偏差在琴上永远看不见。**这就是 DAW 当老师的含义。**

**达标**：四调上 `4536251` 弹到 80 BPM 不掉拍，回放听不出明显不齐。

## 四、阶段 3 · 与鼓锁（第 8–9 周，40 min）

| 动作 | 说明 |
| --- | --- |
| Drummer 编辑器 | 双击 region，Intensity/Complexity **拉到最低**，Kick & Snare 拉高 → 最简 pattern |
| 左手 | 只弹根音跟 kick |
| 右手 | 切和弦 |
| **看轨道视图波形** | 左手音符与 kick 波形是否垂直对齐 |

这是"kick 与 bass 是同一事件"（见 [[05_编曲分工与频率预算]] §三）**最直观的验证**，比任何图都直接。

**达标**：左手与 kick 波形对齐；且第二遍能靠**耳朵**判断"刚才那一下偏了"。

## 五、阶段 4 · 录音与设备（第 10–12 周，40 min）

| 步 | 操作 |
| --- | --- |
| 1 | `Preferences > Audio > Devices` 记下 **Roundtrip Latency** |
| 2 | buffer 取 `32 / 128 / 512 / 1024` 各录一次 |
| 3 | 记录：延迟多少 ms、何时开始爆音（sync 错误 / Overload） |
| 4 | 做成自己的实测表 |

> 这就是 [[06_键盘手路径与技术栈映射]] §二"最值一行"的体感版。**在 Logic 里 10 分钟做完，比读十篇 ALSA 文档有用。**

**达标**：能说出"这台机器 128 samples 下 roundtrip = X ms，64 开始偶发爆音"，并有实测表。

## 六、阶段 5 · 编曲拆解（第 13 周起，长期）

| 步 | 操作 |
| --- | --- |
| 1 | 目标曲（Plastic Love）拖进 Logic |
| 2 | `Stem Splitter` 拆人声/鼓/bass/其他（13.0 起可再拆鼓组） |
| 3 | `T` 打 Arrangement Marker：Intro / Verse / Pre / Chorus / Bridge |
| 4 | **核心任务**：和弦进行抄成 MIDI，用 4 个不同音色各弹一遍，比较效果 |

**达标**：写得出段落结构表 + 和弦进行 + 每段乐器增减清单。**比听十节课有效。**

## 七、剪映与 FCP 的位置

> [!warning] 这条路线里它们一次都用不到，现在也不该学
> 剪辑属 `2_剪辑` 那条线。现在学它会抢走十二周最需要的注意力，而瓶颈明明在键盘与编曲。

**唯一真实用途（每两周 15 分钟）**：

手机录下自己弹 comping 的视频 → 导入 FCP 叠上 Logic 导出的音轨 → 用波形对齐做一次**音画同步**。

一次操作练两件事：
1. 编曲复盘——看得见手在什么位置进
2. **音画同步（A/V sync / PTS）**——Linux 音视频里的同一个概念

**所以 FCP 现在只当"编曲的示波器"，不当剪辑软件学。**
