# 厨房作业卡（贴冰箱 · 一页版）

> **这一页只用来看，不用来学。** 原理、翻车点、为什么这么做 → [[食材处理手册]] §十二。
> 每天做饭前扫一眼，特别是「五条不要」。

---

## 一、三句话

| # | 记住这一句 |
| --- | --- |
| **1** | **两把刀**：生刀（红柄）只切生肉生鱼 · 熟刀只切熟食和水果 |
| **2** | **一块板两面**：**A 面（侧边有红线）只碰生肉生鱼** · **B 面碰菜和熟食** |
| **3** | **生肉不过板**：吸干、上浆都在**袋子或盘子里**做，不上砧板 |

---

## 二、分工表（照着拿，不要想）

| 东西 | 只碰 | 用完怎么处理 |
| --- | --- | --- |
| **生刀**（红柄） | 生肉 · 生鱼 · 生禽 | 热水＋洗洁精刷 → **开水冲烫 10 s** → 立起晾 |
| **熟刀** | 熟食 · 水果 · 饼 | 热水＋洗洁精冲净 → 晾干 |
| **A 面砧板**（红线那面） | 生肉 · 生鱼 · 生禽（**每 14 天一次**） | 垫保鲜袋再切 → 刷（**连侧面那圈**）→ 塑料板可烫 → **立起来晾** |
| **B 面砧板** | **蔬菜 → 熟食**（先菜后熟） | 冲净 → 立起来晾 |

**约定**：**有红线的那面朝下放。**

---

## 三、什么时候必须洗，什么时候冲一下就行

| 级别 | 情况 | 处理 |
| --- | --- | --- |
| 🔴 **必须做** | 碰过**生肉 / 生鱼 / 生禽 / 生蛋液**，之后要碰任何入口的东西 | 热水＋洗洁精刷 → **开水冲烫 20~30 s** |
| 🟡 **冲一下** | 切完**带泥的菜**（根茎、葱蒜、菌菇），接着切别的 | 清水冲掉泥渣，不必烫 |
| 🟢 **不用管** | 同类叶菜之间换 · 切水果前（水果本身要洗） | 什么都不做 |

> **常温水冲一遍不是消毒**，只是"把残渣冲掉，让后面的刷洗有效"。**别把"冲一下"当成"洗干净了"。**

---

## 四、水的三个档（越往下越强）

| 做法 | 干什么用 |
| --- | --- |
| 常温水冲 | 去残渣（所有刷洗的**前置**） |
| **热水＋洗洁精刷** | **日常主力**：去油 + 把细菌刷走 |
| **开水冲烫 ≥80℃，20~30 s** | **真消毒**：用在 A 面和生刀之后 |

**还有第四件，别忘**：**洗完立起来晾干**。
干燥和开水烫同等重要——**一块永远湿的板，怎么洗都白洗**。

---

## 五、五条不要（最容易忘的就是这五条）

| # | 不要 |
| --- | --- |
| 1 | **不要刻板面做记号**（刻痕是永远刷不到的死角）→ 画在**侧边** |
| 2 | **不要只刷板的两个大面**（侧面那圈也沾了汁） |
| 3 | **不要共用刀套、共用抹布**（刀干净了套子是脏的＝白分） |
| 4 | **不要拿生刀切入口的东西**，哪怕"就切一下" |
| 5 | **不要把带汁的板平放在台面上**（台面一脏，后面放上去的都算沾到） |

> **竹木砧板不烫不泡**（会开裂，裂缝变永久藏污点）→ 只刷洗 + 晾到全干。
> **塑料砧板**可冲烫 20~30 s，但别整块泡沸水。

## 六、收尾六问（做完扫一眼）

- [ ] 切熟食用的是**熟刀**吗？
- [ ] 上板的东西，**A 面/B 面拿对了吗**？
- [ ] A 面用完，**侧面那圈刷了吗**？
- [ ] 板**立起来晾了吗**（不是平放）？
- [ ] 生肉盘和熟食盘，今天是**同一个**吗？
- [ ] 抹布/海绵，今天**擦过生肉区**吗？刀套混用了吗？

> 有一条答"是"，当天就不算过关——**不是"大概没事"，是"这一项没做"**。

---

## 七、贴在灶台边的那个提醒

**早上 60 min 的流程本来不需要刀，也不需要砧板。**
肉在 T1 已经切好分装，菜在前一晚已经切好入盒。

**刀或板一旦在早上出现，说明正在做流程外的事——那一刻就是警报。**
