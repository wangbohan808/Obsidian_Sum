# 记账仪表盘

> [!info] 本页用途
> 账期 = 每月 20 号发工资 → 次月 19 号，共 28–31 天。
> **发薪日当天先结清欠款、付下月房租，再领工资，然后才开新账期。** 所以房租不在任何账期的流水里（首期尤其如此），账期内固定支出只有 1,145。
> 每天花的钱写进 `9.记账/流水/YYYY-MM-20.csv`，本页自动统计。
> 参数在 [[预算参数]]，期初资金在 [[资金账户]]，改那两页这里自动重算。

## 怎么记一笔

打开当期流水 `9.记账/流水/2026-10-20.csv`，末尾加一行，七列英文逗号分隔：

```
2026-10-20,外卖,外卖,25,花呗,是,加班没做饭但还是点了
```

| 列 | 填什么 |
|---|---|
| 日期 | `YYYY-MM-DD` |
| 类型 | `固定` / `自炊` / `外卖` / `其他` / `收入` / `还款` |
| 分类 | 房租·水电·猫咪·话费·健身·AI·食材·外卖·日用品·**衣物**·交通·社交·医疗·其他 |
| 金额 | 纯数字，不要写 ¥ |
| 账户 | 余额宝 / 银行卡 / 花呗 / 白条 / **得物先用后付** / 现金 |
| 已做饭 | 外卖行必填 `是`/`否`，其他行留空 |
| 备注 | 不能有英文逗号 |

> [!warning] 三条不能破的规则
> 1. **还款不进支出**。还花呗记 `类型=还款`，看板会整个排除。消费当天已经记过了，再记一次就是双计。
> 2. **10/20 的工资不要记**。那 9,990 已经含在期初 33,000 里。从 11/20 那笔开始才记 `收入`。
> 3. **餐饮不必逐项记**。一天写一行 `49`，实际 55 就写 55。目标准确比明细准确重要。

## 每月 20 号要做的四件事

顺序就是实际的付款顺序：

1. **结清白条 / 花呗** → 记 `类型=还款`（不进支出）
2. **付下月房租 1,680** → 记 `固定 / 房租`，日期写发薪日
3. **工资到账** → 记 `收入`，金额填实际到手
4. **新建流水 `流水/YYYY-MM-20.csv`**，把第 1–3 笔写在最前面，之后日常逐笔追加

> [!warning] 只有首期（2026-10-20）例外
> 那天的还款、房租、工资都发生在 33,000 这个期初之前，**一笔都不记**。从 2026-11-20 起才按上面四步走。

对账：余额宝 + 银行卡实际总额 vs 看板「当前净资产」，差额超 200 就是有漏记。
