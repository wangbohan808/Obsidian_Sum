# 设备台账

> [!info] 用途
> 把散落的机型文件（HW1 / HW14R / HW6U / HWP6 / L15M / 海尔点激光系列 / 海尔欧洲 / 海尔水洗机泰国）
> 当成一张表来查。每台设备一篇笔记，本页只做汇总视图。
> 新设备：复制一篇空壳模板，填 `type/status/project/mastery/tags` 即可自动进表。

## 全部设备

```dataview
TABLE status AS 状态, mastery AS 熟练度, updated AS 更新
FROM "3.海能工作"
WHERE regexmatch("^(HW\d|HWP6|L15M|海尔点激光|海尔欧洲|海尔水洗机)", file.name)
SORT file.name ASC
```
