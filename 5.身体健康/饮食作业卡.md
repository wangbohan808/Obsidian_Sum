## 一、一周分两种早晨

| | **蒸饭日 · 一 / 三 / 五** | **炒饭日 · 二 / 四 / 六** |
|---|---|---|
| **起床** | **05:30** | **06:30** |
| **吃** | 现蒸杂粮饭 250 g ＋ **煎牛排 160 g / 三文鱼 125 g** | **炒饭**：隔夜饭 250 g ＋ **虾仁 150 g ＋ 蛋 2 个** |
| **做饭耗时** | **19 min**（煮饭 65 min 零占用） | **8 min** |

**周日**：放纵餐一顿，不设闹钟，但 **21:30 睡**。

## 三、杂粮配方（一次 200 g，出两天的份）

| 原料 | 每次 |
|---|---|
| **燕麦米** | **100 g** |
| **鹰嘴豆（干）** | **50 g** |
| 糙米 | 30 g |
| 黑米 | 20 g |
| **水** | **320 ml（1 : 1.6）** |

> **一次配 30 天的量混匀装罐，早上舀一勺。** 不比称纯糙米多一步。
> **不要用纯糙米替代**：同样 200 g，纯糙米蛋白 15 g / 纤维 7 g，这套配方 29 g / 18 g。

## 四、蒸饭日早上（一 / 三 / 五）

| # | 时刻 | 做什么 |
|---|---|---|
| **1** | **05:33** | 杂粮 200 g ＋ 水 320 ml（**泡豆水倒掉**）→ 按「**糙米饭**」 |
| **2** | 05:35–05:55 | **冥想 20 min**（煮饭在跑） |
| **3** | 05:55–06:15 | **出门散步 20 min** |
| **4** | **06:15** | **焯菜 300 g**：一半装碗、一半装午餐盒 |
| **5** | **06:38** | 饭好。**只盛两份**：早上 250 g 现吃 / **次日份 250 g 摊开进冷藏** |
| **6** | **06:41** | **煎牛排 160 g**（每面 1.5~2 min）／ 三文鱼 125 g |
| **7** | 07:10 | 早餐 ＋ 装午餐盒（菜一半 ＋ **凝胶冰盒**） |

> **次日那份是冷藏，不是冷冻。** 它第二天早上要用来炒饭，冻了来不及解冻。

## 五、炒饭日早上（二 / 四 / 六）—— 8 min

| # | 时刻 | 做什么 |
|---|---|---|
| **1** | 06:33–06:53 | 散步 20 min |
| **2** | 06:53–07:13 | 冥想 20 min |
| **3** | **07:13** | 锅热 → **虾仁 150 g**（擦干、1 g 油、0.3 g 盐）**炒散盛出** |
| **4** | | **蛋 2 个**炒散 → 下**隔夜饭** → 回虾仁 |
| **5** | | **炒到全部冒热气**（不是"表面热了"） |

> **蛋先炒散盛出，再下饭。不能把蛋液提前拌进冷饭**——那是产毒的最优基质。见第七条。

### 4. 每单备注两条

| # | 备注 |
|---|---|
| **1** | **酱汁另装**（沙拉酱 / 油醋 / 千岛一律分开） |
| **2** | **不加额外主食**（不另外加饭、不加面） |

### 5. 这条规则和深绿叶菜的关系

A.5 的 300 g 深绿叶菜是**早上焯、一半装午餐盒**。所以午餐自带一半菜，外卖的"轻蔬"只是补充。
**但早上没焯菜的那天，午餐必须点能量碗 / 谷物饭（自带西兰花），不能点荞麦面。**

## 七、六条不要（最容易忘的就是这六条）

| # | 不要 |
|---|---|
| **1** | **泡豆不要放室温**——必须冷藏，深圳室温泡一夜会发酸 |
| **2** | **隔夜饭不要连锅放一夜**——煮好 2 h 内盛出、摊开、进冷藏 |
| **3** | **炒饭不要剩**——只炒一次，炒了不剩，剩了不二次加热 |
| **4** | **蛋液不要提前拌进冷饭**——先炒蛋，再下饭 |
| **5** | **苹果胀就减半**——难受源是**产气**（山梨糖醇/果糖），不是酸；**垫着吃没用，只能减量** |
| **6** | **不要用混合每日坚果**——维 E 只有纯杏仁的 1/3 |

> **第 2–4 条的底层**：炒饭综合征的毒素**耐 126℃ / 30 min，复热杀不掉**。安全不靠"炒热"，靠**从出锅到入口全程不进温区**。

## 八、四个判据（不用温度计，用眼睛和手）

| 什么 | 判据 |
|---|---|
| **饭熟了** | 锅底无积水 · 米粒能捻开 · **鹰嘴豆一压就散** |
| **肉熟了** | 中心无血色、切开不流汁 |
| **菜** | 断生、颜色变深、茎能咬断 |
| **炒饭透了** | **中心冒热气**（不是表面热了） |

## 十一、前一晚怎么处理明天的肉（9 min）

**只用于：当天买回来的鲜肉、第二天要吃。** 冻过的肉（膜已破）**跳过第 1 步**，只吸干。

| # | 动作 | 关键 |
|---|---|---|
| **1** | 冷水泡 **5 min** | 只去表面血水。**别泡久**——肌纤维吸水，煎时出水变柴 |
| **2** | **厨房纸按压擦干** | **最关键的一步**。表面有水 → 油挂不住 → 明早煎不出焦面 |
| **3** | **片成 1.5~2 cm 厚片** | 3 cm 块会外老内生 |
| **4** | **盐 1 g** 抓匀（160 g 肉） | 过夜量是早上现腌的两倍 |
| **5** | 等 5 min，**把渗出的水倒掉/吸掉** | 漏这步 → 油被水推开，油封等于没做 |
| **6** | **油封 3~5 g** 抓匀 | 薄薄一层，多了明早溅油 |
| **7** | **加盖/装袋，放冷藏室最里侧**（不靠门） | 防串味、防风干、温度稳定 |

**三条红线**

| # | 不要 |
|---|---|
| **1** | **淀粉不要前一晚加**——冷藏一夜会沉降返水，明早**脱浆、粘锅、不脆**。淀粉是**下锅前 3 min** 的事 |
| **2** | **明早不要回温**——冷藏取出直接下锅 |
| **3** | **煎，不要炒**——炒要一直翻动，表面温度上不去、持续出水，鸡胸必柴 |

> 不想腌也行：**只擦干、冷藏**，明早一次性加 **1.5 g 盐 ＋ 5 g 淀粉**抓匀。
> 虾仁另一条：**150 g 是炒饭里 2~3 min 炒到变色**，不是煎 10 min。
