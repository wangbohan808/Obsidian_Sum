# 预算参数

> [!info] 这一页是看板的"输入"
> 改这里的数字，[[00_记账仪表盘]] 会自动重算。**不要在看板里改数**。
> 只有 `monthly_budget` / `fixed_total` / `rent` / `daily_allowance` / `disposable_income` / `food_daily` / `cycle_start_day` 这几个数字影响计算。

## 0. 账期定义（发薪日制）

| 项 | 值 |
|---|---|
| 账期起点 | 每月 **20 号**（发薪日） |
| 账期终点 | 次月 **19 号** |
| 账期长度 | 28–31 天，随月份浮动 |
| 账期标识 | 用起点日命名，如 `2026-10-20` 表示 10/20 – 11/19 |
| 流水文件 | `9.记账/流水/YYYY-MM-20.csv` |

**这是纯日历周期，不随实际结清日浮动。** 早一天晚一天结清都归到同一个账期里，否则账期长度不定，月度之间没法比。

### 0.1 边界：发薪日当天固定做完三件事

顺序不能变，因为它决定了「期初余额」是哪个时点的钱：

| 顺序 | 动作 | 归属 |
|---|---|---|
| ① | 结清白条 / 花呗 | 记 `类型=还款`，**永远不进支出** |
| ② | 付**下个月**房租 1,680（银行卡） | 发生在账期之外 |
| ③ | 工资 9,990 到账 | 发生在账期之外 |
| → | 剩下的余额 = 新账期第一秒的钱 | 期初快照 |

**核心结论：房租永远不在账期内发生。** 它是「付下个月、提前付」，所以在任何一笔账期流水里都不该出现房租 —— 它已经在账期开始前一秒被扣掉了。

于是：

```
账期内固定支出 = 2,825 − 1,680 = 1,145 元
账期内预算     = 1,145 + 57 × 天数
```

10/20–11/19 是 31 天 → 1,145 + 57×31 = **2,912 元**（这才是看板上的本期预算）

而全口径的月支出仍是 2,825 + 自炊 = **4,535**（30 天）/ **4,592**（31 天），只是其中 1,680 落在账期边界上。

### 0.2 账期内会发生什么

| 项目 | 时点 | 金额 |
|---|---|---|
| 水电 | 月底左右（账期第 10–12 天） | 250 |
| 猫咪饮食 | 月中 | 500 |
| 话费 8 + 29 + 39 | 月中 | 76 |
| 健身房月卡 | 月中 | 199 |
| AI 会员 | 月中 | 120 |
| **账期内固定合计** | | **1,145** |
| 餐饮 / 外卖 / 交通 / 日用品 | 每天 | 按实记 |

> [!note] 时点只是个大概
> 除了水电你明确说了在月底，其余四项按实际扣款日记就行。时点不影响月度合计，只影响看板前几天的「固定项已付」显示。

### 3.1 为什么从 49 涨到 57

| 变动 | 元/天 |
|---|---|
| 水果按实价（原按 4.9 记，实际苹果 6 ＋ 橙/猕猴桃 4） | **+5.10** |
| 牛里脊按里脊零售（原按牛霖批发价 70 元/kg 记） | **+5.74** |
| 油盐按实价（原按"橄榄油 1 瓶 15 元"记） | **+1.18** |
| 虾仁按次摊销（原表按 4.95 元/天算满 30 天） | **−2.14** |
| 坚果鱼日减量 ＋ 芝麻酱微调 | **−0.45** |
| **净变动** | **+9.43**（46.4 → 55.9；预算取 57 留 1 元缓冲） |

> **这不是"标准放宽"，是原表口径错。** 旧 §3 的结构「面粉 3 ＋ 生肉 25 ＋ 水果 5 ＋ 蔬菜 10 ＋ 坚果 4 ＋ 酱料油 2 ＝ 49」里**没有鸡蛋**（4 元/天），水果按 2.45 元/个、橄榄油按 15 元/瓶、虾仁不摊销。那套结构对应的是旧篮子，不是现在这个。

### 3.2 牛肉价格：50~70 元/kg 是批发价

| 部位 | 批发（元/kg） | 零售推算 |
|---|---|---|
| A 里脊 | 78 | 100~110 |
| 米龙 | 65 | 85~90 |
| **牛霖** | **61** | **80~95** |
| 眼肉 | 80 | 105~115 |

105.9 元/kg 原切里脊**落在零售正常区间中间**，不是买贵。零售端没有任何牛部位能做到 50~70 元/kg。原表拿"牛霖批发价"比"里脊零售价"，才得出"高出 51%~112%"的结论。

### 3.3 三条压缩线（超支时按顺序动）

|---|---|---|---|
| ① | 三文鱼 3 次/周 → 2 次 | −3.03 | EPA+DHA 6.2→4.1 g/周，仍高于推荐 1.75 |

## 4. 预算线

账期内（看板用的就是这个数）：

```
账期预算 = 1,145 + 57 × 天数
  · 31 天账期 = 2,912
  · 30 天账期 = 2,855
```

全口径（含边界那 1,680）：

```
月最低支出 = 固定 2,825 + 自炊 1,710 = 4,535 元
日可变额度 = (11,430 − 2,825) ÷ 30 = 287 元/天
月结余   = 11,430 − 4,535 = 6,895 元
储蓄率   = 6,895 ÷ 11,430 = 60.3%
年积累   = (11,430 × 12) − 54,420 = 82,740 元
```

> `daily_allowance` 287 是"固定支出扣完之后所有可变支出的日额度"，**自炊 57 在这 287 里面**，不是额外再加。
> 储蓄率从 62.4% 降到 60.3%，差额 240 元/月全部来自"苹果按实价 ＋ 蔬菜改 300g 深绿 ＋ 口径修正"，**不是新增消费项目**。

> 两个数不是矛盾：4,535 是「一个月总共花掉多少」，2,912 是「一个账期的流水里会出现多少」。差额 1,680 就是房租，它在账期开始前已经付了。


## 5. 未列项预备金（重要）

上面 4,535 是"清单口径"，不是真实底线。以下项目必然发生，暂按 **650 元/月** 预留：

| 类别 | 估算/月 |
|---|---|
| 日用品（纸品、洗护、清洁） | 100 |
| 通勤交通 | 200 |
| 理发、衣物（年均摊） | 180 |
| 猫砂 / 疫苗 / 驱虫 / 看病 | 100 |
| 医疗、其他零散 | 70 |

**真实底线 ≈ 5,185 元/月**，对应结余约 6,245 元。记账三个月后，用实际数据替换这里的估算值。

> **首月例外（2026-10-20 ~ 11-19）**：还有一笔**备餐启动采购**（保鲜袋百只装、记号笔、厨房纸、保鲜盒、调味料），约 300~400 元，一次性，**记在流水里但不算食材**，否则第一个月的 `food_daily` 会被冤枉超支。

## 6. 迟到早退（唯一可完全消除的支出）

月均 150 元 = **年 1,800 元**。相比它在预算里的占比，更重要的是它的性质：这是唯一一项**只要按点到岗就自动归零**的钱，既不是消费也不是投资。

如果连续 3 个月做到零扣款，相当于月可支配从 11,430 涨到 11,580，日额度从 287 涨到 292。
