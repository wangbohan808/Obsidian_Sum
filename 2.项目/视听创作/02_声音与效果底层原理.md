# 声音与效果 · 底层原理

> **一句话核心：音乐制作只有三层——物理层（声音是什么）、信号层（声音怎么流）、结构层（声音怎么排）；所有效果器都在物理层的四个维度上动手，软件的一切都是这三层之上的便利化。**

> 缘起：2026-11-11。本人反馈"乐理底层理解不深，导致 AUX / 混响 / 采样器 / 效果器这些概念无法吸收"，并提出判断——**做音乐的基础逻辑很简单，软件只是对基础逻辑的拓展**。本篇即为那个"基础逻辑"。
> 用途：遇到任何一个不认识的功能，回到本篇判断它属于哪一层、动的是哪条轴。

---

## 零、三层框架

| 层 | 内容 | 软件里长什么样 | 决定什么 |
|---|---|---|---|
| **物理层** | 声音是什么：频率、振幅、时间、相位 | 所有音色与效果 | 听起来"对不对" |
| **信号层** | 声音怎么流动：源 → 处理 → 汇总 → 输出 | 轨道、Insert、Send、Bus、Aux | 听起来"清不清楚" |
| **结构层** | 声音怎么排：分层 × 分段 | 编曲、编排、和弦 | 听起来"好不好" |

乐理之所以重要，是因为它决定**结构层填什么内容**。效果器之所以难懂，是因为没人告诉你**它们只在物理层的四条轴上动手**。

---

## 一、效果器的四条轴（总纲）

| 轴 | 改什么 | 代表效果器 |
|---|---|---|
| **频谱** | 明暗、色彩 | EQ、滤波器、失真、饱和、激励器 |
| **振幅** | 起伏、响度 | 压缩、限幅、噪声门、扩展、瞬态整形 |
| **时间** | 重复、模糊 | 延迟、合唱、镶边、混响、变调、时间伸缩 |
| **空间** | 左右、远近 | 声像、立体声宽度、混响尾巴 |

**混响同时跨时间与空间**——所以它听起来最像"真实房间"。合唱与延迟也跨了两条轴（时间 + 音高）。

> 判断法：拿到一个不认识的效果器，先问"它动的是哪条轴"，它就不再是黑盒。

## 二、信号层：Insert / Send / Aux / Bus

### 1. 四个词的关系

这四者描述的是**同一套管道系统的不同部位**：

| 词 | 是什么 | 一句话 |
|---|---|---|
| **Bus（总线）** | 一条"汇流管道" | 多路信号汇成一路的节点，用编号区分（Bus 1、Bus 2…） |
| **AUX（辅助）** | 一条通道的**角色** | 专门装"共享效果器"的通道，靠某条 Bus 接收信号 |
| **Send（发送）** | 一个**动作** | 从当前轨"抄一份"信号，送到某条 Bus |
| **Effect（效果器）** | 处理 | 挂在 Insert（轨内）或 Aux（共享）上 |

> **关键澄清**：Bus 和 Aux 不是两种东西，是一条管道的两头。"Send 到 Bus 3" 与 "Aux 3 上挂着混响" 讲的是同一根管道——**Bus 是编号，Aux 是用途**。

**自来水比喻**：主管道（Bus）上装一台净水器（效果器），各房间的水龙头（轨道）接一根细管（Send）抽一点水进去过滤，过滤完汇回总出口。

### 2. 完整信号路径

```
音源（乐器 / 音频）
  → Insert（串联，这条轨专属）
  → Fader（推子，音量）
  → ┬→ Output（干声直出）
    └→ Send（并联，抽一份）→ Aux（共享效果器）→ Output
                                    ↓
                                 Master（主推子 + 总线效果 + 电平表）
```

### 3. 为什么混响要用 Send，不直接挂 Insert

| 理由 | 说明 |
|---|---|
| **省算力** | 5 条人声共用一个混响，只算一遍 |
| **统一空间** | 同一个混响让所有声音听起来"在同一房间" |
| **干湿可独立控制** | 推子决定多响，Send 量决定多"远"，互不干扰 |
| **可单独处理湿声** | 在 Aux 上切掉混响的低频（避免糊），不影响干声 |

### 4. Pre / Post Fader 的差别

| 模式 | 行为 | 什么时候用 |
|---|---|---|
| **Post Fader**（默认） | 送出的量跟着推子变：推子拉低，混响也变小 | 常规做法，符合直觉 |
| **Pre Fader** | 送出的量固定，不受推子影响 | 需要"声音消失但混响还在"的特殊效果 |

## 三、混响：它在物理上是什么

### 1. 三段结构

耳朵听到的从来不只是"声音本身"：

```
振幅
│█              直达声（最先到，最响）
│ ▎▎▎           早期反射（撞墙回来，几个离散尖峰）
│    ╲╲╲╲
│        ╲╲╲╲╲╲╲____   混响尾巴（密集反射叠加，指数衰减）
└───────────────────────→ 时间
  ├──┤├──┤├──────────┤
  pre   ER        decay
```

| 段 | 是什么 | 提供什么感知 |
|---|---|---|
| **直达声** | 从声源直接到你耳朵 | 定位、清晰度 |
| **早期反射** | 撞到近处墙面回来的几次 | 房间形状、距离感 |
| **混响尾巴** | 无数次反射混叠、逐渐衰减 | 空间体积、氛围 |

### 2. 参数与物理量一一对应（不用背）

| 参数 | 物理含义 | 调它等于 |
|---|---|---|
| **Pre-delay** | 直达声到第一次反射的时间 | 声源离墙更远（人声常用 20–40ms 避免糊） |
| **Decay / Reverb Time** | 尾巴衰减到 -60dB 的时间 | 房间更大、更空 |
| **Size** | 空间尺寸 | 小房间到大教堂 |
| **Damping / HF Damp** | 高频衰减更快 | 软装多、空气吸高频（调高更"暗"更自然） |
| **Diffusion** | 反射密集程度 | 墙面越粗糙，反射越密 |
| **Early Reflections** | 早期反射的强度 | 近处反射面的存在感 |
| **Wet / Dry** | 干湿比 | 声源在房间"里面"还是"外面" |

### 3. 算法混响 vs 卷积混响

| 类型 | 原理 | Logic 插件 | 特点 |
|---|---|---|---|
| **算法混响** | 用数学延迟网络实时合成 | ChromaVerb、PlatinumVerb | 参数全可调，CPU 轻 |
| **卷积混响** | 用真实空间的**脉冲响应（IR）** 做卷积运算 | Space Designer | 最真实，但不可"调房间" |

**IR（Impulse Response）是什么**：在那个空间里"拍一下手"录下来的结果，即该空间的**声学指纹**。

> 关联：外接盘上 897MB 的 `Impulse Responses` 目录，就是几百个真实空间（音乐厅、教堂、板式房间、吉他音箱等）的指纹库。

## 四、压缩：自动音量控制

### 1. 四参数

| 参数 | 含义 | 人话 |
|---|---|---|
| **Threshold** | 超过多少 dB 才开始压 | 从哪个音量开始管 |
| **Ratio** | 超过后输入涨 N dB，输出只涨 1 dB | 管得多狠。4:1 = 压掉 3/4 |
| **Attack** | 多快开始压 | **决定"打击感"** |
| **Release** | 多快恢复 | 决定"呼吸感"，太短会抽气 |
| **Knee** | 拐点软硬 | 硬拐点更"利"，软拐点更"自然" |
| **Makeup Gain** | 补偿增益 | 压完变轻了，补回来 |

### 2. Attack 快慢是最反直觉的一点

| Attack | 效果 | 用在 |
|---|---|---|
| **慢（20–50ms）** | 放过最响的音头，只压尾巴 → **音头突出 = 更有打击感** | 鼓、拨弦、需要"咬"的声音 |
| **快（1–5ms）** | 音头一出来就被压平 → **更平滑、更"贴"** | 人声、贝斯、需要"稳"的声音 |

### 3. 为什么用压缩（按重要性）

1. **让人声每个字都听得清**（不用手动画音量曲线）
2. **增加密度**：压完补增益，整体更响更"实"——这是"商业味"的来源之一
3. **塑造音头**（见上表）
4. **粘合**（Bus 压缩）
5. **侧链**：用另一个信号触发压缩。经典用法是底鼓一响就压贝斯 → 低频不打架

### 4. Bus 压缩的本质：共享增益衰减

把多条轨先汇到一条 Bus，再在这条 Bus 上挂压缩器。

> **原理只有一句**：压缩器看的是"总电平"。所以多条声音响的时候一起被压、轻的时候一起被放开——它们的起伏被**同一条曲线**控制（业内叫 **shared gain reduction**）。结果是"粘合"：几个各自起伏的声音，听起来像**一个人在演奏**。

**比喻**：几个人合唱，你用一只手统一压他们的音量。因为他们被同一只手控制，节奏起伏同步了，听起来就像一个声部。

**典型用法**：鼓 Bus（kick 与 snare 咬合）、人声 Bus（主唱与伴唱融合）、整个混音的 Bus（总线压缩）。

## 五、效果器全景（按四轴归类 + 原理一句话）

| 效果器 | 轴 | 原理 |
|---|---|---|
| **EQ** | 频谱 | 滤波器：对某频段加或减。低切去不需要的低频，高切去刺耳的高频 |
| **失真 / 饱和** | 频谱 | **非线性**：把波形顶削平，削出的棱角就是新高次谐波 → 更亮、更"脏"、更厚 |
| **激励器** | 频谱 | 专门生成高频谐波，制造"空气感" |
| **共振峰 / 声码器** | 频谱 | 用一个声音的频谱包络去塑造另一个声音 |
| **压缩** | 振幅 | 超过阈值自动降音量，压扁动态 |
| **限幅 Limiter** | 振幅 | 比率 ∞:1 + 快启动，只当"天花板"，防爆音 |
| **噪声门 Gate** | 振幅 | 低于阈值完全切断（去底噪、做节奏断点） |
| **扩展器** | 振幅 | 反向压缩：小的更小、大的更大（恢复动态） |
| **延迟 Delay** | 时间 | 复制信号，推后一段时间再放 |
| **合唱 Chorus** | 时间 + 音高 | 短延迟（15–35ms）+ LFO 让延迟时间微变 → 音高微飘 → 像多人同唱 |
| **镶边 Flanger** | 时间 + 相位 | 更短延迟（1–10ms）+ 反馈 → 梳状滤波，"扫过去"的喷气声 |
| **相位器 Phaser** | 相位 | 全通滤波器 + LFO，移动陷波位置 |
| **混响 Reverb** | 时间 + 空间 | 密集反射的叠加，或卷积真实空间 |
| **声像 Pan** | 空间 | 左右声道电平比 |
| **立体声宽度** | 空间 | 中侧（M/S）处理：放大差异成分，让声音变宽 |
| **变调 / 时间伸缩** | 频率 / 时间 | 变速播放，或相位声码器、颗粒重排 |

## 六、音色的构成：泛音、包络、共振峰、时变

### 1. 为什么同一个音高听起来是不同乐器

> 基频决定"你听到的是哪个音"，**泛音构成 + 包络决定"这是什么乐器"**。

```
泛音列（横向 = 频率）
│▌  基频（最强）
│  ▎  ▎   ▎    ▎     ▎      ▎     ← 谐波，逐级减弱
└────────────────────────────→
  泛音越高、越强 → 越亮
  泛音少而弱   → 越暗、越"圆"
```

```
包络 ADSR（横向 = 时间）
│   ╱╲
│  ╱  ╲________
│ ╱            ╲
└─A──D────S─────R──→
```

| 参数 | 含义 |
|---|---|
| **A** Attack | 从 0 到最大音量要多久 |
| **D** Decay | 从最大降到保持电平要多久 |
| **S** Sustain | 按住不放时保持的电平 |
| **R** Release | 松手后多久完全消失 |

**实例对照**：钢琴 = 快起、快衰、几乎无保持；弦乐 Pad = 慢起、长保持、慢收。

> **一句话总纲**：采样器是"直接录下这两样东西"，合成器是"用数学生成这两样东西"。这就是全部区别。

### 2. 决定音色的四个要素（按重要性）

| 序 | 要素 | 作用 | 人耳敏感度 |
|---|---|---|---|
| 1 | **谐波幅度分布** | 明暗、质感的主体 | 极高 |
| 2 | **起音包络（前 20–50ms）** | **决定"这是什么乐器"** | 极高 |
| 3 | **共振峰（formant）** | 决定"谁在演奏"，不随音高变化 | 高 |
| 4 | **时变 + 非谐波成分** | 决定"自然是还是假" | 中高 |

**共振峰**：乐器或人声腔体的**固定共振频率**。它不随音高移动，所以唱高音时别人仍认得出是你的声音。**人声元音 a / e / i 的本质就是三组不同的共振峰模式。**

**非谐波**：钟、鼓、金属的泛音**不是整数倍**，所以听起来"无明确音高"或"有金属感"。这也是这类声音适合采样、不适合合成的原因。

> **推论**：合成器难做到像真实乐器，不是泛音不对，而是**造不出真实的起音噪音**（槌击、拨弦、弓毛摩擦、气声）。这也解释了为什么采样器里"极短的音"最难做。

### 3. 一个周期不够：音色是三段频谱

**"取一个周期做傅里叶"只在稳态段成立。** 真实声音里严格周期性的部分很短：

| 阶段 | 是否周期 | 原因 |
|---|---|---|
| **起音（0–50ms）** | **否** | 能量急剧增长 + 撞击/摩擦噪音 |
| **稳态** | 近似是 | 振幅恒定，波形重复 |
| **衰减** | **否** | 振幅一直在变（周期信号要求幅度恒定） |
| **颤音 / 揉弦** | **否** | 周期长度本身在波动 |
| **鼓 / 气声 / 雨声** | **完全否** | 无周期，只有噪音 |

所以分析的框架要按段拆：

| 分析对象 | 用什么 | 得到什么 | 决定什么 |
|---|---|---|---|
| 稳态段 | FFT（较长窗口） | 离散谐波柱 | 明暗、质感 |
| 起音段 | 短窗口 / 波形观察 | 连续谱 + 噪音 + 上升斜率 | **是什么乐器** |
| 衰减段 | 多帧连续分析 | 频谱随时间的变化 | 自然还是假 |
| 噪音类 | FFT（看整体包络，不看单柱） | 频谱包络 | 鼓、气声的"材质" |

> **只看稳态会以为合成器能模仿一切；加上起音与衰减才发现，真实感主要藏在无法用单个周期表示的地方。**

**顺带纠正一个更根本的误解**：音高不是"最低频率"决定的。只播放 440 / 660 / 880Hz（不含 220Hz 基频），人耳听到的音高仍是 220Hz——这叫**缺失基频**（missing fundamental）。所以准确说法是：**音高由波形的周期性（谐波间距）决定，而非"哪个频率最强"**。

### 4. 相位：被丢掉的那一半

一个周期做完变换得到两样东西：**幅度谱 + 相位谱**。"音色由谐波幅度决定"这个说法，本身已经在做简化——**只留幅度、丢掉相位**。

这个简化对人类听觉成立（相位聋），但对两件事**不成立**：

| 场景 | 相位的作用 |
|---|---|
| 单声道、单个稳态音 | 几乎没有影响，听不出 |
| **起音瞬间（瞬态）** | 有影响，会改变音头的锐利度 |
| **多轨叠加 / 立体声** | **极其关键**。频率相同、相位差 180° 会互相抵消，声音变薄甚至消失 |

> **结论**：**音色感知 ≈ 幅度谱；波形生成 = 幅度谱 + 相位谱。**
> 混音里天天说"相位"，说的不是音色问题，是**叠起来会不会打架**的问题。贝斯与底鼓叠完低频消失，八成就是相位抵消。

### 5. 没有周期的声音怎么办

鼓、镲、气声、雨声**根本没有周期**，无法"取一个周期"。它们的音色由**频谱包络**（spectral envelope）决定：**不看具体哪几根谐波柱，而看整个频谱的形状趋势**。

> 所以合成器造鼓的方式是"**噪音发生器 + 滤波器**"：用滤波器的形状去塑造噪音的频谱包络。这也是造鼓不需要音高的原因。

### 6. 四种造音方式

| 方式 | 怎么产生泛音 | Logic 代表 | 典型音色 |
|---|---|---|---|
| **采样** | 直接录真实声音 | Quick Sampler、Sampler (EXS24) | 真实乐器、鼓、音效 |
| **减法合成** | 振荡器产生富泛音的波 → 滤波器削掉不需要的 | ES2、Retro Synth (Analog) | Lead、Bass、Pad |
| **波表合成** | 预存一堆波形，在之间滑动切换 | Retro Synth (Wavetable)、Alchemy | 会"动"的电子音色 |
| **FM 合成** | 一个振荡器调制另一个的频率 → 大量非谐波泛音 | Retro Synth (FM)、EFM1 | 金属感、钟声、电钢 |
| **加法 / 频谱** | 直接叠加多个正弦，逐个控制强度 | Alchemy | 极精确的音色塑形 |
| **颗粒合成** | 把采样切成毫秒级碎片重新排列 | Alchemy | 氛围、Texture、非常规音响 |
| **物理建模** | 用数学模型模拟弦 / 管 / 膜的振动 | Sculpture | 逼真独奏弦乐、奇特共鸣体 |

### 7. 从波形反推物理模型

> **核心公式**：**声音 = 激励源 × 共振系统**（输出频谱 = 激励频谱 × 传递函数）。
> 这是"音色的物理模型"唯一的实用形式，整个音频工业都建在这条乘法上。

| 声音 | 激励源（谁在振动） | 共振系统（谁在塑形） |
|---|---|---|
| 提琴 | 弓毛摩擦 / 拨弦 | 琴板 + 空气腔 |
| 管乐 | 气流湍流 | 管内空气柱驻波 |
| 人声 | 声带脉冲（基频 + 噪音） | 声道（元音 = 三组共振峰） |
| 鼓 | 槌击脉冲 | 鼓腔各阶模态 |
| 合成器 | 振荡器 / 噪音发生器 | 滤波器 |

**为什么必须拆成两项**：频域上它是乘法，**取对数后变成加法，变成加法才能分离**。四条反推路径都在这条线上。

**先澄清一个前提**：时域和频域不是两种数据，是同一份数据的两种写法。FFT 除相位外完全可逆，所以"录音在时域"不构成障碍。真正的障碍是另一件事——**你测到的是响应，测不到系统**。频谱是结果，模型是原因。

| 方法 | 做什么 | 得到什么 | 局限 |
|---|---|---|---|
| **FFT** | 直接看谱 | 一份频谱 | 激励与共振混成乘积，只是"指纹"不是"模型" |
| **倒谱 cepstrum** | 对**对数谱**再做一次 FFT | 快变化（谐波间距）与慢变化（共振包络）分离 | 丢相位；瞬态仍被抹平 |
| **LPC 线性预测** | 解 `x[n] ≈ Σaᵢx[n-i]` 的系数 | 一个全极点滤波器，**极点即共振峰** | 只适合准稳态段（人声、单音） |
| **模态分析** | 给已知激励，测自由衰减 | 每阶模态的 **f / ζ / A** | 需要可控激励；给振动特征，不给材料与几何 |

**倒谱的直觉**：对数谱上，谐波是"快起伏"，共振峰包络是"慢趋势"。把这条曲线本身当成一个信号再做变换，快慢就被推到轴的两端——**一次变换，两个因子分开**。（商业化形态就是 MFCC，语音识别的标准特征。）

**模态分析的三个参数**：

```
敲一下 → 测响应 → 每个共振峰拆出三个数
   f     谱峰位置          振得多快
   ζ     包络衰减率        材料内耗（-60dB 需多久）
   A     峰值高度          被激励起多少
```

这三个数就是"这个物体怎么振"的完整描述，物理建模合成器（Sculpture）底层即此。

> **必须承认的一条**：声音 → 物理是**欠定反问题**，没有唯一解。无穷多个物理系统能产生几乎相同的声音。所以工程上不追求"解释它从哪来"，只追求"**哪组参数能重新产生它**"。前者无解，后者有解。

**这个转向对应软件里的四种取舍**：

| 工具 | 策略 | 代价 |
|---|---|---|
| 采样器 | 不建模，直接存波形 | 不能改；变调必然变速；占空间（62GB 的来源） |
| 减法合成 | 用粗糙模型拟合（振荡器 + 滤波器 + ADSR） | 造不出真实起音噪音 → 不像真乐器 |
| 物理建模（Sculpture） | 真解振动方程，参数即物理量 | 参数极敏感、难调、吃 CPU |
| 频谱再合成（Alchemy） | 从录音反推参数集（倒谱 / LPC 那条路） | 丢瞬态，"像但有塑料感" |

**一个能立刻验证的现象**：用 Alchemy 对一段人声做频谱再合成，然后减少谐波数量。你会听到**稳态段几乎一样，起音段明显不对**。这恰好印证第 3 小节：**稳态可以被参数化，瞬态不能**——非周期的那部分，是数学描述不进去的。

这也解释了工业界的现实答案是"**采样 + 合成混合**"（Sampler 里叠一层合成器补起音），而不是纯建模。

## 七、四个音源工具：什么时候用哪个

### 1. Quick Sampler

**拖任何音频进去都能变成可演奏乐器，但代价是"变速"**。

采样器变音高只有一种手段：**改变播放速度**。

- 播放速度 ×2 = 音高 +12 半音（一个八度）= **时长 ÷2**
- 拖一段 5 秒人声，弹高八度 → 变 2.5 秒、音色变"花栗鼠"
- 弹低两个八度 → 20 秒的沉闷拖长音

| 模式 | 行为 | 用在 |
|---|---|---|
| **Classic** | 键盘映射全音域，变速变调 | 单一音色演奏（贝斯、Lead） |
| **One Shot** | 不分音高，按一下完整播一遍 | 鼓、音效、一句话 |
| **Slice** | 自动检测瞬态切片，每片一个键 | 鼓组拆分、节奏重排 |

> **结论**：适合鼓、音效、人声切片、短促单音；**不适合需要长时间保持的持续音**（Pad、弦乐铺底），因为拉伸会失真。

### 2. Sampler（EXS24）

**为什么需要它**：一个样本跨 4 个八度会严重失真。真实乐器要"多采样"：

| 机制 | 作用 |
|---|---|
| **Key Zone（音区映射）** | 低/中/高音区各用独立录音，每个只负责两三个半音 |
| **Velocity Layer（力度层）** | 同一个音，轻弹与重弹用**不同录音**（真实乐器音色确实随力度变） |
| **Round Robin（轮换）** | 同音连弹三次用三个样本轮流，避免"机关枪"式机械重复 |

一个像样的钢琴音色背后可能有 **100 多个音频文件**。Sampler 就是管理这套映射的容器；Quick Sampler 是它的简化版（1 到几个样本）。

### 3. Alchemy

Logic 旗舰合成器，**一台机器里装了六种引擎**（加法 / 波表 / 颗粒 / 采样 / FM / 鼓），3000+ 预设。

- **场景**：Pad、Texture、氛围、音响设计、影视配乐
- **为什么用它**：做"会动、会呼吸、会变化"的音色最强
- **学习建议**：**先用预设改**，Month 2 之后再自己搭

### 4. Retro Synths（一族）

模拟经典硬件与物理建模的合成器集合：

| 插件 | 类型 | 场景 |
|---|---|---|
| **ES2** | 老牌减法合成 | Bass、Lead、Pad |
| **Retro Synth** | 一机四模式：Analog / Sync / Wavetable / FM | 通用电子音色，参数少、上手快 |
| **Sculpture** | 物理建模（模拟弦/管/膜振动） | 逼真独奏弦乐、奇特共鸣体（进阶） |
| **EFM1** | FM 合成 | 电钢、钟声、金属感 |

### 5. 减法合成的完整链条（所有合成器的通用骨架）

```
振荡器（产生富含泛音的波：锯齿 / 方波 / 三角）
  → 滤波器（削掉泛音 → 决定明暗）
  → 包络 ADSR（决定音量随时间怎么变 → 决定"性格"）
  → 效果（混响、延迟、失真）
```

四个环节，正好对应 Retro Synth 面板上的四块区域。看懂这个，任何合成器界面都不再陌生——它们只是这四块的变体。

## 八、音视频处理的对应关系（同一套数学）

用户提出的类比，方向是对的，而且能一路对应：

| 图像 / 视频 | 音频 | 共同的数学本质 |
|---|---|---|
| 高斯模糊 | 混响 / 低通滤波 | 用周围的值平滑当前值 |
| 锐化 | EQ 高频提升 / 激励器 | 放大高频差异 |
| 对比度调整 | 压缩 | 重新映射动态范围 |
| 局部蒙版 | 侧链 | 只让处理作用于局部 |
| 帧混合 / 运动模糊 | 延迟 / 混响 | 时间维度上的"涂抹" |
| 色彩曲线 | EQ 曲线 | 同一条映射曲线的两种感官 |
| 多图层 Alpha 混合 | Bus 汇总 / 叠加 | 加权求和 |
| 卷积核扫描像素 | 卷积混响扫描采样 | **同一个运算**，维度不同 |

> **唯一的本质差异**：图像是**二维空间**上的采样，音频是**一维时间**上的采样。所以图像的"邻居"是上下左右的像素，音频的"邻居"是前后几个采样点。**所有音频效果器，本质上都是"对时间轴上相邻采样做运算"。**

这也解释了为什么混响能用卷积实现：卷积就是"拿一个模板扫过整段信号"，和图像里用一个卷积核扫过像素是同一个运算。

## 九、学习顺序（按依赖关系，不按菜单）

| 序 | 学什么 | 为什么排在这 |
|---|---|---|
| 1 | **泛音 + ADSR** | 先理解"音色"是什么，合成器面板才有意义 |
| 2 | **EQ** | 最简单，只有一个动作：加或减某频段 |
| 3 | **压缩** | 第二简单，只有一个动作：超过阈值就压 |
| 4 | **Send / Aux / 混响** | 理解信号流，才能理解"空间" |
| 5 | **Bus 压缩** | 第 3 与第 4 的组合 |
| 6 | 其余全部 | 遇到具体问题再学 |

## 十、常见误解纠正

| 误解 | 实际 |
|---|---|
| AUX 和 Bus 是两种通道 | 同一条管道的两端：Bus 是编号，Aux 是用途 |
| 混响越多越好听 | 混响是"距离"，多了会让声音后退、发糊。人声通常 Send 到 -12dB 左右开始试 |
| 压缩会让声音变小 | 压缩本身会降峰值，但配合 Makeup Gain 后是**变大、变实** |
| 采样器能"任意变调不变速" | 变速是变调的唯一手段，除非上时间伸缩算法（会有音质代价） |
| 合成器比采样器高级 | 两者是两条路：要真实用采样，要电子用合成 |
| 效果器越多越专业 | 每条轨 2–3 个够用。堆效果器通常是没找到问题根源 |
| **音色差异来自相位组合** | 来自**谐波幅度分布**。相位随机打乱后听感几乎不变（相位聋）；相位影响的是瞬态与多轨叠加，不是音色识别 |
| **一个音在时域必然周期性** | 只有**稳态段**近似周期。起音、衰减、颤音、鼓/气声都不是，而音色识别最依赖起音那段 |
| **取一个周期做傅里叶，就能得出音色** | 那是傅里叶**级数**，且会丢掉相位。软件用 FFT 对**窗口**做；且一个窗口只看得到稳态，要看起音与衰减得用多帧分析 |
| **音高由最低频率决定** | 由**谐波间距（周期性）**决定。缺了基频，人耳仍能补出正确音高（missing fundamental） |
| 频谱就是声音的物理性质 | 频谱是**物理结构对激励的响应**，不是性质本身。性质是张力、长度、阻尼、共振腔形状 |
| **录音在时域，所以得不出频域的音色模型** | 时域与频域是**同一份数据的两种写法**，FFT 除相位外完全可逆。真正的障碍是"测得到响应，测不到系统" |
| **频谱可以直接当物理模型用** | 频谱是**乘积的结果**（激励 × 共振），两个因子混在一起。必须靠倒谱 / LPC / 模态分析把它拆开，才能生成而不只是识别 |
| **每个声音都有唯一对应的物理模型** | 声音 → 物理是**欠定反问题**，无穷多个系统能产生几乎同一声音。工程上只求"能重新产生它的参数集"，不求唯一解释 |
