# 骑行

> **一句话定位：骑行是自向类爱好——留白、陶冶、换脑，不背"拓展圈子"的 KPI。**

## 一、定位（2026-10-26 定）

| 项 | 结论 |
|---|---|
| 类别 | **自向**（对照 [[20.爱好与圈子·三本账与场地判据]] 的两把尺子） |
| 功能 | 周日上午的留白 / 陶冶 / 换脑，与钢琴同档 |
| 落点 | 周日上午（`15.作息与周节奏` 执行表 C 的"自由"格） |
| 成败标准 | **骑完是不是松下来了**，不是配速、不是里程 |
| 明确不做 | 车队化、按巡航速度定目标、"练到能跟上再进群" |

## 二、为什么不拿它拓圈

- 骑行是**完全可以不说话就完成**的项目——社交是可选配件，不是必需件；
- 车队**按巡航速度分组**，社交货币是"你能跟上"，体能不够时唯一选项是自己骑；
- 所以它的社交入口会**随水平关闭**，而不是打开。与攀岩正好相反（越菜越有人给你讲线）。

> 详细对照见 [[20.爱好与圈子·三本账与场地判据]] §四。**如果哪天真想从骑行上认识人，那是新增一个场地（车店群骑），不是升级骑行本身。**
