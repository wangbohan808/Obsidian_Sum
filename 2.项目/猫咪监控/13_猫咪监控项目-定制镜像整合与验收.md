# 13 猫咪监控项目：定制镜像整合与验收

> 目标：把"内核裁剪 + AI 运行时 + 猫监控应用 + 网络上传"全部固化进**一个可烧录的最简镜像**。
> 主推：**BSP 定制内核 + rsdk 组装**（文档 01 + 04 + 06 的落地版）；
> 备选：Buildroot 极简固件（文档 03）、Yocto 可复现流水线（文档 02）。

---

## 1. 方案选择矩阵（本项目的最终决策）

| 需求权重 | rsdk（主推） | Buildroot（备选） | Yocto（进阶） |
| --- | --- | --- | --- |
| 开发速度（1-5） | 5 | 3 | 2 |
| AI 生态（rknn/gstreamer 包） | 5（apt 直装） | 3（需 overlay 拷贝） | 3（需写 recipe） |
| 体积最小 | 3（数百 MB） | 5（几十 MB） | 4 |
| 驱动裁剪粒度 | 3（包级） | 5（内核+包级） | 4 |
| 简历展示价值 | 高 | 高 | 很高 |

**结论**：主方案 rsdk；Buildroot 作为"超小体积演示固件"第二产出；Yocto 作为可复现流水线第三产出（时间允许时）。

## 2. 定制内核（BSP）——所有方案共用

### 2.1 内核裁剪清单（本项目）

编辑 `/home/wbh808/bsp/linux/rk2410/kconfig.conf`，追加：

```text
# ===== 猫监控项目驱动清单 =====

# --- 必须保留（启动与核心功能）---
CONFIG_MMC=y                    # eMMC/SD
CONFIG_MMC_DW_ROCKCHIP=y
CONFIG_USB_XHCI_HCD=y           # USB（UVC 摄像头/外设）
CONFIG_USB_DWC3=y
CONFIG_SERIAL_8250_DW=y         # 串口调试
CONFIG_ETH=y / CONFIG_STMMAC_ETH=y          # 千兆网
CONFIG_WLAN=y
CONFIG_AIC8800_WLAN_SUPPORT=y   # WiFi（以实际 config 名称为准，见 defconfig）
CONFIG_ROCKCHIP_RKNPU=y         # NPU
CONFIG_VIDEO_ROCKCHIP_CIF=y     # MIPI 摄像头（若用 USB 可保持开启无妨）
CONFIG_VIDEO_ROCKCHIP_ISP=y
CONFIG_VIDEO_ROCKCHIP_ISPP=y
CONFIG_VIDEO_IMX219=y           # 若用 IMX219
CONFIG_USB_VIDEO_CLASS=y        # USB UVC
CONFIG_VIDEOBUF2_DMA_CONTIG=y
CONFIG_ROCKCHIP_MPP_SERVICE=y   # 硬件编解码（VEPU）
CONFIG_VIDEO_ROCKCHIP_VEPU=y
CONFIG_VIDEO_ROCKCHIP_RGA=y     # RGA 硬件缩放
CONFIG_DRM_ROCKCHIP=y           # 显示（保留以防调试接 HDMI；无显示需求可后续裁剪）
CONFIG_WATCHDOG=y
CONFIG_DW_WATCHDOG=y

# --- 可裁剪（本项目不用，逐步验证后注释掉）---

# CONFIG_SND_SOC_ROCKCHIP is not set   # 不用板载音频（用 USB 麦时保留 SND_USB_AUDIO）

# CONFIG_BT is not set                  # 不用蓝牙

# CONFIG_PCIE_ROCKCHIP is not set       # 不用 PCIe（NVMe 需要时保留）

# CONFIG_DRM_PANEL_* is not set         # 不用外接屏（保留 HDMI 则别删 DRM 核心）
```

> 裁剪原则（文档 06 强调）：**先全量构建跑通，再逐项关闭并烧录验证**；PMIC/时钟/GPIO/CPU 频率等基础设施驱动绝不能关。

## 4. 主推方案：rsdk 组装最终镜像

### 4.1 定制 rootfs.jsonnet（增补内容，保持原文件其他部分不动）

文件：`/home/wbh808/rsdk/src/share/rsdk/build/rootfs.jsonnet`

在 `packages+:` 数组追加：

```jsonnet
packages+:
[
    // ===== 猫监控项目 =====
    "rknpu2-rk3588",               // NPU 用户态 + udev（Radxa 源，提供 librknnrt.so）
    "python3-rknnlite2",           // RKNN-Lite2 Python API（Radxa 源，已核实存在，免装 wheel）
    "gstreamer1.0-tools",
    "gstreamer1.0-plugins-base",
    "gstreamer1.0-plugins-good",
    "gstreamer1.0-plugins-bad",
    "gstreamer1.0-rockchip1",      // mpph264enc/mpph265enc（Radxa 源，包名已核实）
    "librockchip-mpp1",            // MPP 运行时
    "librga2",                     // RGA 硬件缩放
    "aic8800-firmware",            // 板载 WiFi 固件（Radxa 源）
    "v4l-utils",
    // media-ctl 工具已包含在 v4l-utils 中（MIPI 媒体管线调试用）
    "python3",
    "python3-numpy",
    "python3-opencv",
    "python3-pip",
    "python3-systemd",
    "cifs-utils",                  // SMB 上传
    "nfs-common",                  // NFS 上传
    "rsync",
    "rclone",                      // 云盘上传（Debian 源有则用，无则 hook 装官方包）
    "network-manager",             // WiFi
    "watchdog",
    "curl",
    "cat-monitor",                 // 我们的应用包（配合 --debs）

```

在 `"customize-hooks"+:` 数组追加（结尾保留原条目）：

```jsonnet
"customize-hooks"+:
[

    |||
        set -e
        mkdir -p "$1/data"
    |||,
    // 确保 rknpu 用户态库路径正确
    |||
        set -e
        echo "/usr/local/lib" > "$1/etc/ld.so.conf.d/cat-monitor.conf"
        chroot "$1" ldconfig || true
    |||,
    // 若 Radxa 源没有 rclone，从官方包安装（示例，按需启用）
    // |||
    //     set -e
    //     wget -O "$1/tmp/rclone.deb" https://downloads.rclone.org/rclone-current-linux-arm64.deb
    //     chroot "$1" dpkg -i /tmp/rclone.deb
    //     rm -f "$1/tmp/rclone.deb"
```

## 8. 常见坑

| 坑 | 解决 |
| --- | --- |
| `--debs` 后自定义内核没生效 | 确认本地 deb 包名与官方一致（`linux-image-6.1.*-rk2410`），且 packages 里显式列出 |
| rsdk 构建下载慢/404 | 用 `-M`/`-m` 国内镜像；第三方镜像加 `-P` 禁用 pkgs.json |
| Buildroot 里没有 gstreamer rockchip 插件 | 检查 buildroot 版本与 BR2_EXTERNAL_ROCKCHIP 路径；或用 overlay 直接拷 .so |
| 应用依赖（python3-opencv 等）体积大 | 接受（Debian 方案体积数百 MB）；追求极限小用 Buildroot 纯 C++ 版 |
| 模型与镜像分离 | 大模型不进镜像：首次启动从 NAS/云盘拉取到 /data/models |
| 烧录后 WiFi 不工作 | 检查 aic8800 驱动与固件包是否进 rootfs（rsdk: aic8800-firmware；buildroot: BR2_PACKAGE_RKWIFIBT_*） |

镜像验收通过后，阅读文档 14：把项目整理成简历可用的素材。
