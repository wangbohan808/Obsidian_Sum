# 设置项探勘表 · 异人之下

> **一句话核心：设置不是"调舒服"，是**缩短「我看到 → 我反应 → 游戏执行」这条链路上的每一段延迟**；凡是增加延迟、减少信息、或让画面与真实判定不一致的，一律关。**

> 用途：终测（2026-11-04 开服）第一天，公开资料无完整设置清单。本表按"应该有"逐项列出，边对边填，填完即为此游戏的设置基线。
> 前提：PC 端、键鼠、准备用自由视角。

---

## 零、三条判据（比清单值钱，换游戏也能用）

动任何一项之前先问三个问题：

| # | 判据 | 处理 |
|---|---|---|
| 1 | 会不会增加「输入 → 画面反馈」的延迟？ | 会 → 关 |
| 2 | 会不会减少你能看到的信息量？ | 会 → 关 |
| 3 | 会不会让「屏幕上的画面」和「服务器的真实判定」不一致？ | 会 → 关 |

这三条能推掉八成选项。格斗游戏和射击游戏、音游共用同一套逻辑：**延迟和清晰度是唯二的真指标，画质不是。**

## 一、画面类

| 设置项 | 它真正影响什么 | 建议 | 界面确认 |
|---|---|---|---|
| 帧率上限 | 每秒能看几次"对手出招" | **拉满**，不要锁 60<br>⚠️ 直播时改锁"能稳定维持"的档位，原因见 [[02_直播推流术语与链路]] | ☐ |
| 垂直同步 | 消撕裂，但引入 1~3 帧延迟 | **关** | ☐ |
| 动态模糊 | 转身瞬间糊片，判断朝向变慢 | **关** | ☐ |
| 景深 | 焦点外虚化，边缘信息丢失 | **关** | ☐ |
| 镜头/屏幕震动 | 有打击反馈，但干扰读帧 | **关或最低** | ☐ |
| 特效质量 | ⚠️ 技能特效过密会**遮挡判定范围** | **中或低** | ☐ |
| 阴影质量 | 几乎无判定价值 | **低** | ☐ |
| 抗锯齿 | 判定边缘是否清晰 | TAA 低 / FXAA | ☐ |
| 视野 FOV | 能看到多少侧方 | **最大** | ☐ |
| 镜头距离 | 同上，看得远不等于看得清 | **最远** | ☐ |
| 亮度/对比度 | ⚠️ **直接影响红光（险招）/蓝光（平招）识别** | 默认偏暗一档，别过曝 | ☐ |
| HDR | 提高对比，但增加识别成本 | **关** | ☐ |
| 分辨率 | 判定边缘清晰度 | **原生**，不要降 | ☐ |
| 植被/人群/杂物密度 | 纯遮挡 | **低** | ☐ |
| 环境光遮蔽 / 反射 | 吃帧，无判定价值 | **低** | ☐ |

## 二、视角与锁敌（本轮核心）

| 设置项 | 选项 | 建议 | 界面确认 |
|---|---|---|---|
| 视角模式 | 自由 / 锁定 / 半锁定 | **按场景切**：1v1 排位用锁定，3v3/2v2 用自由 | ☐ |
| 锁敌策略 | 自动 / 手动 / 不锁 | 先试自动，明确知道切谁再上手动 | ☐ |
| 锁敌优先级 | 最近 / 面向 / 残血 | 车轮战用"最近"最稳 | ☐ |
| 锁敌切换键 | 默认常为中键 | **改独立键**，中键易误触 | ☐ |
| 视角回正 | 开 / 关 | **关**（自动回正 = 抢你的控制权） | ☐ |
| 镜头平滑 / 阻尼 | 0~100 | **0**（这是纯输入延迟，不是"手感柔和"） | ☐ |
| 鼠标灵敏度 | — | 调到"手腕小幅移动转 90°" | ☐ |
| 反转 Y 轴 | 开 / 关 | 个人习惯 | ☐ |
| 手柄死区 | — | 若改用手柄再调 | ☐ |

### ⚠️ 已知官方缺陷（「百相测试」策划快答原文）

| 问题 | 官方表述 | 应对 |
|---|---|---|
| 自由视角体验不佳 | 已承认，正式版改善 | 别指望这版调顺，靠"少转视角、多走位"绕 |
| 智能锁敌不智能 | 群战切换目标麻烦 | 3v3 别依赖自动锁敌 |
| **锁敌机制每局都要重新设置** | 已承认 | **每局开局先按一遍，写进开局流程** |

## 三、战斗与输入

| 设置项 | 它影响什么 | 建议 | 界面确认 |
|---|---|---|---|
| 输入缓冲 / 预输入 | 连招容错窗口 | 中档起步，别一次拉满 | ☐ |
| 招式取消方式 | 长按 vs 单点 | 按角色习惯，先试默认 | ☐ |
| 自动转向 / 攻击方向修正 | ⚠️ **决定"自由视角下出招朝哪"** | 必须实测，不能猜 | ☐ |
| 连招辅助 / 简易模式 | 降低操作量，但压缩上限 | **关**（要练技术就关） | ☐ |
| 身外身快捷栏 | 4 点上限选 3 个 | 按打法配，不影响设置 | ☐ |

## 四、HUD / 界面

| 设置项 | 建议 | 理由 |
|---|---|---|
| 伤害数字 | **关 / 简略** | 挡视线，且不影响判断 |
| 血条样式 | 保持默认 | — |
| 技能 CD 提示 | **开** | 决定你敢不敢起手 |
| 帧率显示 | **必开** | 掉帧=掉拆招，要看得见 |
| 延迟显示 | **必开** | 网络抖动会伪装成"我手慢" |
| 战斗日志 | 按需 | — |

## 五、音频

| 设置项 | 建议 | 理由 |
|---|---|---|
| 音效 | **必开** | 听招、听取消，格斗游戏的重要信息源 |
| 音乐 | 降到 20~30% | 盖住音效就亏了 |
| 语音 | 按需 | 语音会压掉音效细节 |

## 六、练习场三个"神器"（优先级高于一切设置）

去练习场确认这三样有没有，它们决定你能不能做技术研究：

| 功能 | 有 | 没有 |
|---|---|---|
| **判定框显示** | 能直接看到攻击范围/受击框，做帧数据内容 | 只能录屏逐帧数 |
| **帧数显示（招式起止帧）** | 能把"前摇 8 帧"这种话说死 | 只能体感描述，说服力差一个量级 |
| **输入记录显示** | 能证明"是输入丢帧，不是我手慢" | 争议时无法自证 |

> **这三样就是"技术型 UP 主"和"普通玩家"的分界线。** 有，你就能做别人做不了的内容；没有，你的差异化只能落在硬件侧（输入延迟实测、摇杆改装）。
