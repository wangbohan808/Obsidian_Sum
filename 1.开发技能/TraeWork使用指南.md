# TraeWork 使用指南

> 分工一句话：改代码 / 纯文件 → Cursor；动手点界面 / 真实浏览器 / 飞书 / 媒体 / 跨设备 → TraeWork。

## 何时用 Cursor（已够用）
- 写代码、debug、重构、脚本（代码维度比 TraeWork 更顺手）
- 本机文件夹整理、改配置文件

## 何时果断用 TraeWork
| 场景 | 用哪个能力 |
| --- | --- |
| 开桌面软件点按钮、跨 App 搬数据、无 CLI 的老软件 | 电脑控制 |
| 登录态网页填表、抓 JS 渲染数据、批量提交 | 浏览器控制 |
| 飞书文档 / 多维表格 / 日历 / 消息 / 审批 / 会议纪要 | Lark |
| 文生图 / 文生视频（可带参考图、参考视频） | Seedream / Seedance |
| 深度读写 Office、数据出报表 / PPT / 可视化报告 | 内置 Skills |
| 定期自动跑、手机派活、出门在家都能派 | 定时任务 / 移动端 / 网页版 |

## 开箱即用的一等能力（是内置插件，不是 MCP）
- **浏览器控制**：内置浏览器 + 外部 Chrome 扩展 → 真实登录态 / Cookie / JS 渲染下操作页面
- **电脑控制（computer use）**：直接操作 Windows 桌面，点按钮、拖拽、跨 App 协作
- **Lark（飞书）**：文档、多维表格、电子表格、日历、消息、审批、任务、妙记、知识库、邮箱
- **Seedream / Seedance**：文生图 / 文生视频
- **内置 Skills**：docx / xlsx / pdf / pptx / html-report / html-deck / research-guide / video-content-extractor 等
- **定时任务 + 子智能体**：cron 周期执行、多路并行拆任务
- MCP 是开放标准，需自己接，不算开箱即用

## 部署 / 使用步骤
1. 桌面版：下载安装 → 建工作空间
2. 启用插件：设置里开启「浏览器控制」「电脑控制」；「Lark」「Seedance/Seedream」需授权登录
3. 涉及指定文件夹的任务：选该文件夹作工作空间（名称要明确，便于后续固化成 Skill）
4. 不涉及本机文件的任务：直接建工作空间，总结成 Skill
5. 网页版：work.trae.cn 免装，云端沙箱跑（默认不碰本地文件）
6. 移动端：应用商店搜「TRAE」，同账号登录，手机下发、桌面/云端执行，三端实时同步
7. 定时：对话里让 AI 建 cron 任务

## 提效要点（复盘积累）
- 说清验收标准，别只给模糊目标
- 需看页面视觉 / 图 → 用有视觉的模型，别用纯文本模型
- 上下文会丢，长任务拆短、分步验收
- 危险操作会停下等确认；UAC / 验证码 / 登录 / 扫码仍需人工配合
- AI 打转时果断打断纠偏，别让它重复试错
