## 🎬 视频01 · VisionMaster软件安装教程

**视频要点**：VM 算法平台软件的完整安装流程，包含 4 个安装包的用途与安装顺序。

### 安装包组成（共 4 个压缩包）
1. **VM-CN-STD（基础安装包）**——必须先装
2. **VM-Patch-CN（深度学习补丁包）**——需要使用深度学习功能模块时安装
3. **VM-CN（示例补丁包）**——安装后可打开 VM 官方示例方案
4. **VisionTune（深度学习训练工具安装包）**——VM3.4.0 及之后版本，若需深度学习训练必须单独安装

> ⚠️ 深度学习补丁包与示例补丁包的安装**不分先后**；VisionTune 与前面几个包有依赖关系，须在深度学习补丁包之后再装。

### 详细操作流程
1. 解压安装包，双击**基础安装包**开始安装，点击"下一步"
2. 选择**加密方式**和**相机驱动**：
   - 安装在 PC 上 → 选 **标准版**
   - 安装在智能相机上 → 选 **智能相机版**
3. 点击"下一步"完成安装，**建议勾选重启系统**以完成所有配置
4. （按需）安装**深度学习补丁包**：双击 → "开始安装补丁" → 下一步 → 完成
5. （按需）安装**示例补丁包**：同上
6. VM3.4.0 及以后如需深度学习训练：解压 **VisionTune** 安装包 → 双击安装 → 下一步 → 完成（安装后自动打开训练工具界面，可关闭）
7. 插上加密狗，打开 VM 算法平台软件
8. 验证：因安装了示例补丁包，可通过 VM 打开示例方案（如"手机摄像头定位"方案）查看是否正常

## 🎬 视频02 · VM使用教程-本地图像导入及参数设置

**视频要点**：无相机实物时，用本地图像作为图像源的完整参数设置，重点是拼接使能功能。

### 操作流程
1. 工具箱「采集」区拖入**图像源**模块到流程编辑区
2. 双击图像源，选择图像源类型为**本地图像**
3. 通过三个按钮管理图片：**添加图像** / **添加图像文件夹** / **清空图像**

### 关键参数设置
| 参数 | 说明 |
|---|---|
| **像素格式** | 可选 Mono8（黑白）、RGB24（彩色），按导入图像实际类型选择 |
| **取图间隔** | 毫秒，范围 0~1000；现场固定节拍取图时设置，多数场景设为 0 |
| **方案存图** | 把本地图保存进方案，下次打开无需重新导入；**最多 120 张**，存于 C 盘临时文件夹 |
| **S/N 初始值** | 相当于计数器，需要统计输出图像序号时使用，一般不用设 |
| **图片缓存** | 把本地图缓存到内存，减少磁盘读取耗时，用于测试方案耗时/耗时波动 |
| **拼接使能** | 单张图无法完整展示被测物时，导入多张图拼接后再做算法处理 |

### 拼接使能操作（重点演示）
1. 双击图像源 → 打开**拼接使能**按钮
2. 设置**起始高度**（拼接图像 Y 方向起点，可通过鼠标查看图像 Y 值确定）
3. 设置**拼接高度**（决定拼接图像的高度）：若总高 1024、起始 743，则拼接高度 = 1024 - 743 = 281
4. 点击"执行"→ 第一张黑色（无上一张缓存时自动补黑）→ 再次执行 → 两张图成功拼接
5. **触发清空**功能：触发变量非 0 时清空上一张图像缓存（⚠️ 触发变量只能订阅**全局变量**）

### 字符触发过滤
- **输入字符**：选择字符来源；**触发字符**：传输进来的字符须与设置**完全一致**才触发流程；不设置则任意字符（含空字符）都可触发

## 🎬 视频03 · VM使用教程-相机取图及参数设置

**视频要点**：通过相机作为图像源的连接方式、触发模式与参数设置。

### 相机连接（相机管理界面）
1. 图像源选择**相机** → 点击"关联相机"右侧小相机图标 → 进入相机管理
2. 点击设备列表右侧**加号**添加相机，选择相机类型：
   - **全聚焦相机（通用）**：多数第三方相机走此类型，只要 MVS 客户端能连上、能取图的相机，VM 都能连接
   - **相机采集卡（抓拍/面阵采集）**：先通过配置文件加载采集卡 **DCF 文件**，再选相机，可调图像参数/增益、缓存张数
3. 连接方式：
   - 打开 **GigE 相机使能**：加载 CTI 文件枚举并连接（支持 GigE、CameraLink、CoaXPress 等接口相机）
   - **枚举方式**（推荐）：手边有相机直连电脑时首选
   - **跨网段 IP 方式**：相机走网络协议且需远程连接时用；填**本机 IP**（自动获取，勿改）+ **相机 IP**（MVS 客户端可查）

### 关键参数
| 参数 | 说明 |
|---|---|
| **图像缓存** | 相机触发过快、流程来不及处理时开启防丢图（硬触发场景常用）；相机缓存 **100 张** vs 本地图像缓存 5 张，两者概念不同 |
| **实时取流** | 弹出预览窗口实时采集，检查出图是否正常/丢包（仅支持组播的相机可实时取流） |
| **断线重连时间** | 相机断线后在该时长内反复重连，超时则放弃 |
| **触发模式/触发源** | Line0（光耦隔离输入，防外部电压过大烧电路）、Line2（可配置 IO，可设输入/输出，无隔离）、Software（软触发，单次运行触发一次、连续运行连续取图）、Counter（计数器触发，多次硬触发后才外触发一次） |
| **触发延迟** | 相机收到触发信号后延迟响应的时间，单位**微秒** |
| **图像参数** | MVS 客户端设好的参数会自动导入；也可在 VM 内直接调节（⚠️ 需**停止预览**时设置；建议先在 MVS 调好再同步） |

### 其他设置
- **相机类型**：自动判断，定制型号可能误判，手动修正即可
- **有效电平**：搭配 IO 通讯使用
- **控制曝光/控制增益**：可订阅脚本或其他模块输出的 **Flow 型数据**实现逻辑控制；修改后写进方案，后续更换相机方案数值不变

## 🎬 视频04 · VM使用教程-SDK取图

**视频要点**：相机被其他软件占用等复杂情况下，用二次开发（SDK）方式给 VM 图像源输入图像。

### VS 工程环境配置（以 VS2017 + C# 为例）
1. VS 新建项目 → **Windows 窗体应用程序**（C#），框架选 **.NET Framework 4.6.1**（VM 基于该框架开发）
2. 项目属性 → 生成 → **取消勾选"首选 32 位"** ⚠️（后期代码报环境错误先检查此项）
3. 打开 VM 安装路径，使用 **VM4.3 快速引用工具**添加引用：选择项目路径 → 全选模块 → 导入模式选"覆盖"或"跳过同名" → 确定
4. 回 VS 全量重新加载，检查"引用"已成功导入
5. 工具箱 → 右键"选择项" → 浏览打开 VM 安装路径下的**控件库** → 添加成功，搜索"VM"即可见控件

### 搭建简单页面
- 拖动 **GuruBoss**（整体框架）→ **Button**（操作按钮）→ 流程显示区、图像显示区控件，属性里 Dock 选择填充区域

### SDK 取图核心代码
1. 创建**图像源实例**，引用流程中图像源模块
2. 两种输入图像方式：
   - `setImageData()` —— 直接输入图像数据，**单次有效**
   - `setImagePath()` —— 从本地指定路径输入图像（本视频演示方式），路径可在图像文件属性查看
3. ⚠️ **在回调函数中获取结果**（高频运行环境下直接获取会失败）
4. 重新生成 → 启动 → 加载 VM 方案 → 执行方案 → 成功 SDK 取图
5. ⚠️ 若导入彩色图，图像源模块需**打开输出 Mono8**，供后续模块订阅灰度图

## 🎬 视频05 · 快速匹配模块介绍

**视频要点**：用快速模板匹配做高效定位，覆盖建模、运行参数、高级参数的完整讲解。

### 模块界面（4 个子界面）
基本参数 / 特征模板 / 运行参数 / 结果显示

### 建模步骤
1. 基本参数：修改订阅图像源、设置 ROI 区域
2. 特征模板 → **创建**（或"载入"本地模型）→ 编辑模板
3. 顶部菜单：选**当前图像**或本地其他图像建模；**模板存图**（是否同步保存模板图片）；**模型工程导出**（保存到本地）
4. 全部屏蔽打开后用**画笔工具**描绘模板特征轮廓
5. 多模板管理：右侧管理，可隐藏、可设为匹配区域或屏蔽区域
6. 参数不佳时：**尺度和阈值模式改为手动**：
   - **特征尺度**（1~20）：值越大特征尺度越大、边缘点越稀疏、匹配越快；取 1 最精细 ⚠️ 轮廓点增加会使匹配耗时增加
   - **对比度阈值**（1~255）：值越大淘汰特征点越多（示例：设 80 后轮廓点明显减少）

### 运行参数
| 参数 | 说明 |
|---|---|
| **全部搜索模式** | 对所有模板逐一匹配输出最优 |
| **匹配分数** | 相似度阈值，范围 0.1~1，默认 0.5，需实测调整 |
| **匹配个数** | 允许查找最大目标数，默认 1，范围 1~1000 |
| **匹配极性** | 边缘颜色过渡（白→黑/黑→白）；目标极性不一致时设"不考虑极性"（更快则设"考虑极性"） |
| **角度范围** | 目标相对模板角度变化，默认 -45°~+45°，越小越快 |
| **尺度范围** | 一致性尺度变化，默认 -1.0~+1.0（示例：调 0.8~1.4 匹配到尺度不一致目标） |

### 高级参数
- **最大重叠率**（0~100，默认 80）：两目标重叠允许比例；示例：80→可匹配，20→重叠目标漏检
- **排序类型**：按需选择结果排序规则
- **阈值类型**：自动阈值（推荐）/ 模板阈值 / 手动阈值
- **是否考虑噪点**：特征有毛刺时匹配分数会降低，通常不开
- **延拓阈值**：特征在图像边缘显示不全时，缺失比例低于阈值仍可匹配（示例：超出 20% 设 30 可匹配，超 50% 设 60）
- **超时控制**（0~10000 毫秒）：超时停止搜索不返回结果，0 关闭
- **轮廓使能**：勾选显示模板轮廓特征点（不勾选只显示匹配框，减少耗时）

## 🎬 视频06 · VisionMaster开机自启动设置步骤

**视频要点**：机台上电后 VM 软件自动启动并加载方案，减少现场操作步骤。

### 操作流程
1. 打开 VM 主界面 → **设置菜单 → 软件设置** → 找到"启动加载"相关设置
2. **使能开机软件自启动**：主机开机后自动运行 VM
3. **延时启动**（秒）：开机后等待固定时间再启动，建议 **30~90 秒**（最大 1000 秒，不宜过大，受系统启动时间影响）
4. **默认运行界面启动**：VM 运行时不显示主界面，直接显示设置好的运行界面
5. **文件自动加载**：设置是否启动时自动加载方案（需指定方案路径；有密码的方案在此输入密码）
6. **启动状态**：方案加载后运行状态可选连续/非连续，通常选**非连续运行**
7. 点击确认生效

> 示例配置：延时 30 秒 + 运行界面启动 + 自动加载方案 → 开机后全自动进入工作状态，无需人工操作。

## 🎬 视频07 · VisionMaster图像拼接功能演示

**视频要点**：单相机视野不足时，用标定 + 图像拼接工具把多个局部图像拼成整图（VM 3.4.0）。

### 准备标定板
1. VM 工具栏 → **标定板生成工具**：自定义标定板类型、行数、列数、棋盘格实际间距、是否生成 C1 地图
2. 支持海康**一字形/二字形标定板**，生成后自动保存到本地路径，可打印使用

### 全局相机设置
1. 打开相机管理 → 加号添加设备 → 依次添加所有相机
2. ⚠️ 相机需设为**触发模式**（默认软触发）；为区分可重命名

### 图像拼接模块配置
1. 添加图像源模块，设为相机并订阅全局相机
2. 图像处理菜单 → **图像拼接模块** → 双击打开：
   - **输入方式**：单来源（单相机多次移动拍摄）/ 多来源（多相机固定位置同时拍摄）
   - **拼接数目**：参与拼接的图像数量（本视频：2）
   - **拼接方式**：A×B 表示 A 行 B 列（2×1 = 上下拼接）
   - 图像输入按顺序订阅图像源模块
3. **拼接模型页** → 新建模型（或编辑/导入/导出本地模型）

### 标定建模
1. 选择"当前图像"（实时相机，⚠️ 只支持外触发）或"其他图像"（本地导入）
2. ⚠️ 创建模型时使用的**图像数目和顺序**必须与实际拼接输入一致
3. 导入两相机拍摄的标定板图像 → 选择标定板类型 → 点击**提取特征**进行标定
4. 成功标定：弹窗提醒 + 图像左下角三角形变**绿色** → 点击**创建模型** → 可"拼接预览"

### ⚠️ 标定注意事项
- 单相机多位置拍摄：每个拍摄周期内各点位置一致
- 多相机拍摄：各相机相对位置不变，**分辨率和视野一致**
- 保证图像清晰，标定板类型选择须与标定图像一致，否则特征提取失败

## 🎬 视频08 · VisionMaster特征匹配

**视频要点**：用图像边缘特征作模板做定位、计数、有无判断（高精度/快速两种匹配）。

### 建模步骤
1. 添加图像源模块（相机实时图或本地图）
2. 「定位」目录下找**特征匹配**工具：**高精度特征匹配**（精度高、特征精细）或**快速特征匹配**（特征粗糙、速度快）
3. 双击模块 → 基本参数订阅图像、创建 ROI
4. 特征模板 → **创建** → 选择当前图像或本地图像
5. 用建模区域工具（扇圆形/矩形/多边形）选定特征区域，保证**特征区域被完全覆盖**
6. **选择模型匹配中心**自定义匹配中心；可添加多个建模区域，右侧设为**屏蔽区域**（区域无有效特征点）
7. 配置参数：**粗糙尺度**（1~20，越小轮廓越精细）、**对比度阈值**（越大淘汰越多）、尺度/阈值模式（默认自动，可切手动）
8. **橡皮擦**擦除多余轮廓点；**清空/撤销/重做**编辑

### 运行参数
- **最小匹配分数**：过高会匹配不到目标
- **最大匹配个数**：当前图像允许的最大目标数
- **角度范围**：目标相对模板角度变化，超出范围匹配不到
- **最大重叠率**（0~100，默认 50）：示例：重叠 50% 两个都匹配到，降到 10% 只识别上方一个
- **延拓阈值**（最大 90）：边缘缺失比例低于阈值仍可匹配；示例：缺失 20% 设 30 匹配成功，超 50% 设 60

## 🎬 视频09 · VisionMaster 深度学习OCR功能演示

**视频要点**：深度学习 OCR 的完整流程（采集→打标→训练→部署），含软硬件要求。

### 硬件/环境要求
- 训练显卡：**至少 6G 显存**，推荐 GTX1660Ti 及以上，搭配海康 IPC-4700 主机
- 使用深度学习模块需 **IMVSVM-7100 加密狗**

### 训练流程（VisionTrain 1.2.0）
1. 采集训练图片：**至少 11 张**（按实际评估）
2. 打开训练工具 → 平台选择 **VM 平台 + 离线训练** → 新建训练集加载图片
3. 打标（本视频演示**文本行识别**，实际使用较多）：
   - 用**矩形框工具**框住整行字符，框方向尽量与字符方向一致
   - 框上下边缘贴近字符边缘，左右预留 1/2 字符宽度
   - 在下方操作栏正确输入该字符串 → 重复直到所有图完成打标
4. 点击"下一步"（打标数据自动保存）→ 设置深度学习参数：
   - **最大迭代次数**：一般为图片数量的**10~20 倍**
   - 设置模型名称与生成路径 → **开始训练**
5. 训练中可暂停增加迭代次数；可通过训练图库查看效果；曲线收敛于接近 0 即完成
6. 文本行识别训练完成后，**上一步**继续训练**文本定位模型**（为文本识别提供 ROI；如方案中能通过其他方式定位文本，此步可省略）
7. 完成 → 预设路径下获取**两个模型**

### VM 方案部署
1. 图像源导入测试图 → 深度学习模块（**带 G 字母 = GPU 模块**，效率更高；带 C = CPU 模块）
2. ⚠️ GPU 模块需**显存 2G 以上**，推荐 GTX1660Ti 及以上
3. 依次连接：图像源 → **DL 字符定位** → **DL 字符识别**
4. 字符定位模块：加载定位模型，最大查找个数按实际（1 个字符串设 1）
5. 字符识别模块：加载识别模型 → ROI 设置选**继承**，区域选文本定位模型的目标信息矩形
6. 点击运行查看效果；结果显示可改字体、颜色、加个数判断机制

1. 通信管理 → 设备管理 → 选 TCP → 添加配置：
   - **目标 IP + 端口号**（本演示 VM 作客户端）
   - **数据上传**：界面数据实时更新
   - **自动重连**：断开后自动重连
   - **接收结束符**：处理分包问题（上层收到的是去掉结束符的完整数据包）
2. 网络调试助手作 **TCP Server**：本地主机地址/端口与 VM 中目标 IP/端口相同 → 打开
3. 测试收发：助手发信息给 VM（接收正常）；VM 发 String 数据（发送正常）
4. 格式化模块插入文本、订阅匹配框角度 → 发送数据模块 → 执行 → TCP 服务端收到字符信息

## 🎬 视频21 · 项目实战_测量_单相机螺纹测量应用案例

**视频要点**：✅ 准确率 97%+ 的经典实战——单相机定位螺纹起点（XY + R 角度）。核心是**圆环展开 + 图像拼接 + 直线查找采样 + 脚本筛选**的巧妙组合。

### 场景与需求
- 物料为圆形带螺纹，要求引导螺纹**起点位置定位（XY）**并输出**角度 R**（圆心与螺纹起点连线的角度）
- 难点：物料除一个小凹槽外无其他特征，且螺纹起点与外圆粘连情况不稳定，**无法用模板匹配**，也无法用固定 ROI 顶点测量

### 硬件选型
- **1500 万像素相机** + 镜头接**接圈**（缩短工作距离，因视野较小）

### 方案思路推演（视频讲解的思考过程）
1. 模板匹配 ❌（螺纹起点与外圆粘连，匹配率低）
2. 利用凹槽推算 ❌（与客户确认特征不稳定）
3. 把螺纹单独抽离再找 ❌（有的图完全粘连无法处理）
4. ✅ **圆环展开**：螺纹成像内圈密、外圈疏，起点处最宽敞 → 抽离圆环区域做**极坐标展开**（圆环展开模块），把圆形图像展开成矩形图像

### 详细搭建流程（10 步）
1. **定位圆心（XY）**：Blob 模块或圆查找模块定位外圆中心
2. **圆环展开**：用变量计算设置内径/外径（外接矩形框/2 - 60 ≈ 半径 - 60 像素，通过试看排除干扰确定 60）
3. **去噪**：图像有脏物/噪声 → 用 **Blob 分析**提取连通域排除干扰
4. **图像拼接解决 360° 边界问题**：⚠️ 圆环展开最多 360°，若螺纹起点恰在展开图边缘（0° 或 360°），用**两个圆环展开模块 + 左右拼接**实现 360°+180°=540° 展开，保证特征完整
5. **上下拼接**：特征边缘可能紧贴上边缘导致直线查找失败 → 把展开图与另一张相同图**上下拼接**，上方形成黑色连通域，让查找有灰度过渡
6. **直线查找做采样**（替代常规卡尺+Blob Group 循环）：设置**点数 500**（按像素宽度）、**剔除距离 100**（⚠️ 让所有点都不剔除，把"直线查找"当通用采样工具用——本质是沿 ROI 等距分布的卡尺采样）；上边缘从上往下（黑→白）、底边从底往上采样
7. **格式化模块**收集所有采样值（按 0,1,2,3,4 排列顺序取 Y 值）
8. **VM 脚本模块**（支持外部库导入 + C# 编程）核心算法：
   - 读取上/下边缘数据 + 采样点数 → 拆分数组
   - 计算相邻点 Y 差值 → 排序取**前 5 个最大落差**（第一步筛选）
   - 用**底边做基准**：排序取最靠后的 5 个（螺纹起点最靠近底边）
   - 再加防呆（如判断点左边是否还有点，排除杂斑）
   - 输出对应**索引序号**
9. **几何创建模块**验证：按索引从轮廓点集合中取出对应点，确认找点正确
10. **变量计算反推角度**：以圆心为中心虚拟半径 → 索引对应 X / 展开图宽度 = 比例 → 角度 R = 360° × 比例 → 几何创建两点连线渲染显示

### 项目知识点总结
1. Blob / 圆查找模块可做粗定位（XY）
2. 圆环展开模块做极坐标展开，圆 → 矩形
3. 图像有杂斑可用 Blob 或图像处理模块去干扰
4. 圆环展开只有 360°，特征在边缘时**配合图像拼接模块**（两个 270° 展开拼接）
5. 边缘处理可用图像拼接让检测范围保持在视野内
6. 直线查找/圆查找模块可当**采样工具**用（参数调整后采样点不必在直线/圆上）——开拓模块使用思维
7. 格式化模块收集数据 → 脚本模块（C#）DIY 计算 + 防呆
8. 几何创建模块便于定位问题（图形位置不对一眼看出）
9. X/宽度比例 → 变量计算虚拟点 → 与圆心连线渲染，直观显示角度

## 🎬 视频22 · 项目实战_定位_定位项目误差分析及精度提高

**视频要点**：常规定位项目精度问题排查的完整方法论（四大环节 + 量化指标）。

### 排查框架（四大部分）
1. **机构及成像排查** → 2. **标定过程排查** → 3. **视觉过程排查** → 4. **生产过程排查**

### 一、机构及成像排查
- **机构规范性**：相机成像平面与物料平台**尽量垂直**，减少透视畸变误差
- **静态测试**（视觉/成像稳定性）：拍照位不动，连续采集 100 次提取同一特征 → 统计波动 **≤ 1 像素**正常
- **动态测试**（机构走位精度）：
  - 平移精度：沿 X/Y 正负方向走点再回拍照位，往返 100 次 → 机构运动误差 **< 0.02mm**
  - 旋转精度：机械手正反旋转一定角度 → 图像特征角度应等角度变化，角度差 **≤ 0.1°**
  - 复位精度：旋转后回拍照位 → 特征点变化 **≤ 1 像素**
- **成像质量**：对焦清晰，**边缘过渡带 ≤ 3 像素**；检查是否存在桶形/枕形畸变（看直线边是否弯曲）

### 二、标定过程排查
1. **标定参数准确性**：
   - 图像特征点/物理点绑定是否正确
   - N 点标定注意"自动生成物理点"规则理解；4.2 之后平差标定已简化
   - 相机模式（相机静止/运动，上下相机位）与标定类型
   - ⚠️ 自由度一般选**第 2 个**（能应对大部分场景；第 1 个可能因透视有误差）
2. **标定参数合规性**：
   - N 点标定轨迹尽量占视野 **1/2 以上**
   - 旋转角度 **≥ 5°**（太小圆心拟合不准；条件允许可 30°+）
3. **标定数据质量**：
   - 每张标定图特征点提取偏差 **≤ 1 像素**
   - 不同标定图间同一物理点偏差 **≤ 1 像素**
   - 轨迹 X/Y 应垂直、无波动（波动=某张特征点提取偏差）
   - ⚠️ 建议**等步长走点**（便于排查）；打开小画笔查看每次采样点与物理坐标：平移数据应**等差**、旋转数据应回到第 5 点（0,0）且角度对应
4. **标定结果**：
   - 标定状态：1=成功，0=失败
   - **平均像素误差 ≤ 1 像素**；**旋转像素误差 ≤ 0.5°**
   - **旋转一致性**：1=同向，-1=反向（4.1/4.2 后可改参，或重标定）
   - **手性一致性**：标定文件中 IsRightCalA 节点，1=左右手一致，-1=相反

### 三、视觉过程排查
- **视调物理坐标**：工具刚好抓到物料时的机械手坐标（须正确记录）
- **基准图像点**：视调姿态下拍照记录的特征点，生产时该点应保持不变

### 四、生产过程排查
- 生产拍照位与标定第 5 点拍照位一致（允许偏差可补偿，但**姿态/旋转角度必须不变**）
- ⚠️ 生产时**焦距（相机到成像面距离）必须与标定时一致**（成像为锥形模型，距离变化导致标定矩阵失配）
- **平移偏差验证**：只平移，工具能否移动到物料中心 → 不能则重标定
- **旋转移动性验证**：给补偿角度旋转机械手，抓取姿态与视调一致则正确
- **手性验证**：判断机械手坐标系与图像坐标系左右手是否一致，不一致改标定文件
- **旋转中心拟合验证**：用标定旋转图片把旋转后特征旋回基准姿态与基准做差 → 差为 0 则拟合准（可借助单点纠偏模块验证）

### 常见问题速查表
| 问题 | 原因方向 |
|---|---|
| 定位不准 | 机构运动不稳定（动静态测试） |
| 特征提取不稳 | 成像质量差（边缘过渡带 >3 像素） |
| 标定矩阵有误差 | 标定图像数据不稳定（特征点 >1 像素） |
| 定位不准 | 拍照姿态与标定时不一致（旋转） |
| 定位不准 | 机构未到拍照位就计算偏差（等机构稳定） |
| 抓取侧压偏差 | 吸嘴末端与物料平面不平行（水平仪/物理测量/定期检查） |

## 🎬 视频23 · 项目实战_定位_双相机定位引导应用案例

**视频要点**：大物料（单相机拍不全）双相机对角拍摄 → 统一坐标系 → 单点抓取/纠偏引导机械手。

### 场景与难点
- 大物料定位引导：视觉发送抓取坐标给机械手
- 难点①：**多相机坐标系统一**（2/4/8 个相机）
- 难点②：**偏差计算**

### 方案设计思路
1. **坐标系统一**：两个相机分别做**标定板标定** → 都统一到同一个标定板坐标系
2. **与机构连接**：**主相机**与机构做 **N 点标定**（9 点平移 + 3 次旋转）→ 主相机图像坐标系映射到机构物理坐标系
3. **偏差计算**：两相机分别提取对角特征点 → 统一到标定板坐标系 → 求**中点**（作为特征点）+ 两点连线**角度** → 中点经逆矩阵转回主相机图像坐标系 → 单点抓取模块（内部含 N 点标定矩阵）→ 输出物理偏差

### 标定板选择
- 支持：棋盘格标定板、圆标定板、海康一/二型标定板
- ⚠️ **棋盘格/圆标定板无坐标记录**：需手动做坐标偏移，把两相机原点平移到同一棋盘格零点
- ✅ **推荐海康标定板**：中间带二维码，自动记录零点坐标，两相机原点自动对齐，无需手动偏移
- 生成方式：VM 工具栏 → **标定板生成工具** → 设置类型/二维码尺寸/行数/格子边长（mm）→ 生成 → 打印（PDF 格式）
- 标定板大小尽量**同时覆盖两个相机视野**

### 标定板标定过程
1. 打印标定板放于两相机视野内（拍得越多越好）
2. 海康标定板：直接采集图像 → 标定板标定 → 生成标定文件（自动统一坐标系）
3. 其他标定板：手动数格子 → 坐标偏移把原点移到同一位置

### 主相机与机构 N 点标定
- 目的：获取主相机图像坐标系 → 机构物理坐标系的转换矩阵
- 标定物料：选择特征点**稳定提取、精度高（≤1 像素）**的标准件
- 相机静止场景：机构携带标准件移动/旋转 → 采集 9 点平移 + 3 次旋转（9+3 点标定）
- ⚠️ 也可机构吸取物料采样，但要保证吸取无震动

### 偏差计算流程（5 步）
1. **提取两相机对角边角点**：模板匹配粗定位 + 边角点精定位
2. **坐标系统一**：两相机特征点经**标定转换模块**（加载各自标定板标定文件）映射到标定板坐标系
3. **求点位和角度**：**点点测量模块**计算两点连线角度 + 中点坐标
4. **转换到主相机图像坐标系**：⚠️ 用主相机标定矩阵**求逆**（标定转换模块把类型从"图像坐标"改为"物理坐标"即可实现逆变换）
5. **偏差计算**：中点输入**单点抓取模块**（模块内部实现 N 点标定矩阵转换）→ 创建基准（基准图像点 + 基准角度 + 视调物理坐标 + 视调拍照物理坐标 + N 点标定文件）→ 输出**相对物理偏差**和**绝对物理坐标** → 发送数据模块发给机械手引导抓取

### 纠偏场景
- 大物料抓取后需纠偏：流程与单点抓取一致，**仅把"单点抓取"模块换成"单点纠偏"模块**

### ⚠️ 关键知识点
1. 大物料：两相机拍对角求中点做单点抓取/纠偏；精度担忧可增相机数（4/8 相机），相机越多单点扰动越小（按预算/精度平衡）
2. 多坐标系再乱也不用怕：**最终都统一到物理坐标系**，用标定板标定/硬核标定模块统一
3. 标定转换模块**坐标类型选择**：图像坐标 → 标定板坐标；反向需**逆矩阵**（类型选物理坐标）
4. 旋转中心即标定转换后的原点：标定矩阵为 3×3（旋转/平移/缩放/透视关系），通过"旋转中心移到原点并引入平移量"记录旋转中心
   - ⚠️ 平差/旋转标定后，标定转换获得的点 + 第 5 点物理坐标 = 实际绝对物理坐标（旋转标定一般在第 5 点/第 10 点进行）
5. 数据通过发送数据模块发给机械手，形成**闭环引导定位**

## 🎬 视频24 · 项目实战_测量_四相机尺寸测量应用案例

**视频要点**：高精度尺寸测量——四相机分别拍四角，通过标定统一坐标系后测出长宽（32×30mm，公差 ±0.0025mm 级）。

### 项目需求与像素精度推算
- 测量矩形产品长宽：32×30mm，公差 ±0.0025mm
- 精度要求：像素精度达**公差带的 1/10**（源于 G-R&R 重复性 10% 要求；动态重复性约 1 像素）
- 公差带 1/10 = 0.005mm → 长边需 **6400 像素**、短边需 **6000 像素** → 单相机无法满足 → 用**四个相机分别拍四个角**

### 硬件
- 标定板：带二维码的**海康二型标定板**（物理坐标统一）
- 光源/镜头：**标准背光 + 远心组合**（推荐）
- 相机分布：产品四顶点附近，每个相机视野约为产品一角

### 标定流程（4 相机）
1. 拍标定板 → 新建流程：图像源 + **标定板标定模块**
2. 设置标定文件路径、类型（海康二型）、物理尺寸（格子边长 1mm）
3. 运行流程 → 模块自动把标定结果写入标定文件
4. 重复完成相机 1/2/3/4 标定（可查看标定误差验证）

### 测量设置
1. 拖 4 个**图像源**（每个对应一个相机）
2. **边缘焦点工具**获取角点像素坐标
3. **标定转换工具**：根据标定文件把像素坐标转为**物理坐标**
4. **点点测量工具**：计算两个物理点距离得到宽度；重复得长度
5. 运行结果：宽度 ≈ 32mm、长度 ≈ 30mm，基本符合实物 ✓
6. 验证：确认标定转换模块选择对应标定文件；点点测量输入设置为对应标定转换输出 → 运行查看结果

### 典型案例与解决
1. **双击安装包无反应、任务管理器无 VM 进程**：安装包属性 → 常规 → 勾选"解除锁定"取消 → 重新双击安装
2. **报"软件未激活/是否离线激活"**：安装顺序错误 → 按正确顺序重装：基础安装包（选软件安装）→ 试用版补丁 → 试用授权文件 → 更新完成
3. **试用版启动报"加密狗未安装/检测不到"**：
   - 卸载并重装**加密驱动**
   - 无效则改安装包下配置文件：授权节点属性 0（加密狗授权）→ 改为 1（软授权）→ 保存重启
   - 检查"IsRightCalA"（应为正确值，不影响启动但影响显示）
4. **VM 无法启动报"串口驱动"问题**：安装**运行库**——双击安装路径下运行库安装包；仍失败可网上下载运行库
5. **报"超出模块数量上限"**（默认上限 256）：
   - 4.0：退出软件 → 安装目录 SoConfig/Configuration 文件右键编辑 → 修改模块支持数量上限节点（512/1024/2048，两个参数尽量一致）→ 保存重启
   - 4.2：软件顶部工具栏"设置 → 软件设置 → 高级"直接修改模块数量

### 排查方法论
- **优先现场排查**：查看模块输出数据是否合理、处理逻辑是否合理
- **追溯排查**：搭建流程时开启**输出图像模块**（保存每次处理图像便于追溯）；使用**保存日志模块**（记录模块状态与处理结果）
- 无法自行排查 → 联系技术支持 → 仍无法定位 → 打包以下文件给研发：
  1. **日志**（Application/Log 文件夹，打包压缩）
  2. **转储文件**（崩溃时在 VM 安装目录 dump 文件夹产生）
  3. **VM 版本信息截图**（帮助 → 版本信息）
  4. 问题出现的**详细时间**与**复现步骤/方案**
