# ESP32-S3 桌面像素小夜灯「加油鸭」— FreeRTOS 全功能规划 v2

> 设计参考：已确认采用概念图一（`concept_front.jpg`）的外观形态——圆润椭圆白色底座 + 立式圆角磨砂亚克力面板 + 顶置双按键 + 正面 USB-C + 亚克力边缘彩虹光晕 + 左桌宠右信息分屏布局。
> 目标：自制一款 MCU PCB 板，跑 FreeRTOS，通过"主显示矩阵 + 侧发光轮廓光"双层 LED 系统在漫反射亚克力上实现氛围光与信息显示，包含温湿度、高考倒计时（送妹妹）、像素桌宠、RGB 灯效、按键切换、网页自定义配置。
> 语言：中文（本规划及全部交付物均使用中文，代码注释除外）。

### 5.2 原理图要点
- **ESP32-S3 最小系统**：按官方《ESP32-S3 Hardware Design Guidelines》，EN 引脚 10kΩ 上拉 + 1µF RC 缓启；GPIO0/GPIO46 BOOT 配置；UART0 TX/RX 引出测试点方便烧录调试；所有 VDD 引脚就近 100nF 去耦。
- **USB-C 供电**：CC1/CC2 各接 5.1kΩ 下拉到 GND；VBUS 经 ESD 保护后分两路：一路直供 5V LED 电源面，一路进 LDO 出 3.3V。
- **WS2812 数据线**：ESP32 GPIO → 330Ω 串联电阻 → 第一颗 WS2812 DIN；若实测 3.3V 高电平无法稳定驱动 5V WS2812 的 VIH（约 0.7×VDD=3.5V），则在 DOUT 路径上接入 74HCT245 做 3.3V→5V 电平转换（VCC 接 5V）。主矩阵与轮廓光用**两条独立数据线**（不同 GPIO），分别串联电阻，避免一段故障拖垮另一段。
- **电源**：5V 入口放 470µF 电解 + 100nF；主矩阵电源路径建议走 1mm 以上铜宽或铺铜；WS2812 每 50~80 颗就近补 100nF 去耦。
- **SHT40**：SDA/SCL 挂 I2C（加 4.7kΩ 上拉），地址 0x44；传感器位置靠近底座通风孔，避开 LDO 热源。
- **RTC（DS3231）**：I2C 挂同一总线，地址 0x68；VBAT 接 CR1220 电池座，保证掉电时间不丢；这是倒计时可靠工作的关键。
- **按键**：KEY1/KEY2 一端接 GPIO（启用内部下拉），另一端接 3.3V；软件消抖（20ms）；RST/BOOT 按键底部开孔，用牙签按即可。
- **光敏电阻（可选）**：与 10kΩ 分压后接 ADC 引脚，底座顶面开小孔采集环境光。
- **蜂鸣器（可选）**：通过 NPN 三极管（S8050）+ 1kΩ 基极限流驱动，接一个 PWM 通道 GPIO。

### 5.4 PCB 布局建议
- **板形**：建议做成长方形或切角椭圆（长边约 95mm × 65mm），能放入椭圆底座即可；方形 PCB 成本最低。
- **分区**：板中央区域布置 **20×20 WS2812 主矩阵**（贴片面朝上），矩阵下方（板边）放 USB-C 和 LDO，板后方放 ESP32-S3 模组与外围，模组天线朝外且下方净空。
- **主矩阵**：20×20 WS2812B 按蛇形走线串联；灯珠间距 4mm（对应面板发光区约 80×80mm），用 2020 封装可进一步缩小间距；如用 5050 封装间距约 4.5~5mm（发光区约 90×90mm，更贴近面板尺寸）。
- **侧发光 LED**：不焊在主板上，而是用一条**柔性 FPC 小板**或直接飞线 12 颗侧发光 WS2812 粘在底座凹槽内壁，朝向亚克力板下沿；也可以在主板上预留 2PIN 焊盘 + 固定孔，用排针接一条自制的 LED 边条。
- **SHT40**：靠近板边（底座通风孔一侧），下方少铺铜减少热耦合。
- **按键**：KEY1/KEY2 两个轻触开关在板边位置对齐底座顶面开孔（间距 18mm 居中）。
- **USB-C**：板边正向放置（母座朝外），对齐底座正面开孔。
- **铺铜**：5V 和 GND 大面积铺铜；3.3V 星型走线到模组；天线区域下方三层净空。

**装配顺序**：
1. PCB 打样回来，焊好全部元件（先焊最小件，最后焊 WS2812）；
2. USB 上电测试：先只点 1 颗 LED，再点亮矩阵，再驱动轮廓光；
3. 把 PCB 用 M2 螺丝固定到底座下壳；
4. 侧发光 LED 条粘入底座凹槽内壁，引线插主板焊盘；
5. 亚克力背面贴匀光膜，从顶面插入凹槽；
6. 盖上底座上盖（或一体化底座从底部扣合），贴防滑垫脚；
7. 完成。

**亚克力加工文件**：提供 DXF/SVG 切割图纸（90×90mm 正方形 + R12 圆角 + 插入端延长 8mm 的插脚）。

**3D 打印外壳**：提供 OpenSCAD 参数化源文件（可自由调整尺寸/圆角/壁厚），导出 STL 供打印。建议壁厚 2mm，底面留 4 个螺丝柱，凹槽留 3.2mm 槽宽适配 3mm 亚克力+匀光膜。

## 六、固件架构（FreeRTOS 任务设计）

采用 **ESP-IDF v5.x（原生 FreeRTOS）**，PlatformIO 组织工程。核心是"一个功能一个任务"，借此系统学习 RTOS。

### 6.1 FreeRTOS 学习点映射

| RTOS 概念 | 在本项目中的落地 |
|-----------|------------------|
| 任务 / 优先级 / 抢占 | 每个外设/功能一个 task，设不同优先级 |
| 任务状态(就绪/阻塞/挂起) | Button/WiFi 任务大部分时间阻塞等待事件 |
| 队列 | 传感器→显示、WiFi→UI、网页→显示 的消息队列 |
| 事件组 | 模式切换、联网成功、传感器就绪、配网重置等事件聚合 |
| 二值/互斥信号量 | 保护共享 framebuffer（主矩阵+轮廓光各一个互斥量） |
| 递归/超时 | I2C 读取带超时，失败不卡死；HTTP 请求超时 |
| 软件定时器 | 帧刷新节拍、传感器采样节拍、NTP 周期校时、喂狗 |
| 任务通知 | 按键→显示任务的轻量单向通知 |
| 流/消息缓冲区（可选进阶） | 网页上传大图案时分块传帧缓冲 |
| 堆内存管理 | 展示 heap / 任务栈监控（内置状态页） |
| 调度统计 / 优先级反转 | 借助 vTaskGetRunTimeStats / mutex 优先级继承 |
| 看门狗 | ESP-IDF Task Watchdog + Interrupt Watchdog，演示系统健壮性 |

### 6.2 任务划分（优先级从高到低）

| 任务 | 职责 | 周期/触发 | 用到的机制 |
|------|------|-----------|-----------|
| `input_task` | 按键扫描/消抖/长短按识别，发事件 | 10ms 轮询 | 事件组 + 任务通知 |
| `sensor_task` | 读 SHT40（+ 可选光敏 ADC），数据入队 | 2s 定时 | 软件定时器 + 队列 |
| `display_task` | 维护主矩阵 20×20 framebuffer，RMT 刷新 WS2812 | 30fps 帧节拍 | 互斥量保护 fb + 队列 |
| `edge_light_task` | 维护轮廓光 12 灯 framebuffer，独立刷新 | 30fps | 独立互斥量 |
| `pet_task` | 桌宠逐帧动画写入主 fb（仅桌宠/综合模式） | 帧率定时（8fps） | 事件组门控 + 定时器 |
| `effects_task` | RGB 灯效算法（主矩阵全屏/局部效果） | 帧节拍 | 定时器 + 队列 |
| `clock_task` | NTP 校时、RTC 读写、倒计时计算、跨天更新 | 1 分钟/事件 | 事件组 + 互斥量 |
| `wifi_task` | STA/SoftAP 管理、断线重连、mDNS | 事件驱动 | 事件组 |
| `server_task` | ESP-IDF http_server，REST API + 静态页托管 | 事件 | 队列 + 互斥量 |
| `app_task` | 顶层状态机：模式切换编排、功能仲裁 | 事件驱动 | 事件组 + 优先级仲裁 |

### 6.3 显示布局（主矩阵 20×20 分屏设计）

- **左区（列0~11，12列）**：约 12×16 像素桌宠动画区，猫/狗/兔/鸭等像素角色逐帧动。
- **右上区（列12~19，行1~9）**：8×9 像素温湿度数字区（"26°C"/"55%" 两排）。
- **右下区（列12~19，行10~18）**：8×9 像素倒计时区（"99"/"天" 大字天数+小标）。
- **边缘轮廓光**：独立 12 颗侧发光 LED 驱动，不在主矩阵内，不占用 20×20 像素；可显示彩虹、呼吸、单色、温度联动配色等。

### 6.4 显示模式（按键循环切换）
1. **综合页（默认）**：左桌宠动画 + 右上温湿度 + 右下倒计时（开机默认页，参考概念图效果）。
2. **温湿度大字**：全屏显示温湿度数值 + 小图标。
3. **高考倒计时**：全屏"距高考 N 天"大字 + 激励语（如"加油！"），冲刺日自动切红金配色。
4. **桌宠模式**：全屏桌宠动画（桌宠更大，可自由走动/眨眼/睡觉）。
5. **RGB 灯效**：主矩阵全屏灯效（彩虹/呼吸/流星/跑马/粒子/蛇）+ 轮廓光同步或独立配色。
6. **自定义图案**：网页上传的单张/逐帧图案展示。
7. **RTOS 调试页**：显示 uptime、free heap、各任务栈剩余水位、CPU 占用率、WiFi RSSI、IP——学习 FreeRTOS 最有价值的一屏。

长按 KEY2 进入配网模式（SoftAP），长按 KEY1 进入亮度调节（短按循环亮度档位）。

### 6.5 关键数据流
- 传感器/倒计时/网页配置 → 通过**消息队列**喂给 `app_task` 汇总状态，再由 `app_task` 决定各模式下写什么到 `display_task` 的 framebuffer。
- **双 framebuffer**：主矩阵 fb（20×20×3 bytes = 1200 bytes）与轮廓光 fb（12×3 = 36 bytes），各自由独立互斥量保护，避免花屏。
- 配置持久化：WiFi 凭据、倒计时日期、灯效参数、亮度、自定义图案、桌宠选择存 **NVS**；大资源（桌宠动画帧、用户上传图案）存 **LittleFS** 分区。
- 时间：启动时读 RTC，联网后 NTP 同步并回写 RTC；WiFi 断开时降级到 RTC 计时，倒计时永远准确。

## 七、网页配置端（手机浏览器）

- 架构：ESP-IDF `esp_http_server` + LittleFS 托管静态页 + JSON REST API；配置存 NVS，图案/动画资源存 LittleFS。
- 访问方式：
  - 已配网：`http://pixelpet.local`（mDNS）或设备 IP；
  - 首次/重置：长按 KEY2 → 设备开 SoftAP `PixelPet-Setup`，手机连入 → 浏览器自动弹出 Captive Portal → 填家庭 WiFi SSID/密码。
- 功能页面：
  1. **首页仪表盘**：实时显示当前温湿度、倒计时天数、WiFi 状态、固件版本。
  2. **显示模式**：切换默认模式、选桌宠角色（小猫/小狗/小兔/小鸭/自定义）、上传自定义像素图案（支持图片/逐帧 GIF，服务端降采样）。
  3. **高考倒计时**：设置目标日期（默认次年 6 月 7 日）、激励语开关、冲刺日灯效开关、特殊日期提醒（100/30/7 天）。
  4. **RGB 灯效**：主矩阵灯效选择、轮廓光配色（彩虹/单色/呼吸/温度联动）、全局亮度滑块（5 档）、自动亮度开关（若焊了光敏）。
  5. **WiFi 设置**：查看当前网络、切换/重连、忘记网络。
  6. **系统**：重启、恢复出厂、查看 RTOS 状态（任务栈/堆/uptime）、固件 OTA（预留）。
- 设计：移动端优先，卡片式 UI，深色底+彩色点缀，支持横竖屏，全中文。

## 十、补充建议（设计强化项）

按价值优先排序，标 ★ 强烈推荐已纳入默认方案：

1. ★ **DS3231 RTC + CR1220 后备电池**：断电倒计时/时间不丢，不依赖 WiFi，BOM 成本 < 10 元。
2. ★ **双层 LED 系统（主矩阵 + 侧发光轮廓光）**：还原概念图边缘彩虹光晕，比"外圈像素"方案光效更均匀、更"高级"。
3. ★ **RTOS 调试页**：实时展示任务列表/栈余量/堆水位/CPU 占用，是学 FreeRTOS 最直观的一屏。
4. ★ **SoftAP 配网向导 + Captive Portal**：第一次用不需要敲 IP，手机一连 WiFi 就弹出配置页。
5. ★ **亚克力背面贴匀光膜**：消除灯珠颗粒感，呈现概念图里"像素柔和发光"的效果。
6. ★ **独立 RMT 通道驱动主矩阵和轮廓光**：两段 LED 互不影响，一段故障不拖垮另一段。
7. **光敏电阻自动亮度**（可选）：白天亮夜里柔，护眼。
8. **无源蜂鸣器**（可选）：按键音 + 特殊日提示音（"加油"短旋律），成本 1 元。
9. **底座侧面/背面通风栅格**：SHT40 测温准，同时给 LDO 散热。
10. **底部防滑硅胶垫**：4 个小圆垫，防刮桌面。
11. **预留电池仓（v2 迭代）**：底座内可藏 3.7V 锂电 + TP4056 充电板，做成便携版，本次 v1 不做但 PCB 预留位置。
12. **3D 打印外壳分件（上下壳）**：下壳放 PCB，上壳留按键孔和插槽，自攻螺丝 4 颗固定，方便装配与维修。

## 十二、验证（Verification）
