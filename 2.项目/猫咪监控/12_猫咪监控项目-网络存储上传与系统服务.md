# 12 猫咪监控项目：网络、存储、上传与系统服务

> 目标：让 ROCK 5C 连上家庭 WiFi、事件视频本地归档、自动上传到局域网主机或云盘，并作为 7×24 服务稳定运行。

---

## 1. 网络：WiFi 连接（AIC8800D80）

### 1.1 硬件与驱动

ROCK 5C 板载 **WiFi6/BT5.4（AIC8800D80）**。驱动与固件：

- 内核驱动：`CONFIG_WLAN_VENDOR_AIC` / `aic8800` 模块（bsp 与 rk3588_sdk 内核均包含）；
- 固件：RadxaOS 已内置（`/lib/firmware/aic8800/` 或 `aic8800_fdrv` 相关）；自制镜像用 rk3588_sdk 的 `BR2_PACKAGE_RKWIFIBT_AIC8800D80_USB_FIRMWARE=y`（文档 03 §4.1），rsdk 用 `aic8800-firmware` / `aic8800` 相关 Radxa 包。

```bash
# 板端确认
lsusb | grep -i aic          # 期望出现 AIC8800 USB 设备
lsmod | grep aic              # aic8800_fdrv / aic8800_btlpm 等
ip link                       # 期望出现 wlan0
```

### 1.2 用 NetworkManager 连接（推荐，RadxaOS 默认）

```bash
nmcli dev wifi list
nmcli dev wifi connect "MyHomeWiFi" password "******"
nmcli con up "MyHomeWiFi"
nmcli con show "MyHomeWiFi" | grep -E "connection.autoconnect|ipv4"

# 设为开机自连（默认已开）：
nmcli con mod "MyHomeWiFi" connection.autoconnect yes

# 固定 IP（可选，方便 SSH 与上传目标配置）：
nmcli con mod "MyHomeWiFi" ipv4.method manual ipv4.addresses 192.168.1.100/24 \
    ipv4.gateway 192.168.1.1 ipv4.dns 192.168.1.1
nmcli con up "MyHomeWiFi"
```

### 1.3 用 wpa_supplicant（无桌面/极简镜像）

```bash
sudo apt install -y wpasupplicant
sudo tee /etc/wpa_supplicant/wpa_supplicant-wlan0.conf >/dev/null <<'EOF'
ctrl_interface=DIR=/run/wpa_supplicant GROUP=netdev
update_config=1
country=CN

network={
    ssid="MyHomeWiFi"
    psk="******"
    key_mgmt=WPA-PSK
}
EOF
sudo systemctl enable --now wpa_supplicant@wlan0
sudo dhclient wlan0   # 或 systemd-networkd 管理
```

### 1.4 断网自愈

```bash
# systemd 定时检查（每 2 分钟）
cat > /etc/systemd/system/wifi-check.service <<'EOF'
[Unit]
Description=WiFi connectivity check

[Service]
Type=oneshot
ExecStart=/usr/local/bin/wifi-check.sh
EOF
cat > /etc/systemd/system/wifi-check.timer <<'EOF'
[Unit]
Description=Periodic WiFi check

[Timer]
OnBootSec=2min
OnUnitActiveSec=2min

[Install]
WantedBy=timers.target
EOF
```

```bash
cat > /usr/local/bin/wifi-check.sh <<'EOF'
#!/bin/bash
ping -c1 -W3 223.5.5.5 >/dev/null 2>&1 || nmcli dev wifi connect "MyHomeWiFi" password "******"
EOF
chmod +x /usr/local/bin/wifi-check.sh
systemctl enable --now wifi-check.timer
```

## 3. 上传到局域网主机（SMB / NFS）

### 3.1 SMB/CIFS 挂载（家庭 NAS / Windows 共享，最常见）

```bash
sudo apt install -y cifs-utils
sudo mkdir -p /mnt/nas

# 凭据文件（权限 600）
sudo tee /etc/cifs-credentials >/dev/null <<'EOF'
username=nasuser
password=******
EOF
sudo chmod 600 /etc/cifs-credentials

sudo tee -a /etc/fstab >/dev/null <<'EOF'
//192.168.1.50/petcam   /mnt/nas  cifs  credentials=/etc/cifs-credentials,uid=1000,gid=1000,iocharset=utf8,vers=3.0,_netdev,noauto,x-systemd.automount  0 0
EOF
sudo systemctl daemon-reload
sudo mount /mnt/nas
```

### 3.2 NFS（Linux 主机）

```bash
sudo apt install -y nfs-common
sudo mkdir -p /mnt/nas-nfs
sudo mount -t nfs 192.168.1.50:/volume1/petcam /mnt/nas-nfs
# 开机挂载写入 /etc/fstab：server:/path /mnt/nas-nfs nfs defaults,_netdev 0 0
```

### 3.3 上传脚本（rsync，断点续传 + 删除源文件）

```bash
cat > /usr/local/bin/upload-videos.sh <<'EOF'
#!/bin/bash
set -e
SRC=/data/videos
DEST=/mnt/nas/petcam/videos

# 只有目标可达才执行（避免离线时堆积/重复扫描）
mountpoint -q /mnt/nas || exit 0

# --remove-source-files：传完删除本地副本（目录保留）
rsync -av --remove-source-files --timeout=60 "$SRC"/ "$DEST"/
find "$SRC" -name "*.mp4" -size 0 -delete
EOF
chmod +x /usr/local/bin/upload-videos.sh
```

systemd timer（每小时 + 开机后 5 分钟）：

```bash
cat > /etc/systemd/system/video-upload.service <<'EOF'
[Unit]
Description=Upload pet camera videos to NAS
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/upload-videos.sh
EOF

cat > /etc/systemd/system/video-upload.timer <<'EOF'
[Unit]
Description=Upload videos hourly

[Timer]
OnBootSec=5min
OnUnitActiveSec=1h
AccuracySec=1min

[Install]
WantedBy=timers.target
EOF
systemctl enable --now video-upload.timer
```

## 4. 上传到云盘 / 对象存储（rclone）

### 4.1 安装与配置

```bash
sudo apt install -y rclone
rclone config
# 交互式创建 remote，常见选择：

#   WebDAV（Nextcloud/坚果云/群晖 WebDAV）

#   Aliyun Drive / Alist（国内网盘桥接）

#   S3（MinIO/阿里云 OSS）

#   Google Drive / OneDrive
```

示例（WebDAV，坚果云/Nextcloud）：

```bash
rclone config create webdav webdav \
    url https://dav.jianguoyun.com/dav/ \
    vendor other \
    user "you@example.com" \
    pass "******"
```

### 4.2 上传脚本

```bash
cat > /usr/local/bin/upload-cloud.sh <<'EOF'
#!/bin/bash
set -e
# 先传局域网 NAS，再传云盘（可只选其一）
/usr/local/bin/upload-videos.sh || true
rclone move /data/videos webdav:PetCam/videos \
    --transfers 2 --checkers 4 --log-file=/var/log/rclone.log \
    --delete-empty-src-dirs --retries 3
EOF
chmod +x /usr/local/bin/upload-cloud.sh
# 同样用 systemd timer 每小时触发
```

> `rclone move` 自带"传完删除源文件"语义，且支持断点续传（`--checkers` 并发数按板子内存调整，1~2 即可）。

### 4.3 事件通知（可选，简历加分）

用钉钉/企业微信/Bark webhook 推送事件摘要：

```bash
cat > /usr/local/bin/notify.sh <<'EOF'
#!/bin/bash
# 用法：notify.sh "8月12日 08:30 猫咪进食 42秒"
msg="$1"
curl -s -X POST https://oapi.dingtalk.com/robot/send?access_token=TOKEN \
     -H 'Content-Type: application/json' \
     -d "{\"msgtype\":\"text\",\"text\":{\"content\":\"$msg\"}}" >/dev/null
EOF
```

在事件状态机结束时调用（Python）：

```python
subprocess.Popen(['/usr/local/bin/notify.sh', summary], stdout=subprocess.DEVNULL)
```

## 5. systemd 服务化（7×24 稳定运行）

### 5.1 主服务单元

```ini
# /etc/systemd/system/cat-camera.service
[Unit]
Description=Cat Camera AI Monitor
After=network-online.target local-fs.target
Wants=network-online.target
RequiresMountsFor=/data

[Service]
Type=simple
User=radxa
WorkingDirectory=/opt/cat-monitor
Environment=PYTHONUNBUFFERED=1
ExecStart=/usr/bin/python3 /opt/cat-monitor/app/main.py --config /etc/cat-monitor/config.yaml
Restart=always
RestartSec=5
StartLimitIntervalSec=300
StartLimitBurst=5
# 卡死自动重启（主进程看门狗）
WatchdogSec=30
# 日志限制
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Python 里喂狗：

```python
import systemd.daemon
systemd.daemon.notify('WATCHDOG=1')   # 每个主循环喂一次（<30s）
```

### 5.2 硬件看门狗（可选）

```bash
# 内核开启 CONFIG_WATCHDOG / CONFIG_DW_WATCHDOG（RK3588 自带 dw_wdt）
sudo apt install -y watchdog
echo -e "watchdog-device = /dev/watchdog\ninterval = 10\n" | sudo tee /etc/watchdog.conf
sudo systemctl enable --now watchdog
```

### 5.3 日志与状态

```bash
journalctl -u cat-camera -f
journalctl -u cat-camera --since today | grep -E "EVENT|ERROR"
systemctl status cat-camera
```

健康自检（systemd timer 每天）：

```bash
cat > /usr/local/bin/health-check.sh <<'EOF'
#!/bin/bash
# 1) 服务活着？
systemctl is-active cat-camera >/dev/null || systemctl restart cat-camera
# 2) 磁盘空间？
avail=$(df /data | awk 'NR==2{print $4}')
[ "$avail" -lt 5000000 ] && /usr/local/bin/notify.sh "磁盘剩余不足: $((avail/1024)) MB"
# 3) 最近一小时是否有事件日志写入（防静默故障）
find /data/videos -newermt "1 hour ago" -name "*.mp4" | head -1 | grep -q . || \
  logger -t cat-camera "No recording in last hour (may be normal)"
EOF
```

## 6. 电源、散热与长期稳定性

| 项目 | 做法 |
| --- | --- |
| 电源 | 5V/3A+ 稳定电源（官方 30W PD），避免供电不足导致 SD 卡/UVC 掉线 |
| 散热 | 官方散热片 + 小风扇；温度 `cat /sys/class/thermal/thermal_zone0/temp` 控制在 <75°C |
| 频率策略 | `cpufreq` 设 `schedutil`/`conservative`；NPU 不推理时允许降频 |
| 存储寿命 | 视频写 eMMC/NVMe；SD 卡选 A2；`noatime` 挂载；日志放内存 tmpfs |
| 掉电保护 | 视频文件用 `splitmuxsink` 周期性切分（5 分钟一段），掉电最多丢当前段 |
| 时间同步 | `systemd-timesyncd` 开启，事件命名依赖正确时钟 |
| 上传防呆 | 所有上传脚本在挂载/网络不可达时静默退出，下一轮重试 |
